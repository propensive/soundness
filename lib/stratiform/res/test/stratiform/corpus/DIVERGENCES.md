# Corpus divergences from the Rust reference implementation

The fixtures were ported from the Rust reference implementation at the commit
recorded in `UPSTREAM_SHA`, and `.check` files were originally generated by that
binary.

The reference implementation has not yet adopted the LIRA-based schema-reference
pragma grammar (TEL `design/lira-schema-references.md`; soundness#1841), so every
fixture touching the pragma diverges from upstream until it regenerates:

- Pragma lines use LIRA references (`domain/name[:version|:tag]`) in place of the
  deleted URL identifier form; `https://tel-lang.org/schema/tels` became the
  pinned coordinate's module, `specification.tel/tels`.
- The `Pragma` struct in `.check` files has the new shape
  `version`/`reference`/`layers`/`signature`/`sigil`, with the reference rendered
  as its canonical flat string. This shape is locally defined by
  `TelCheckTree.ofPragma` pending upstream adoption.
- `pragma-schema-url-with-fragment` was retired (the URL form no longer exists)
  and replaced by `pragma-reference-with-signature`; `e122-pragma-extra-atoms`
  became a pure order/multiplicity case (two references); the `pragma-full-form`,
  `pragma-reference-*`, `pragma-layers-*`, `pragma-sigil-only`,
  `pragma-pinned-tels`, `e121-*` and `e122-*` reference/layer fixtures and
  `e310-schema-plus-sigil` are local additions with hand-written `.check` files.
- Error messages in `errors:` sections for E121/E122 follow the reworded
  specification text; only the codes are compared by the test suites.
