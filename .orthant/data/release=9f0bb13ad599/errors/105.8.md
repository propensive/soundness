# `↯/s.105.8` — `PublicKey.Error`

Raised when a key document cannot be read as a public key of the cipher asked for.

## Cause

A public key is read from an X.509 `SubjectPublicKeyInfo` or a PKCS#1 `RSAPublicKey`, bare or
in PEM armor, as a key of a named cipher, such as `PublicKey[Rsa[2048]]`. This error covers a
document that is not a public key, and one that holds a key of another algorithm or size.

## Variants

```tabular
column  Code
column  Reason
column  Message
row  `↯/s.105.8.1`  `Malformed`  the key document was malformed: <detail>
row  `↯/s.105.8.2`  `Mismatch`  a <expected> key was expected but <found> was found
row  `↯/s.105.8.3`  `Unsupported`  the key uses an unsupported <detail>
```

## Resolution

A `Mismatch` names what the document holds: read the key as that cipher, or supply the key
that was intended. A key in OpenSSH's single-line form is not PEM; read it with
`OpenSsh.publicKey`.
