# `SN-728` — Missing `Tactic[JsonRpcError]` (retired)

This error no longer exists. The page is kept so that the code is not reused, and so
that a reference to it from an older release can still be resolved.

## What became of it

Obligatory's `rpc` macro no longer raises this error: nothing in the source reported it when Soundness
adopted bolt codes, so it was given none.
