# `↯/s.106.2` — `JsonPointer.Error`

Raised when a JSON pointer cannot be resolved.

## Cause

Jacinta resolves JSON pointers per RFC 6901. The constructor takes
a `reason: Reason`; the rendered message is `the JSON pointer
could not be resolved because $reason`.

## Variants

(`↯/s.106.2.1`, `UnknownDocument`, was retired when `JsonPointer` lost its never-populated document
URL and `JsonPointer.Registry`; the remaining numbers are unchanged.)

### `↯/s.106.2.2` — `ExpectedHash`

A JSON reference does not begin with `#`.

**Example.** `[↯/s.106.2.2] the JSON reference was not valid because a JSON reference must begin with '#'`

**Resolution.** Begin the reference with `#`, as in `#/play/title`.

### `↯/s.106.2.3` — `ExpectedSlash`

A JSON reference's fragment does not begin with `/`.

**Example.** `[↯/s.106.2.3] the JSON reference was not valid because a JSON reference fragment must begin with '/'`

**Resolution.** Begin the fragment with `/`, as in `#/play`. A bare `#` addressing the whole document is also valid.

### `↯/s.106.2.4` — `BadEscape`

A `~` in a JSON reference is not followed by `0` or `1`.

**Example.** `[↯/s.106.2.4] the JSON reference was not valid because a '~' in a JSON reference must be followed by '0' or '1'`

**Resolution.** Escape a literal `~` as `~0` and a literal `/` as `~1`. No other escape is defined.
