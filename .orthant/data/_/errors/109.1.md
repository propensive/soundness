# `↯/s.109.1` — `Tmux.Error`

Raised when Exoskeleton cannot execute the `tmux` binary.

## Cause

Exoskeleton's `Tmux` integration shells out to `tmux`. If the
binary is not on `PATH` (or is not executable), this error is
thrown.

## Example message

```
[↯/s.109.1] can't execute tmux
```

## Resolution

Install `tmux` and ensure it is on the `PATH` of the process.

## Variants

### `↯/s.109.1.1` — `ShellNotInstalled`

The shell that tmux was asked to run is not on the `PATH`.

**Example.** `` [↯/s.109.1.1] can't drive tmux: the shell binary `fish` is not installed ``

**Resolution.** Install the shell, or name one that is present.

### `↯/s.109.1.2` — `SessionDied`

The tmux session ended while the program was driving it.

**Example.** `[↯/s.109.1.2] can't drive tmux: the tmux session terminated unexpectedly`

**Resolution.** The session was killed, or the command inside it exited. Check the tmux server's own logs.

### `↯/s.109.1.3` — `ExecFailed`

The `tmux` binary could not be executed at all.

**Example.** `[↯/s.109.1.3] can't drive tmux: could not execute tmux`

**Resolution.** Install tmux, or ensure it is on the `PATH` of the process.
