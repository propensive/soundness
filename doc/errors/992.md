# `SN-992` — `Xsd.Error`

Raised when an XML document cannot be read as an XML Schema.

## Cause

`Xsd.parse` reads a schema document into the `Xsd` model, and reports the first construct it
cannot accept. The message is `the XML Schema could not be read because $reason`.

## Variants
```tabular
column  Code
column  Reason
column  Meaning
column  Message
column  Resolution
row  `SN-992.1`  `NotSchema`  The document element is not `schema` in the XML Schema namespace.  `[↯SN-992.1] the XML Schema could not be read because the document element is root, not an XML Schema`  Pass the schema document itself, with its `xs:`, `xsd:` or default prefix bound to `http://www.w3.org/2001/XMLSchema`.
row  `SN-992.2`  `Unexpected`  An element appears where the schema grammar does not allow it.  `[↯SN-992.2] the XML Schema could not be read because {http://www.w3.org/2001/XMLSchema}oops may not appear in schema`  Correct the schema, or report the construct if it is one the model does not yet read.
row  `SN-992.3`  `MissingAttribute`  A declaration lacks an attribute it must have, such as a global element's `name`.  `[↯SN-992.3] the XML Schema could not be read because the element has no name attribute`  Add the attribute.
row  `SN-992.4`  `BadOccurs`  A `minOccurs` or `maxOccurs` is neither a number nor `unbounded`.  `[↯SN-992.4] the XML Schema could not be read because lots is not a valid number of occurrences`  Use a non-negative integer, or `unbounded` for `maxOccurs`.
row  `SN-992.5`  `UnknownPrefix`  A `type`, `ref`, `base`, `itemType`, `memberTypes` or `substitutionGroup` uses a prefix the document does not bind.  `[↯SN-992.5] the XML Schema could not be read because the prefix zz is not bound to a namespace`  Declare the prefix with `xmlns:zz="…"` on the schema element or an ancestor.
row  `SN-992.6`  `BadFacet`  A facet's value is not of the kind the facet takes, such as a non-numeric `length`.  `[↯SN-992.6] the XML Schema could not be read because many is not a valid value for the maxLength facet`  Give the facet a value of the right kind.
row  `SN-992.7`  `Duplicate`  A global element, type, attribute or group is declared twice under one name.  `[↯SN-992.7] the XML Schema could not be read because the element a is declared more than once`  Remove or rename one of the declarations.
```
