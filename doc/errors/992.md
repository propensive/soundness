# `SN-992` — `Xsd.Error`

Raised when an XML document cannot be read as an XML Schema.

## Cause

`Xsd.parse` reads a schema document into the `Xsd` model, and reports the first construct it
cannot accept. The message is `the XML Schema could not be read because $reason`.

## Variants

### `SN-992.1` — `NotSchema`

The document element is not `schema` in the XML Schema namespace.

**Example.** `[↯SN-992.1] the XML Schema could not be read because the document element is root, not an XML Schema`

**Resolution.** Pass the schema document itself, with its `xs:`, `xsd:` or default prefix bound
to `http://www.w3.org/2001/XMLSchema`.

### `SN-992.2` — `Unexpected`

An element appears where the schema grammar does not allow it.

**Example.** `[↯SN-992.2] the XML Schema could not be read because {http://www.w3.org/2001/XMLSchema}oops may not appear in schema`

**Resolution.** Correct the schema, or report the construct if it is one the model does not yet
read.

### `SN-992.3` — `MissingAttribute`

A declaration lacks an attribute it must have, such as a global element's `name`.

**Example.** `[↯SN-992.3] the XML Schema could not be read because the element has no name attribute`

**Resolution.** Add the attribute.

### `SN-992.4` — `BadOccurs`

A `minOccurs` or `maxOccurs` is neither a number nor `unbounded`.

**Example.** `[↯SN-992.4] the XML Schema could not be read because lots is not a valid number of occurrences`

**Resolution.** Use a non-negative integer, or `unbounded` for `maxOccurs`.

### `SN-992.5` — `UnknownPrefix`

A `type`, `ref`, `base`, `itemType`, `memberTypes` or `substitutionGroup` uses a prefix the
document does not bind.

**Example.** `[↯SN-992.5] the XML Schema could not be read because the prefix zz is not bound to a namespace`

**Resolution.** Declare the prefix with `xmlns:zz="…"` on the schema element or an ancestor.

### `SN-992.6` — `BadFacet`

A facet's value is not of the kind the facet takes, such as a non-numeric `length`.

**Example.** `[↯SN-992.6] the XML Schema could not be read because many is not a valid value for the maxLength facet`

**Resolution.** Give the facet a value of the right kind.

### `SN-992.7` — `Duplicate`

A global element, type, attribute or group is declared twice under one name.

**Example.** `[↯SN-992.7] the XML Schema could not be read because the element a is declared more than once`

**Resolution.** Remove or rename one of the declarations.
