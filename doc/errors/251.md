# `SN-251` — `Css.Error`

Raised when a stylesheet contains a construct that is not valid CSS.

## Cause

Cataclysm checks property names against the known set and parses selectors against the full
modern grammar, so a misspelled property or a malformed selector is reported rather than
passed to a browser that will silently ignore it.

## Variants

```tabular
column  Code
column  Reason
column  Message
row  `SN-251.1`  `UnterminatedComment`  a comment was not terminated
row  `SN-251.2`  `UnterminatedString`  a string literal was not terminated
row  `SN-251.3`  `UnexpectedEnd`  the input ended before a rule was closed
row  `SN-251.4`  `UnexpectedChar`  the character <char> was not expected here
row  `SN-251.5`  `EmptySelector`  a selector was expected but none was found
row  `SN-251.6`  `UnknownProperty`  <name> is not a recognized CSS property
row  `SN-251.7`  `BadValue`  <value> is not a valid value for the <property> property
row  `SN-251.8`  `UnsupportedValue`  the value of <name> uses an unsupported type
row  `SN-251.9`  `InvalidName`  <name> is not a valid CSS identifier
```

## Resolution

Correct the property name or the selector. Errors accumulate: a rule with several faults
reports all of them, which is why the error type is plural — `CssErrors` carries the list.
