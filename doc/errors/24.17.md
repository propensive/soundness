# `↯/s.24.17` — `Disturbance`

Raised by `pacify` in place of a `Throwable` thrown by foreign code.

## Cause

`pacify` runs a block of code which was not written with Soundness, such
as a compiler or a classloader, and which reports its failures by
throwing. Whatever the block throws that is not fatal to the program
— any throwable which `NonFatal` accepts, and also an `AssertionError`,
a `StackOverflowError` or a `LinkageError` — is raised as a
`Disturbance`, whose `throwable` is what was thrown.

## Example message

```
[↯/s.24.17] foreign code threw java.lang.AssertionError with the message, not so
```

## Resolution

Handle the `Disturbance` as any other error, with `safely`, `recover`
or `mitigate`, and read its `throwable` for the cause. If the throwable
shows a defect in the foreign code's inputs, such as a class missing
from a classpath, correct the inputs.
