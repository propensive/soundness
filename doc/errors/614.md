# `SN-614` — `Tel.Provider.Error`

Raised when a TEL document does not conform to the schema a `Tel.Provider` reads it by.

## Cause

Stratiform's `Tel.Provider` reads a document through its schema as a record's fields are read,
and reports each mismatch through the `Tactic` of the code reading the field, so that a
validating reader can collect them all. The message is `the TEL did not conform to its schema
because $reason`.

## Variants

### `SN-614.1` — `Absent`

A field the schema requires is missing from the document.

**Example.** `[↯SN-614.1] the TEL did not conform to its schema because the field first-name is required`

**Resolution.** Add the field, or make it optional in the schema.

### `SN-614.2` — `NotSigil`

A field read by the `Sigil` validator holds an atom of more than one character.

**Example.** `[↯SN-614.2] the TEL did not conform to its schema because the value ab is not a single character`

**Resolution.** Give the field a single character.
