# `SN-868` — `Arithmetic.Error`

Raised when an arithmetic operation cannot produce a representable result.

This is distinct from a *value* that cannot be represented, which is
`Decimal.Error` or `Rational.Error` depending on the type.

## Cause

Hypotenuse's checked division raises this error for cases such as
integer division by zero or `MinValue / -1` (which overflows the
positive range).

## Example message

```
[↯SN-868] the result is unrepresentable
```

## Resolution

Guard against zero divisors; for the `MinValue / -1` case, widen
the dividend before dividing.

## Variants

### `SN-868.1` — `DivisionByZero`

The divisor was zero. Raised only under `import arithmeticOptions.division.checked`;
the unchecked default lets the platform's own division semantics apply.

### `SN-868.2` — `Overflow`

The result exceeded the range of its type. Raised only under
`import arithmeticOptions.overflow.checked`. This was `SN-331` (`OverflowError`)
until the two were unified.
