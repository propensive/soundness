# `SN-794` — `BenchError`

Raised when Sedentary cannot execute a benchmark.

## Cause

The error is generic; common causes include configuration
problems, an inability to start the benchmarking harness, or
failures during warm-up.

## Example message

```
[↯SN-794] unable to run benchmarks
```

## Resolution

Inspect the cause chain or harness logs. More specific reasons
may be added in future.
