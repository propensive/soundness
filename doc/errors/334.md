# `SN-334` — `Timespan.Error`

Raised when a text value does not parse as an ISO-8601 duration.

## Cause

`Timespan`'s `Decodable` instance and the `dur"…"` interpolator share one
parser. When it rejects the input — a bare `P`, a missing designator, or
components out of order — this error carries the offending text. The
message is `$text is not a recognized duration`.

This was a variant of `SN-333` until durations were separated from moments:
a duration has no date, no clock time and no timezone, so a failure to read
one is not a failure to determine a moment.

**Example.** `[↯SN-334] P is not a recognized duration`

**Resolution.** Supply a complete ISO-8601 duration, such as `P1Y2M3DT4H5M6S`
for one year, two months, three days, four hours, five minutes and six
seconds. A `dur"…"` literal is checked at compile time and cannot raise this.
