# `SN-589` — `WebDriverError`

Raised when Tarantula's WebDriver action fails inside the browser.

## Cause

The remote WebDriver returned an error response: a 4xx or 5xx status
whose body carries the W3C error object,
`{"value":{"error":…,"message":…,"stacktrace":…}}`. The constructor
takes a `reason: Reason` (decoded from the `error` field, one of the
W3C WebDriver error codes), the browser-supplied `message` as
`detail`, and the `stacktrace`, split on newlines, as
`browserStacktrace`. The rendered message is `the WebDriver action
failed because $reason: $detail`.

Decoding is total: a code the specification has added since, or a
driver-specific one, becomes `Other(code)` rather than being lost.

## Variants

The subcodes below are frozen. `SN-589.1` to `SN-589.8` keep the
meanings they were first published with — including `Other` at 8,
which is why the list is not in alphabetical order — and codes added
since append from 9.

| Code | Variant | Wire code | Meaning | Resolution |
|---|---|---|---|---|
| `SN-589.1` | `NoSuchElement` | `no such element` | The element addressed by the action was not present in the DOM. | Verify the locator strategy and target; wait for the element to appear before acting on it. |
| `SN-589.2` | `StaleElement` | `stale element reference` | The element was previously located but has since been removed from or replaced in the DOM. | Re-locate the element after navigation or DOM mutation before retrying. |
| `SN-589.3` | `NoSuchWindow` | `no such window` | The window or tab handle referenced by the action does not exist. | Confirm the window handle is current; switch to a valid window before acting. |
| `SN-589.4` | `JavascriptError` | `javascript error` | A script evaluated by the WebDriver threw an exception. | Inspect the script and the supplied `detail` for the underlying JavaScript exception. |
| `SN-589.5` | `ScriptTimeout` | `script timeout` | An asynchronous script did not complete within the configured timeout. | Raise the script timeout, or fix the script so that it resolves promptly. |
| `SN-589.6` | `Timeout` | `timeout` | The WebDriver operation timed out before completion. | Raise the relevant timeout, or fix the page so that the awaited condition can be met. |
| `SN-589.7` | `UnknownCommand` | `unknown command` | The WebDriver does not recognise the command issued. | Confirm the WebDriver version supports the action; upgrade the driver if necessary. |
| `SN-589.8` | `Other` | *(any unrecognized code)* | The WebDriver reported an error code that does not map to one of the other cases. The original code is captured in the `Other(code)` parameter. | Consult the W3C WebDriver specification, or the driver's own documentation, for the reported code. |
| `SN-589.9` | `ElementClickIntercepted` | `element click intercepted` | Another element would receive the click — typically an overlay, a modal or a sticky header. | Scroll the target into view, dismiss the obscuring element, or click through the actions API. |
| `SN-589.10` | `ElementNotInteractable` | `element not interactable` | The element is in the DOM but cannot receive the interaction. | Wait until the element is displayed and enabled; check it is not zero-sized or `pointer-events: none`. |
| `SN-589.11` | `InsecureCertificate` | `insecure certificate` | Navigation was blocked because the page was served with an untrusted certificate. | Request the `acceptInsecureCerts` capability when the session is created. |
| `SN-589.12` | `InvalidArgument` | `invalid argument` | An argument to the command was not of the type or in the range the specification requires. | Check the argument against the specification for that command. |
| `SN-589.13` | `InvalidCookieDomain` | `invalid cookie domain` | A cookie was set for a domain other than the current document's. | Navigate to the cookie's domain before setting it. |
| `SN-589.14` | `InvalidElementState` | `invalid element state` | The element's state forbids the command — clearing a non-editable element, for instance. | Check the element is editable, or use script execution instead. |
| `SN-589.15` | `InvalidSelector` | `invalid selector` | The locator was not valid for its strategy. | Check the CSS selector or XPath expression. |
| `SN-589.16` | `InvalidSessionId` | `invalid session id` | The session is no longer active: it was deleted, or the browser terminated. | Open a fresh session; do not retain a session handle beyond its block. |
| `SN-589.17` | `MoveTargetOutOfBounds` | `move target out of bounds` | A pointer action addressed coordinates outside the viewport. | Scroll the target into view, or use element-relative pointer origins. |
| `SN-589.18` | `NoSuchAlert` | `no such alert` | An alert command was issued while no user prompt was open. | Check for an open prompt before accepting, dismissing or reading it. |
| `SN-589.19` | `NoSuchCookie` | `no such cookie` | No cookie of that name is associated with the current document. | Check the name, the document's domain, and the cookie's path. |
| `SN-589.20` | `NoSuchFrame` | `no such frame` | The frame handle or index referenced by the action does not exist. | Check the frame index or element; switch back to the top-level context first. |
| `SN-589.21` | `NoSuchShadowRoot` | `no such shadow root` | The element does not host a shadow root. | Check the element hosts an open shadow root; closed roots are not reachable. |
| `SN-589.22` | `DetachedShadowRoot` | `detached shadow root` | The shadow root was located but its host has since left the DOM. | Re-locate the host element and its shadow root after DOM mutation. |
| `SN-589.23` | `SessionNotCreated` | `session not created` | The driver could not start a session, commonly a browser/driver version mismatch or a missing browser binary. | Check the driver matches the installed browser; check the requested capabilities. |
| `SN-589.24` | `UnableToSetCookie` | `unable to set cookie` | The driver could not set the cookie. | Check the cookie's domain, path, `secure` and `sameSite` attributes against the current document. |
| `SN-589.25` | `UnableToCaptureScreen` | `unable to capture screen` | The screenshot could not be taken. | Check the element has a non-empty rendered area, and that the window is not minimized. |
| `SN-589.26` | `UnexpectedAlertOpen` | `unexpected alert open` | A user prompt was open when a command that requires none was issued. | Accept or dismiss the prompt, or set the `unhandledPromptBehavior` capability. |
| `SN-589.27` | `UnknownError` | `unknown error` | The driver reported a failure it could not classify. This is also raised when a driver replies with a body that is not the W3C error object at all — a crashed driver, or an interposed proxy — in which case `detail` is the raw body. | Inspect `detail` and `browserStacktrace`; check the driver's own log. |
| `SN-589.28` | `UnknownMethod` | `unknown method` | The command exists but does not support the HTTP method used. | Check the command's method against the specification. |
| `SN-589.29` | `UnsupportedOperation` | `unsupported operation` | The driver does not implement the command. | Check the driver's conformance; some commands, such as printing to PDF, are not universal. |

**Example.** `[↯SN-589.1] the WebDriver action failed because the requested element was not found: no such element: Unable to locate element: {"method":"css selector","selector":"#absent"}`
