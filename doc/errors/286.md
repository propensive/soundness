# `SN-286` — `Ar.Error`

Raised when an `ar` archive (the container format of `.deb` packages and `.a` static
libraries) cannot be read or written.

## Cause

Bitumen parses `ar` members lazily from a byte stream, so a fault is reported when the
malformed structure is reached rather than when the archive is opened. The format carries no
checksum and no end-of-archive marker, so the two-byte header terminator and the recorded
member size are the only structural checks available.

## Variants

| Code | Reason | Message |
| --- | --- | --- |
| `SN-286.1` | `BadMagic` | the archive does not begin with the ar magic bytes (got <actual> bytes) |
| `SN-286.2` | `BadTerminator` | the header is not terminated by the two magic bytes (got <actual> bytes) |
| `SN-286.3` | `BadDecimal` | the <field> field did not contain a valid decimal value |
| `SN-286.4` | `BadOctal` | the <field> field did not contain a valid octal value |
| `SN-286.5` | `TruncatedStream` | the archive stream ended unexpectedly (needed <needed> bytes, got <got>) |
| `SN-286.6` | `BadLongNameRef` | the long-name reference <reference> does not resolve in the archive's name table |
| `SN-286.7` | `UnsupportedNameFormat` | the member name <name> uses the BSD length-prefixed form, which is not supported |
| `SN-286.8` | `WriteUnsupported` | ar archives cannot yet be opened for writing |

## Resolution

A truncated archive usually means an incomplete download or a stream that ended early; a bad
terminator means the reader has lost the header boundary, typically because an earlier member's
size field was corrupt. A long-name reference that does not resolve means a GNU archive whose
`//` name table is missing or precedes the wrong members. BSD-style `#1/<length>` names are not
produced by Debian or GNU tooling and are rejected rather than misread.
