# `↯/s.134.2` — `YamlPath.Error`

Raised when a YAML path expression is malformed.

## Cause

A YAML path names a location within a document. Its syntax is checked when written as a
literal and when parsed at runtime, by the same parser.

## Variants
(`↯/s.134.2.1`, `UnknownDocument`, was retired when `YamlPath` lost its never-populated document URL
and `YamlPath.Registry`; the remaining numbers are unchanged.)

```tabular
column  Message
row  `↯/s.134.2.2`  `ExpectedHash`  `[↯/s.134.2.2] a YAML path must begin with '#'`
row  `↯/s.134.2.3`  `ExpectedSlash`  `[↯/s.134.2.3] a YAML path fragment must begin with '/'`
row  `↯/s.134.2.4`  `BadEscape`  `[↯/s.134.2.4] a '~' in a YAML path must be followed by '0' or '1'`
```

## Resolution

The reason names the character or construct at fault. A path must begin at the root, and
each step must be a key or an index.
