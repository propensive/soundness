# `SN-993` — `Xml.Provider.Error`

Raised when an XML value does not conform to the XML Schema an `Xml.Provider` reads it by.

## Cause

Xylophone's `Xml.Provider` checks a document against its schema as a record's fields are read,
and reports the first mismatch. The message is `the XML did not conform to its schema because
$reason`.

## Variants

### `SN-993.1` — `OutOfRange`

A number falls outside the bounds of its type: a `minInclusive`, `maxInclusive`, `minExclusive`
or `maxExclusive` facet, or the bounds a builtin such as `xs:positiveInteger` implies. An absent
bound is `Unset`.

**Example.** `[↯SN-993.1] the XML did not conform to its schema because the value 200 is outside the range 0 to 150`

**Resolution.** Supply a value within the range, or relax the facet.

### `SN-993.2` — `LengthOutOfRange`

A value's length violates a `length`, `minLength` or `maxLength` facet.

**Example.** `[↯SN-993.2] the XML did not conform to its schema because the length of abcd is outside the range 3 to 3`

**Resolution.** Supply a value of a permitted length.

### `SN-993.3` — `PatternMismatch`

A value does not match a `pattern` facet.

**Example.** `[↯SN-993.3] the XML did not conform to its schema because the value nope does not match the pattern \d{3}-[A-Z]{2}`

**Resolution.** Supply a value matching the pattern.

### `SN-993.4` — `NotPermitted`

A value is not among an `enumeration` facet's values.

**Example.** `[↯SN-993.4] the XML did not conform to its schema because the value urgent is not one of low, normal, high`

**Resolution.** Supply one of the permitted values.

### `SN-993.5` — `TooManyDigits`

A decimal has more digits than a `totalDigits` or `fractionDigits` facet allows.

**Example.** `[↯SN-993.5] the XML did not conform to its schema because the value 1.234 has more digits than the 5 total or 2 fraction digits permitted`

**Resolution.** Round or truncate the value to the permitted digits.

### `SN-993.6` — `Absent`

A required element or attribute — one with `minOccurs` of at least one, or `use="required"` — is
missing, or the element it names is in the wrong namespace.

**Example.** `[↯SN-993.6] the XML did not conform to its schema because the element or attribute city is required`

**Resolution.** Add the element or attribute, in the namespace the schema expects.
