# `SN-053` — `Dns.Error`

Raised when a DNS message or name cannot be decoded, encoded or resolved.

## Cause

Urticose's `Dns` vocabulary decodes RFC 1035 wire messages (`data.as[Dns.Message]`), parses
names from their presentation form (`Dns.Name.parse`), encodes messages back to bytes, resolves
names through the platform resolver (`Dns.resolve`) and, in coaxial, exchanges queries with a
nameserver. The message is `the DNS message is not valid because $reason`.

## Variants

### `SN-053.1` — `Truncated`

The message ended inside a field: a header, a name, a question or a record's data.

**Example.** `[↯SN-053.1] the DNS message is not valid because the message ends at offset 12, inside a field`

**Resolution.** Check that the whole datagram was received; a UDP reply longer than the receive
buffer is cut short, so raise the buffer size (`Socket.Option.DatagramSize`) or retry over TCP.

### `SN-053.2` — `BadPointer`

A compressed name points forward, to itself, or past the end of the message. RFC 1035 allows a
pointer only to a *prior* occurrence of a name.

**Example.** `[↯SN-053.2] the DNS message is not valid because the name pointer at offset 12 points forward`

**Resolution.** The sender's compression is broken; the message cannot be read.

### `SN-053.3` — `BadLabel`

A label byte uses one of the reserved label types (`0x40` or `0x80`) rather than a length or a
pointer.

**Example.** `[↯SN-053.3] the DNS message is not valid because the label at offset 20 has unsupported type 64`

**Resolution.** Extended label types are not supported; the message cannot be read.

### `SN-053.4` — `LongLabel`

A label is longer than 63 octets.

**Example.** `[↯SN-053.4] the DNS message is not valid because the label aaaa… is longer than 63 octets`

**Resolution.** Shorten the label; a DNS-SD instance name is limited to 63 bytes of UTF-8.

### `SN-053.5` — `LongName`

A name's labels, with their length bytes and the terminator, exceed 255 octets.

**Example.** `[↯SN-053.5] the DNS message is not valid because the name a.b.c… is longer than 255 octets`

**Resolution.** Shorten the name.

### `SN-053.6` — `EmptyLabel`

A name in presentation form contains an empty label, such as `a..b` or `.a`.

**Example.** `[↯SN-053.6] the DNS message is not valid because the name a..b contains an empty label`

**Resolution.** Remove the doubled or leading dot; a *trailing* dot is allowed and denotes the root.

### `SN-053.7` — `BadEscape`

A backslash in a name in presentation form is not followed by a character or three decimal
digits in the range 0–255.

**Example.** `[↯SN-053.7] the DNS message is not valid because the name a\9b contains a malformed escape sequence`

**Resolution.** Write a literal backslash as `\\`, a literal dot as `\.`, and an arbitrary
character code as `\DDD`.

### `SN-053.8` — `BadRdata`

A record's data length disagrees with its typed body: an `A` record that is not four bytes, an
`AAAA` not sixteen, a name or `SRV` fields that overrun the declared length.

**Example.** `[↯SN-053.8] the DNS message is not valid because the A record data at offset 40 is malformed`

**Resolution.** The sender's record is malformed; the message cannot be read.

### `SN-053.9` — `LongString`

A `TXT` character-string is longer than 255 octets.

**Example.** `[↯SN-053.9] the DNS message is not valid because a character-string of 300 octets exceeds 255`

**Resolution.** Split long `TXT` content into several strings.

### `SN-053.10` — `Trailing`

Bytes remain after the last section of the message.

**Example.** `[↯SN-053.10] the DNS message is not valid because the message has trailing bytes from offset 60`

**Resolution.** Decode exactly one datagram's worth of data.

### `SN-053.11` — `Oversize`

A section has more than 65535 entries, so its count cannot be encoded.

**Example.** `[↯SN-053.11] the DNS message is not valid because the count 70000 does not fit in a 16-bit field`

**Resolution.** Split the records across messages.

### `SN-053.12` — `Unresolved`

`Dns.resolve` could not resolve the name through the platform's resolver.

**Example.** `[↯SN-053.12] the DNS message is not valid because the name nonexistent.example could not be resolved`

**Resolution.** Check the name and the machine's DNS configuration.

### `SN-053.13` — `Timeout`

No response to a query arrived before the timeout.

**Example.** `[↯SN-053.13] the DNS message is not valid because no response arrived before the timeout`

**Resolution.** Check that the nameserver is reachable, or lengthen `Socket.Option.Timeout`.

### `SN-053.14` — `Mismatch`

A response's ID or question does not match the query it was received for.

**Example.** `[↯SN-053.14] the DNS message is not valid because the response with ID 4660 does not answer the query`

**Resolution.** A stray or spoofed datagram was received; retry the query.
