# `SN-053` — `Dns.Error`

Raised when a DNS message or name cannot be decoded, encoded or resolved.

## Cause

Urticose's `Dns` vocabulary decodes RFC 1035 wire messages (`data.as[Dns.Message]`), parses
names from their presentation form (`Dns.Name.parse`), encodes messages back to bytes, resolves
names through the platform resolver (`Dns.resolve`) and, in coaxial, exchanges queries with a
nameserver. The message is `the DNS message is not valid because $reason`.

## Variants
```tabular
column  Code
column  Reason
column  Meaning
column  Message
column  Resolution
row  `SN-053.1`  `Truncated`  The message ended inside a field: a header, a name, a question or a record's data.  `[↯SN-053.1] the DNS message is not valid because the message ends at offset 12, inside a field`  Check that the whole datagram was received; a UDP reply longer than the receive buffer is cut short, so raise the buffer size (`Socket.Option.DatagramSize`) or retry over TCP.
row  `SN-053.2`  `BadPointer`  A compressed name points forward, to itself, or past the end of the message. RFC 1035 allows a pointer only to a *prior* occurrence of a name.  `[↯SN-053.2] the DNS message is not valid because the name pointer at offset 12 points forward`  The sender's compression is broken; the message cannot be read.
row  `SN-053.3`  `BadLabel`  A label byte uses one of the reserved label types (`0x40` or `0x80`) rather than a length or a pointer.  `[↯SN-053.3] the DNS message is not valid because the label at offset 20 has unsupported type 64`  Extended label types are not supported; the message cannot be read.
row  `SN-053.4`  `LongLabel`  A label is longer than 63 octets of UTF-8. Checked when a name is constructed (`Dns.Name(…)`, `Dns.Name.parse`, `+`, `prefix`), so that encoding a message is total.  `[↯SN-053.4] the DNS message is not valid because the label aaaa… is longer than 63 octets`  Shorten the label; a DNS-SD instance name is limited to 63 bytes of UTF-8.
row  `SN-053.5`  `LongName`  A name's labels, with their length bytes and the terminator, exceed 255 octets.  `[↯SN-053.5] the DNS message is not valid because the name a.b.c… is longer than 255 octets`  Shorten the name.
row  `SN-053.6`  `EmptyLabel`  A name in presentation form contains an empty label, such as `a..b` or `.a`.  `[↯SN-053.6] the DNS message is not valid because the name a..b contains an empty label`  Remove the doubled or leading dot; a *trailing* dot is allowed and denotes the root.
row  `SN-053.7`  `BadEscape`  A backslash in a name in presentation form is not followed by a character or three decimal digits in the range 0–255.  `[↯SN-053.7] the DNS message is not valid because the name a\9b contains a malformed escape sequence`  Write a literal backslash as `\\`, a literal dot as `\.`, and an arbitrary character code as `\DDD`.
row  `SN-053.8`  `BadRdata`  A record's data length disagrees with its typed body: an `A` record that is not four bytes, an `AAAA` not sixteen, a name or `SRV` fields that overrun the declared length.  `[↯SN-053.8] the DNS message is not valid because the A record data at offset 40 is malformed`  The sender's record is malformed; the message cannot be read.
row  `SN-053.9`  `LongString`  A `TXT` character-string is longer than 255 octets; checked when `Dns.Rdata.Txt` is constructed.  `[↯SN-053.9] the DNS message is not valid because a character-string of 300 octets exceeds 255`  Split long `TXT` content into several strings.
row  `SN-053.10`  `Trailing`  Bytes remain after the last section of the message.  `[↯SN-053.10] the DNS message is not valid because the message has trailing bytes from offset 60`  Decode exactly one datagram's worth of data.
row  `SN-053.11`  `Unresolved`  `Dns.resolve` could not resolve the name through the platform's resolver.  `[↯SN-053.11] the DNS message is not valid because the name nonexistent.example could not be resolved`  Check the name and the machine's DNS configuration.
row  `SN-053.12`  `Timeout`  No response to a query arrived before the timeout.  `[↯SN-053.12] the DNS message is not valid because no response arrived before the timeout`  Check that the nameserver is reachable, or lengthen `Socket.Option.Timeout`.
row  `SN-053.13`  `Mismatch`  A response's ID or question does not match the query it was received for.  `[↯SN-053.13] the DNS message is not valid because the response with ID 4660 does not answer the query`  A stray or spoofed datagram was received; retry the query.
```
