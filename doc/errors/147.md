# `SN-147` — `LspError`

Raised when a Language Server Protocol operation fails, or by a handler to answer a request
with a JSON-RPC error response. Each reason carries the standard JSON-RPC/LSP wire code,
which `Lsp.listen` places in the error response's `error.code` member.

## Cause

Exegesis implements the LSP wire protocol. This error covers a malformed message, a request
the server cannot satisfy, and any fault a handler chooses to raise: a raised `LspError`
pre-empts the handler's result, becoming an error response for a request or a
`window/logMessage` notification otherwise.

## Resolution

The reason distinguishes a protocol fault from a request that was well-formed but could not
be served. A protocol fault usually means client and server disagree about the protocol
version or the message framing; a handler-raised reason such as `RequestFailed` describes
the server's own refusal, and its details are forwarded to the client in the error
response's message.
