# `↯/s.113.1` — `Oci.Error`

Raised when an OCI container image is malformed or cannot be read.

## Cause

An OCI image is a tar archive with a prescribed layout: an `oci-layout` marker, an
`index.json`, and blobs addressed by digest. This error covers a missing or malformed
member, an unsupported digest algorithm, and a blob whose content does not match its digest.

## Variants

```tabular
column  Code
column  Reason
column  Message
row  `↯/s.113.1.1`  `MissingLayout`  the archive does not contain an oci-layout marker
row  `↯/s.113.1.2`  `UnsupportedLayout`  the image layout version <version> is not supported
row  `↯/s.113.1.3`  `MissingIndex`  the archive does not contain an index.json document
row  `↯/s.113.1.4`  `MissingBlob`  the blob <digest> is not present in the archive
row  `↯/s.113.1.5`  `DigestMismatch`  the blob addressed as <expected> has the digest <actual>
row  `↯/s.113.1.6`  `InvalidBlob`  the blob <digest> could not be interpreted: <detail>
row  `↯/s.113.1.7`  `UnsupportedDigest`  the digest algorithm <algorithm> is not supported
row  `↯/s.113.1.8`  `NoManifest`  the image index lists no manifests
row  `↯/s.113.1.9`  `WriteUnsupported`  OCI image archives cannot be opened for writing
```

## Resolution

A digest mismatch means the image is corrupt or has been altered, and should not be
trusted. A missing blob usually means an incomplete pull. `verified` checks digests;
`layer` and `compressed` do not.
