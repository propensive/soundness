# `SN-609` — `Bintel.Error`

Raised when a BinTEL document cannot be decoded.

## Cause

BinTEL is TEL's binary encoding, guided by a schema. This error covers malformed framing, a
schema signature that does not match the reader's schema, and content that does not conform
to the schema it claims. Variants 1–16 are the B01–B16 codes of §10 of the BinTEL
specification; variant 17 is a resource limit of the decoder (§11), which the specification
places outside that taxonomy because a decoder with a larger limit would accept the same
bytes.

## Variants

| Code | Reason | Message |
| --- | --- | --- |
| `SN-609.1` | `BadMagic` | the magic number is missing or matches neither B2 C4 B5 BB (external mode) nor B2 C4 B5 BC (self-contained mode) |
| `SN-609.2` | `VarintError` | a variable-length integer in the stream is invalid |
| `SN-609.3` | `BadSignatureLength` | the schema signature length is not a valid palimpsest length under any (H, k_i, k_r) |
| `SN-609.4` | `BadSignature` | the schema signature does not decode against the library |
| `SN-609.5` | `BadKeywordIndex` | a keyword index exceeds the parent's flat-keyword count |
| `SN-609.6` | `ValueTruncated` | a Scalar value's byte length extends beyond end of input |
| `SN-609.7` | `BadUtf8` | a Scalar value's bytes are not valid UTF-8 |
| `SN-609.8` | `TrailingBytes` | a whole-document reader found bytes after the document |
| `SN-609.9` | `UnexpectedEoi` | the decoder requested bytes beyond end of input |
| `SN-609.10` | `ReferenceUnresolved` | a Reference or SelectRef in the schema does not resolve to a definition of its kind |
| `SN-609.11` | `EmbeddedSignatureMismatch` | the signature recomputed from the embedded schema body does not equal the carried signature |
| `SN-609.12` | `EmbeddedSchemaUndecodable` | the embedded schema body does not decode as a valid TEL document under tels |
| `SN-609.13` | `CodecUnresolved` | a scalar's declared encoding is not resolved by the codec binding |
| `SN-609.14` | `CodecDecodeFailed` | an encoded scalar's value bytes are rejected by the bound codec |
| `SN-609.15` | `CodecNoncanonical` | an encoded scalar's value bytes are not the re-encoding of their decoded text |
| `SN-609.16` | `DeclaredLengthMismatch` | the declared document length disagrees with the structural extent of the document |
| `SN-609.17` | `NestingLimitExceeded` | the document nests Structs more deeply than the decoder's limit |

## Resolution

A signature mismatch means the reader holds a different schema from the writer; check the
signature before decoding rather than after. A self-contained frame carries its schema, so
it decodes without one being held locally. `TrailingBytes` is a property of the reader's
contract, not of the bytes: the same input is a well-formed stream to `Bintel.decodeStream`
and a single document with a continuation to `Bintel.decodeDocument`. A document framed
before the length field was added (before TEL commit 8380ef7) fails at `BadSignatureLength`,
because its signature length is read as the document length.
