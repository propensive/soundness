# `↯/s.90.1` — `Css.Error`

Raised when a stylesheet contains a construct that is not valid CSS.

## Cause

Cataclysm checks property names against the known set, the descriptors of an at-rule such as
`@font-face` against that rule's own set, and parses selectors against the full modern
grammar, so a misspelled property or a malformed selector is reported rather than passed to
a browser that will silently ignore it.

## Resolution

Correct the property name or the selector. Errors accumulate: a rule with several faults
reports all of them, which is why the error type is plural — `CssErrors` carries the list.
