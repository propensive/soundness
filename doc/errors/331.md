# `SN-331` — `OverflowError` (retired)

**This code is no longer raised.** `OverflowError` and `DivisionError` were two
names for one concept — an arithmetic operation with no representable result — and
are now `Arithmetic.Error`, whose `Overflow` reason is `SN-868.2`.

It was raised when a numeric operation would exceed the representable
range of its result type.

## Cause

Hypotenuse's checked arithmetic raises this error rather than
silently wrapping when an addition, subtraction, multiplication,
or shift would overflow.

## Example message

```
[↯SN-331] an overflow error occurred
```

## Resolution

Use a wider numeric type for the result, or restructure the
computation to avoid intermediate overflow.
