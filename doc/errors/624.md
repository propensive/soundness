# `SN-624` — `Json.Provider.Error`

Raised when a JSON value does not satisfy the schema it is being
validated against.

## Cause

Jacinta's `Json.Provider` validates JSON values against a schema as a record's fields are read,
and reports each mismatch via this error, through the `Tactic` of the code reading the field, so
that a validating reader can collect them all. The message is `the
JSON was not valid according to the schema because $reason`.

## Variants
```tabular

row  `SN-624.1`  `JsonType`  The value's type does not match what the schema requires.  `[↯SN-624.1] the JSON was not valid according to the schema because expected JSON type number, but found string`  Provide a value of the type the schema requires, or relax the schema if the type is genuinely flexible.
row  `SN-624.2`  `MissingValue`  A required value is absent from the JSON. The reason names the missing field where it is known.  `[↯SN-624.2] the JSON was not valid according to the schema because the value of locality was missing`  Add the missing field, or mark it optional in the schema.
row  `SN-624.3`  `IntOutOfRange`  An integer value falls outside the `minimum`/`maximum` allowed by the schema. Raised by the `"integer!"` provider type; an absent bound is `Unset` rather than a sentinel.  `[↯SN-624.3] the JSON was not valid according to the schema because the value was not between 1 and 99`  Constrain the value to the schema's permitted range.
row  `SN-624.4`  `PatternMismatch`  A string value does not match the regular expression in the schema's `pattern`.  `[↯SN-624.4] the JSON was not valid according to the schema because the value did not conform to the regular expression [a-z]+`  Adjust the value to match the schema's pattern, or loosen the pattern.
row  `SN-624.5`  `NumberOutOfRange`  A number falls outside the `minimum`/`maximum` (or exclusive bounds) the schema declares. Raised by the `"number!"` provider type.  `[↯SN-624.5] the JSON was not valid according to the schema because the number was not between -90.0 and 90.0`  Constrain the value to the schema's permitted range.
row  `SN-624.6`  `LengthOutOfRange`  A string's length falls outside the schema's `minLength`/`maxLength`. Raised by the `"string!"` provider type.  `[↯SN-624.6] the JSON was not valid according to the schema because the string's length was not between 1 and 214`  Shorten or lengthen the value to fit the schema.
row  `SN-624.7`  `NotPermitted`  A string is not one of the schema's `enum` values (or its `const`). Raised by the `"enum"` provider type.  `[↯SN-624.7] the JSON was not valid according to the schema because the value Polygon was not one of Point`  Use one of the listed values, or extend the schema's `enum`.
row  `SN-624.8`  `UnexpectedKind`  A value is of a JSON kind which none of the alternatives of its union (`anyOf`, `oneOf`, or a `type` naming several) accepts.  `[↯SN-624.8] the JSON was not valid according to the schema because the value was a JSON boolean, which is not one of string, number`  Give a value of one of the kinds the schema lists.
row  `SN-624.9`  `Unparsable`  A string's text is not valid for its `format`: a `json-pointer` or a `regex` which does not parse.  `[↯SN-624.9] the JSON was not valid according to the schema because the value a[ is not a valid regex`  Correct the value so that it parses in its format.
```
