# `SN-624` — `Json.Provider.Error`

Raised when a JSON value does not satisfy the schema it is being
validated against.

## Cause

Jacinta's `Json.Provider` validates JSON values against a schema as a record's fields are read,
and reports the first mismatch via this error. The message is `the
JSON was not valid according to the schema because $reason`.

## Variants

### `SN-624.1` — `JsonType`

The value's type does not match what the schema requires.

**Example.** `[↯SN-624.1] the JSON was not valid according to the schema because expected JSON type number, but found string`

**Resolution.** Provide a value of the type the schema requires, or
relax the schema if the type is genuinely flexible.

### `SN-624.2` — `MissingValue`

A required value is absent from the JSON.

**Example.** `[↯SN-624.2] the JSON was not valid according to the schema because the value was missing`

**Resolution.** Add the missing field, or mark it optional in the
schema.

### `SN-624.3` — `IntOutOfRange`

An integer value falls outside the `minimum`/`maximum` allowed by
the schema. Raised by the `"integer!"` provider type; an absent
bound is `Unset` rather than a sentinel.

**Example.** `[↯SN-624.3] the JSON was not valid according to the schema because the value was not between 1 and 99`

**Resolution.** Constrain the value to the schema's permitted range.

### `SN-624.4` — `PatternMismatch`

A string value does not match the regular expression in the schema's
`pattern`.

**Example.** `[↯SN-624.4] the JSON was not valid according to the schema because the value did not conform to the regular expression [a-z]+`

**Resolution.** Adjust the value to match the schema's pattern, or
loosen the pattern.

### `SN-624.5` — `NumberOutOfRange`

A number falls outside the `minimum`/`maximum` (or exclusive bounds) the schema declares.
Raised by the `"number!"` provider type.

**Example.** `[↯SN-624.5] the JSON was not valid according to the schema because the number was not between -90.0 and 90.0`

**Resolution.** Constrain the value to the schema's permitted range.

### `SN-624.6` — `LengthOutOfRange`

A string's length falls outside the schema's `minLength`/`maxLength`. Raised by the
`"string!"` provider type.

**Example.** `[↯SN-624.6] the JSON was not valid according to the schema because the string's length was not between 1 and 214`

**Resolution.** Shorten or lengthen the value to fit the schema.

### `SN-624.7` — `NotPermitted`

A string is not one of the schema's `enum` values (or its `const`). Raised by the `"enum"`
provider type.

**Example.** `[↯SN-624.7] the JSON was not valid according to the schema because the value Polygon was not one of Point`

**Resolution.** Use one of the listed values, or extend the schema's `enum`.
