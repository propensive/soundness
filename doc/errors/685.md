# `SN-685` — `Git.Error`

Raised when a Git operation invoked through Octogenarian fails. Each variant
names the specific condition git reported, or that Octogenarian itself
detected; the error's `detail` field carries git's own message when the
command-line backend has one.

## Cause

A backend (the command-line one, or the native one) could not complete the
operation. The message is the fixed prefix followed by the `Reason` variant:
`the Git operation could not be completed because $reason`.

Several variants are the typed outcome of a compare-and-swap: every operation
that moves a ref takes the `Stale` value it is conditional on and fails with
`Moved` if the ref no longer holds it, which is the only defence against another
process writing the same repository.

```tabular

column  Resolution
row  `SN-685.1`  `CannotExecuteGit`  The `git` command itself could not be executed: no `git` binary was found on the search path, or it could not be started.  `` [↯SN-685.1] the Git operation could not be completed because the `git` command could not be executed ``  Install Git, or supply `Commandline.Command` with the path of the binary.
row  `SN-685.2`  `NoRepository`  The path opened as a repository is not one: neither a bare repository, a `.git/` directory, a working tree containing one, nor a linked worktree's `<worktree>/.git` file.  `[↯SN-685.2] the Git operation could not be completed because /tmp/x is not a Git repository`  Open a path that `git rev-parse --git-dir` would accept, or initialize one with `Git.init`.
row  `SN-685.3`  `NoWorktree`  A bare repository was opened as a `Git.Worktree`, which needs an index and working files.  `[↯SN-685.3] the Git operation could not be completed because the repository has no working tree`  Open it as a `Git.Repo` instead, or open a linked worktree of it.
row  `SN-685.4`  `Moved`  A compare-and-swap failed: the ref held a different value from the `Stale` one the operation was conditional on. Another process moved it between the read and the write.  `[↯SN-685.4] the Git operation could not be completed because refs/heads/main was 3f2a… when read but is now 9c1d…`  Read the ref again, decide whether the operation still applies, and retry with the fresh value.
row  `SN-685.5`  `NoSuchRef`  A revision or reference named in the operation does not exist.  `[↯SN-685.5] the Git operation could not be completed because the reference refs/heads/feature does not exist`  Check the name; `resolve` returns `Unset` rather than raising for a probe.
row  `SN-685.6`  `NoSuchObject`  No object with the given hash is in the object database, or it is not of the kind requested.  `[↯SN-685.6] the Git operation could not be completed because the object 5c1d… does not exist`  Fetch the object, or check the hash.
row  `SN-685.7`  `RefExists`  A ref was to be created, but one of that name already exists.  `[↯SN-685.7] the Git operation could not be completed because the reference refs/tags/v1 already exists`  Choose another name, or delete the existing ref first.
row  `SN-685.8`  `Unmerged`  A branch was to be deleted without `force`, but its tip is not reachable from HEAD, so the deletion would lose commits.  `[↯SN-685.8] the Git operation could not be completed because the branch feature at 3f2a… is not fully merged`  Merge the branch first, or delete it with `force = true`.
row  `SN-685.9`  `Conflict`  An operation which cannot stop for conflicts (a fast-forward-only pull, a stash pop that must apply cleanly) met conflicting changes.  `[↯SN-685.9] the Git operation could not be completed because there are conflicts in a, b`  Resolve the conflicts through an operation that can stop, such as `merge`, which reports them as a `Stopped` outcome.
row  `SN-685.10`  `NothingToCommit`  A commit was requested whose tree is identical to its parent's, and empty commits were not allowed.  `[↯SN-685.10] the Git operation could not be completed because there is nothing to commit`  Stage a change, or pass `allowEmpty = true`.
row  `SN-685.11`  `Detached`  The operation needs HEAD to be on a branch, and it is detached.  `[↯SN-685.11] the Git operation could not be completed because HEAD is detached`  Switch to a branch first.
row  `SN-685.12`  `Dirty`  Local changes to the listed files would be overwritten by the operation.  `[↯SN-685.12] the Git operation could not be completed because local changes would be overwritten in a, b`  Commit, stash or restore the files first.
row  `SN-685.13`  `NotFastForward`  A fast-forward was required (by `FastForward.Only`, or by a remote refusing a non-fast-forward push) and the histories have diverged.  `[↯SN-685.13] the Git operation could not be completed because the update is not a fast-forward`  Merge or rebase first, or force the update if that is what is meant.
row  `SN-685.14`  `OutsideWorktree`  A path given to a working-tree operation lies outside the working tree.  `[↯SN-685.14] the Git operation could not be completed because /etc/passwd is outside the working tree`  Use a path formed from the worktree handle.
row  `SN-685.15`  `Untracked`  A path given to an operation on tracked files is not tracked.  `[↯SN-685.15] the Git operation could not be completed because loose is not tracked`  Add the file first, or use an operation for untracked files such as `clean`.
row  `SN-685.16`  `NoOperationInProgress`  `continue`, `skip`, `abandon` or `quit` was called with no merge, rebase, cherry-pick or revert in progress.  `[↯SN-685.16] the Git operation could not be completed because no merge, rebase, cherry-pick or revert is in progress`  Check `operation()` before continuing.
row  `SN-685.17`  `OperationInProgress`  A new operation was started while a merge, rebase, cherry-pick or revert was still stopped.  `[↯SN-685.17] the Git operation could not be completed because an operation is already in progress`  Continue or abandon the operation in progress first.
row  `SN-685.18`  `NoSuchRemote`  The named remote is not configured.  `[↯SN-685.18] the Git operation could not be completed because the remote origin does not exist`  Add it with `addRemote`.
row  `SN-685.19`  `RemoteExists`  A remote was to be added under a name already in use.  `[↯SN-685.19] the Git operation could not be completed because the remote origin already exists`  Choose another name, or use `setRemoteUrl`.
row  `SN-685.20`  `Unauthorized`  The remote refused the credentials offered, or asked for some and none were available.  `[↯SN-685.20] the Git operation could not be completed because authentication with origin failed`  Configure credentials for the remote.
row  `SN-685.21`  `Unreachable`  The remote could not be reached: its host did not resolve, or refused or timed out the connection.  `[↯SN-685.21] the Git operation could not be completed because the remote origin could not be reached`  Check the URL and the network.
row  `SN-685.22`  `RemoteRejected`  The remote accepted the connection but refused to update the ref, for the reason it gave.  `[↯SN-685.22] the Git operation could not be completed because the remote rejected refs/heads/main: pre-receive hook declined`  Read the reason; it is the remote's policy.
row  `SN-685.23`  `LeaseFailed`  A push with `Push.Force.Lease` found the remote's ref at a different value from the one expected.  `[↯SN-685.23] the Git operation could not be completed because the remote's refs/heads/main was expected to be 3f2a… but is 9c1d…`  Fetch, reconsider, and push with a fresh expectation.
row  `SN-685.24`  `NoteNotFound`  `content` was called on a note reference, and no note is attached to the commit in that namespace.  `[↯SN-685.24] the Git operation could not be completed because no note was attached to the given object`  Use `note`, which returns `Unset` rather than raising.
row  `SN-685.25`  `NoSuchConfig`  A configuration key the operation needs is not set anywhere git would look; typically `user.name` or `user.email` for a commit.  `[↯SN-685.25] the Git operation could not be completed because the configuration key user.email is not set`  Set it with `configure`, or in the global configuration.
row  `SN-685.26`  `InvalidConfig`  A configuration key or value is malformed: a key with no section, say.  `[↯SN-685.26] the Git operation could not be completed because nosection is not a valid value for `  Use a `section.name` or `section.subsection.name` key.
row  `SN-685.27`  `BadSignature`  A signature on a commit or tag did not verify.  `[↯SN-685.27] the Git operation could not be completed because the signature could not be verified: …`  Check the signer's key is trusted, and that the object has not been altered.
row  `SN-685.28`  `SigningFailed`  The signer could not produce a signature.  `[↯SN-685.28] the Git operation could not be completed because the object could not be signed: …`  Check the signing key and the signing program.
row  `SN-685.29`  `Unsupported`  The backend in use does not implement the operation.  `[↯SN-685.29] the Git operation could not be completed because skipping is not supported by this backend`  Use the other backend, or a different operation.
row  `SN-685.30`  `Unexpected`  git failed in a way the reason table does not recognise; the error's `detail` carries git's own message.  `[↯SN-685.30] the Git operation could not be completed because git reported an unexpected failure`  Read the `detail`.
row  `SN-685.31`  `NoteExists`  A note was to be added to a commit which already has one in that namespace, without `force`.  `[↯SN-685.31] the Git operation could not be completed because a note is already attached to 5c1d…`  Pass `force = true` to replace it, or use `appendNote`.
row  `SN-685.32`  `NoSuchWorktree`  The path given is not a linked working tree of the repository.  `[↯SN-685.32] the Git operation could not be completed because /tmp/x is not a linked working tree`  List the worktrees with `worktrees()`.
row  `SN-685.33`  `NoSuchStash`  The stash entry no longer exists: it was popped or dropped since it was listed.  `[↯SN-685.33] the Git operation could not be completed because the stash entry does not exist`  List the stashes again.
row  `SN-685.34`  `Locked`  A lock file (`<ref>.lock`, `index.lock` or `config.lock`) exists: another process is writing the same ref, index or configuration file, or crashed and left the lock behind.  `[↯SN-685.34] the Git operation could not be completed because the lock file for refs/heads/main is held by another process`  Retry once the other process has finished; if no process holds it, remove the stale lock file by hand.
```
