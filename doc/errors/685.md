# `SN-685` — `Git.Error`

Raised when a Git operation invoked through Octogenarian fails. Each variant
names the specific condition git reported, or that Octogenarian itself
detected; the error's `detail` field carries git's own message when the
command-line backend has one.

## Cause

A backend (the command-line one, or the native one) could not complete the
operation. The message is the fixed prefix followed by the `Reason` variant:
`the Git operation could not be completed because $reason`.

Several variants are the typed outcome of a compare-and-swap: every operation
that moves a ref takes the `Stale` value it is conditional on and fails with
`Moved` if the ref no longer holds it, which is the only defence against another
process writing the same repository.

## Variants

### `SN-685.1` — `CannotExecuteGit`

The `git` command itself could not be executed: no `git` binary was found on the search path, or it could not be started.

**Example.** `[↯SN-685.1] the Git operation could not be completed because the `git` command could not be executed`

**Resolution.** Install Git, or supply `Commandline.Command` with the path of the binary.

### `SN-685.2` — `NoRepository`

The path opened as a repository is not one: neither a bare repository, a `.git` directory, a working tree containing one, nor a linked worktree's `.git` file.

**Example.** `[↯SN-685.2] the Git operation could not be completed because /tmp/x is not a Git repository`

**Resolution.** Open a path that `git rev-parse --git-dir` would accept, or initialize one with `Git.init`.

### `SN-685.3` — `NoWorktree`

A bare repository was opened as a `Git.Worktree`, which needs an index and working files.

**Example.** `[↯SN-685.3] the Git operation could not be completed because the repository has no working tree`

**Resolution.** Open it as a `Git.Repo` instead, or open a linked worktree of it.

### `SN-685.4` — `Moved`

A compare-and-swap failed: the ref held a different value from the `Stale` one the operation was conditional on. Another process moved it between the read and the write.

**Example.** `[↯SN-685.4] the Git operation could not be completed because refs/heads/main was 3f2a… when read but is now 9c1d…`

**Resolution.** Read the ref again, decide whether the operation still applies, and retry with the fresh value.

### `SN-685.5` — `NoSuchRef`

A revision or reference named in the operation does not exist.

**Example.** `[↯SN-685.5] the Git operation could not be completed because the reference refs/heads/feature does not exist`

**Resolution.** Check the name; `resolve` returns `Unset` rather than raising for a probe.

### `SN-685.6` — `NoSuchObject`

No object with the given hash is in the object database, or it is not of the kind requested.

**Example.** `[↯SN-685.6] the Git operation could not be completed because the object 5c1d… does not exist`

**Resolution.** Fetch the object, or check the hash.

### `SN-685.7` — `RefExists`

A ref was to be created, but one of that name already exists.

**Example.** `[↯SN-685.7] the Git operation could not be completed because the reference refs/tags/v1 already exists`

**Resolution.** Choose another name, or delete the existing ref first.

### `SN-685.8` — `Unmerged`

A branch was to be deleted without `force`, but its tip is not reachable from HEAD, so the deletion would lose commits.

**Example.** `[↯SN-685.8] the Git operation could not be completed because the branch feature at 3f2a… is not fully merged`

**Resolution.** Merge the branch first, or delete it with `force = true`.

### `SN-685.9` — `Conflict`

An operation which cannot stop for conflicts (a fast-forward-only pull, a stash pop that must apply cleanly) met conflicting changes.

**Example.** `[↯SN-685.9] the Git operation could not be completed because there are conflicts in a, b`

**Resolution.** Resolve the conflicts through an operation that can stop, such as `merge`, which reports them as a `Stopped` outcome.

### `SN-685.10` — `NothingToCommit`

A commit was requested whose tree is identical to its parent's, and empty commits were not allowed.

**Example.** `[↯SN-685.10] the Git operation could not be completed because there is nothing to commit`

**Resolution.** Stage a change, or pass `allowEmpty = true`.

### `SN-685.11` — `Detached`

The operation needs HEAD to be on a branch, and it is detached.

**Example.** `[↯SN-685.11] the Git operation could not be completed because HEAD is detached`

**Resolution.** Switch to a branch first.

### `SN-685.12` — `Dirty`

Local changes to the listed files would be overwritten by the operation.

**Example.** `[↯SN-685.12] the Git operation could not be completed because local changes would be overwritten in a, b`

**Resolution.** Commit, stash or restore the files first.

### `SN-685.13` — `NotFastForward`

A fast-forward was required (by `FastForward.Only`, or by a remote refusing a non-fast-forward push) and the histories have diverged.

**Example.** `[↯SN-685.13] the Git operation could not be completed because the update is not a fast-forward`

**Resolution.** Merge or rebase first, or force the update if that is what is meant.

### `SN-685.14` — `OutsideWorktree`

A path given to a working-tree operation lies outside the working tree.

**Example.** `[↯SN-685.14] the Git operation could not be completed because /etc/passwd is outside the working tree`

**Resolution.** Use a path formed from the worktree handle.

### `SN-685.15` — `Untracked`

A path given to an operation on tracked files is not tracked.

**Example.** `[↯SN-685.15] the Git operation could not be completed because loose is not tracked`

**Resolution.** Add the file first, or use an operation for untracked files such as `clean`.

### `SN-685.16` — `NoOperationInProgress`

`continue`, `skip`, `abandon` or `quit` was called with no merge, rebase, cherry-pick or revert in progress.

**Example.** `[↯SN-685.16] the Git operation could not be completed because no merge, rebase, cherry-pick or revert is in progress`

**Resolution.** Check `operation()` before continuing.

### `SN-685.17` — `OperationInProgress`

A new operation was started while a merge, rebase, cherry-pick or revert was still stopped.

**Example.** `[↯SN-685.17] the Git operation could not be completed because an operation is already in progress`

**Resolution.** Continue or abandon the operation in progress first.

### `SN-685.18` — `NoSuchRemote`

The named remote is not configured.

**Example.** `[↯SN-685.18] the Git operation could not be completed because the remote origin does not exist`

**Resolution.** Add it with `addRemote`.

### `SN-685.19` — `RemoteExists`

A remote was to be added under a name already in use.

**Example.** `[↯SN-685.19] the Git operation could not be completed because the remote origin already exists`

**Resolution.** Choose another name, or use `setRemoteUrl`.

### `SN-685.20` — `Unauthorized`

The remote refused the credentials offered, or asked for some and none were available.

**Example.** `[↯SN-685.20] the Git operation could not be completed because authentication with origin failed`

**Resolution.** Configure credentials for the remote.

### `SN-685.21` — `Unreachable`

The remote could not be reached: its host did not resolve, or refused or timed out the connection.

**Example.** `[↯SN-685.21] the Git operation could not be completed because the remote origin could not be reached`

**Resolution.** Check the URL and the network.

### `SN-685.22` — `RemoteRejected`

The remote accepted the connection but refused to update the ref, for the reason it gave.

**Example.** `[↯SN-685.22] the Git operation could not be completed because the remote rejected refs/heads/main: pre-receive hook declined`

**Resolution.** Read the reason; it is the remote's policy.

### `SN-685.23` — `LeaseFailed`

A push with `Push.Force.Lease` found the remote's ref at a different value from the one expected.

**Example.** `[↯SN-685.23] the Git operation could not be completed because the remote's refs/heads/main was expected to be 3f2a… but is 9c1d…`

**Resolution.** Fetch, reconsider, and push with a fresh expectation.

### `SN-685.24` — `NoteNotFound`

`content` was called on a note reference, and no note is attached to the commit in that namespace.

**Example.** `[↯SN-685.24] the Git operation could not be completed because no note was attached to the given object`

**Resolution.** Use `note`, which returns `Unset` rather than raising.

### `SN-685.25` — `NoSuchConfig`

A configuration key the operation needs is not set anywhere git would look; typically `user.name` or `user.email` for a commit.

**Example.** `[↯SN-685.25] the Git operation could not be completed because the configuration key user.email is not set`

**Resolution.** Set it with `configure`, or in the global configuration.

### `SN-685.26` — `InvalidConfig`

A configuration key or value is malformed: a key with no section, say.

**Example.** `[↯SN-685.26] the Git operation could not be completed because nosection is not a valid value for `

**Resolution.** Use a `section.name` or `section.subsection.name` key.

### `SN-685.27` — `BadSignature`

A signature on a commit or tag did not verify.

**Example.** `[↯SN-685.27] the Git operation could not be completed because the signature could not be verified: …`

**Resolution.** Check the signer's key is trusted, and that the object has not been altered.

### `SN-685.28` — `SigningFailed`

The signer could not produce a signature.

**Example.** `[↯SN-685.28] the Git operation could not be completed because the object could not be signed: …`

**Resolution.** Check the signing key and the signing program.

### `SN-685.29` — `Unsupported`

The backend in use does not implement the operation.

**Example.** `[↯SN-685.29] the Git operation could not be completed because skipping is not supported by this backend`

**Resolution.** Use the other backend, or a different operation.

### `SN-685.30` — `Unexpected`

git failed in a way the reason table does not recognise; the error's `detail` carries git's own message.

**Example.** `[↯SN-685.30] the Git operation could not be completed because git reported an unexpected failure`

**Resolution.** Read the `detail`.

### `SN-685.31` — `NoteExists`

A note was to be added to a commit which already has one in that namespace, without `force`.

**Example.** `[↯SN-685.31] the Git operation could not be completed because a note is already attached to 5c1d…`

**Resolution.** Pass `force = true` to replace it, or use `appendNote`.

### `SN-685.32` — `NoSuchWorktree`

The path given is not a linked working tree of the repository.

**Example.** `[↯SN-685.32] the Git operation could not be completed because /tmp/x is not a linked working tree`

**Resolution.** List the worktrees with `worktrees()`.

### `SN-685.33` — `NoSuchStash`

The stash entry no longer exists: it was popped or dropped since it was listed.

**Example.** `[↯SN-685.33] the Git operation could not be completed because the stash entry does not exist`

**Resolution.** List the stashes again.
