# `↯/s.128.4` — `Xml.Provider.Error`

Raised when an XML value does not conform to the XML Schema an `Xml.Provider` reads it by.

## Cause

Xylophone's `Xml.Provider` checks a document against its schema as a record's fields are read,
and reports each mismatch through the `Tactic` of the code reading the field, so that a
validating reader can collect them all. The message is `the XML did not conform to its schema because
$reason`.

## Variants
```tabular
column  Code
column  Reason
column  Meaning
column  Message
column  Resolution
row  `↯/s.128.4.1`  `OutOfRange`  A number falls outside the bounds of its type: a `minInclusive`, `maxInclusive`, `minExclusive` or `maxExclusive` facet, or the bounds a builtin such as `xs:positiveInteger` implies. An absent bound is `Unset`.  `[↯/s.128.4.1] the XML did not conform to its schema because the value 200 is outside the range 0 to 150`  Supply a value within the range, or relax the facet.
row  `↯/s.128.4.2`  `LengthOutOfRange`  A value's length violates a `length`, `minLength` or `maxLength` facet.  `[↯/s.128.4.2] the XML did not conform to its schema because the length of abcd is outside the range 3 to 3`  Supply a value of a permitted length.
row  `↯/s.128.4.3`  `PatternMismatch`  A value does not match a `pattern` facet.  `[↯/s.128.4.3] the XML did not conform to its schema because the value nope does not match the pattern \d{3}-[A-Z]{2}`  Supply a value matching the pattern.
row  `↯/s.128.4.4`  `NotPermitted`  A value is not among an `enumeration` facet's values.  `[↯/s.128.4.4] the XML did not conform to its schema because the value urgent is not one of low, normal, high`  Supply one of the permitted values.
row  `↯/s.128.4.5`  `TooManyDigits`  A decimal has more digits than a `totalDigits` or `fractionDigits` facet allows.  `[↯/s.128.4.5] the XML did not conform to its schema because the value 1.234 has more digits than the 5 total or 2 fraction digits permitted`  Round or truncate the value to the permitted digits.
row  `↯/s.128.4.6`  `Absent`  A required element or attribute — one with `minOccurs` of at least one, or `use="required"` — is missing, or the element it names is in the wrong namespace.  `[↯/s.128.4.6] the XML did not conform to its schema because the element or attribute city is required`  Add the element or attribute, in the namespace the schema expects.
row  `↯/s.128.4.7`  `Malformed`  A value's text cannot be read as its type — `xs:int` text which is not a number, say — or the element has no text to read.  `[↯/s.128.4.7] the XML did not conform to its schema because the text none is not a valid Double`  Give the element or attribute text of the type the schema declares.
```
