# `↯/s.123.2` — `Git.RefError`

Raised when a value is not a valid Git reference name.

## Cause

Octogenarian validates reference names against `git
check-ref-format`'s rules. The constructor records the offending
`value` and a `reason: Reason`; the rendered message is `$value
is not a valid Git reference because $reason`.

```tabular
row  `↯/s.123.2.5`  `EmptySegment`  The name contains an empty path segment — typically a leading, trailing, or doubled `/`.  `[↯/s.123.2.5] verona//capulet is not a valid Git reference because the name contains an empty path segment`  Remove the empty segment.
row  `↯/s.123.2.6`  `InvalidCharacter`  The name contains a character Git forbids in references: any of `*`, `[`, `\`, ` `, `^`, `~`, `:`, or `?`.  `[↯/s.123.2.6] verona capulet is not a valid Git reference because the name contains a character forbidden by Git`  Replace the forbidden character with `-` or `_`.
row  `↯/s.123.2.7`  `BadHash`  The value passed to `Git.Hash` was not a 40-character lowercase hexadecimal string.  `[↯/s.123.2.7] abc is not a valid Git reference because the value is not a 40-character hexadecimal hash`  Provide the full 40-character SHA-1 commit hash.
row  `↯/s.123.2.8`  `BadRefspec`  The value passed to `Git.Refspec.parse` was not a refspec: it had more than one `:` separating source and destination.  `[↯/s.123.2.8] a:b:c is not a valid Git reference because the value is not a valid refspec`  Write the refspec as `source`, `source:destination` or `:destination`, with an optional leading `+`.
```
