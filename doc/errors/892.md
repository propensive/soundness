# `SN-892` — `HostnameError`

Raised when a value cannot be parsed as a valid DNS hostname.

## Cause

Urticose validates hostnames per the DNS rules: total length ≤ 253,
each label ≤ 63 characters, only `A`-`Z`, `a`-`z`, `0`-`9`, and `-`
allowed (and `-` not at the start of a label). The message is `the
hostname is not valid because $reason`.

## Variants

### `SN-892.1` — `LongDnsLabel`

A single DNS label is longer than 63 characters.

**Example.** `[↯SN-892.1] the hostname is not valid because the DNS label foobarbaz... is longer than 63 characters`

**Resolution.** Shorten the offending label.

### `SN-892.2` — `LongHostname`

The hostname as a whole exceeds 253 characters.

**Example.** `[↯SN-892.2] the hostname is not valid because the hostname is longer than 253 characters`

**Resolution.** Use a shorter fully-qualified domain name.

### `SN-892.3` — `InvalidChar`

A character that is not permitted in a DNS hostname appears.

**Example.** `[↯SN-892.3] the hostname is not valid because the character _ is not allowed in a hostname`

**Resolution.** Remove or replace the offending character.

### `SN-892.4` — `EmptyDnsLabel`

A label is empty — typically caused by `..` in the input or a leading
or trailing dot.

**Example.** `[↯SN-892.4] the hostname is not valid because a DNS label cannot be empty`

**Resolution.** Remove the empty label.

### `SN-892.5` — `InitialDash`

A label starts with `-`, which DNS does not allow.

**Example.** `[↯SN-892.5] the hostname is not valid because the DNS label -foo begins with a dash which is not allowed`

**Resolution.** Remove or relocate the leading dash.
