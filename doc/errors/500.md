# `SN-500` — `Motif.Error`

Raised when Praxinoscope cannot compile a regular expression to its RE2
form, or when an analysis over compiled expressions cannot complete.
Each variant pinpoints the problem.

## Cause

Praxinoscope parses the RE2 regular-expression syntax: a strict subset
of common regex syntax which excludes every construct that would break
the linear-time matching guarantee. When the parser cannot accept the
input, it raises a `Motif.Error` carrying the character `index` at
which the problem was detected and a `Reason` explaining what was
wrong. The constructed message is `the regular expression could not be
compiled because $reason at $index`. Two further variants
(`BudgetExceeded` and `Unverifiable`) arise not from parsing but from
the containment analysis (`subsumes`/`intersects`), whose worst case
is exponential and therefore budgeted.

## Variants

### `SN-500.1` — `UnclosedGroup`

A group was opened with `(` but never closed with `)`.

**Resolution.** Add the missing `)`, or escape the `(` if a literal
parenthesis is intended.

### `SN-500.2` — `NotInGroup`

A `)` was encountered with no corresponding `(`.

**Resolution.** Add the missing `(`, escape the `)` if it should be
literal, or remove the stray closing parenthesis.

### `SN-500.3` — `UnexpectedChar`

A character was found which does not belong at this position, such as
a quantifier with nothing to repeat, or a stray character in a
repetition range.

**Resolution.** Review the pattern around the reported index.

### `SN-500.4` — `BadRepetition`

A repetition range `{n,m}` has `m < n`.

**Resolution.** Swap the bounds, or use `{n,}` if no upper bound is
needed.

### `SN-500.5` — `IncompleteRepetition`

A repetition range was opened with `{` but never closed with `}`.

**Resolution.** Add the missing `}`.

### `SN-500.6` — `EmptyCharClass`

A character class `[…]` contained no characters.

**Resolution.** Add at least one character to the class, or remove
the empty `[]`.

### `SN-500.7` — `UnclosedClass`

A character class was opened with `[` but never closed with `]`.

**Resolution.** Add the missing `]`, or escape the `[` if a literal
bracket is intended.

### `SN-500.8` — `UnclosedEscape`

The pattern ends with a `\` that has nothing to escape.

**Resolution.** Either remove the trailing backslash or escape the
character that should follow it.

### `SN-500.9` — `InvalidEscape`

An escape sequence has no assigned meaning in RE2 syntax, such as an
escaped alphanumeric character with no special interpretation, a
malformed `\x` hexadecimal escape, or a Unicode property escape
(`\p{…}`), which is not yet supported.

**Resolution.** Remove the backslash if the character was meant
literally, or correct the escape sequence.

### `SN-500.10` — `InvertedRange`

A character-class range `[a-b]` has an end lower than its start.

**Resolution.** Swap the ends of the range.

### `SN-500.11` — `Backreference`

The pattern contains a backreference (`\1`…`\9` or `\k<…>`).
Backreferences make matching NP-hard, so RE2 syntax excludes them by
design.

**Resolution.** Restructure the pattern without backreferences, or
use the JVM regex backend, which supports them.

### `SN-500.12` — `Lookaround`

The pattern contains lookahead (`(?=…)`, `(?!…)`) or lookbehind
(`(?<=…)`, `(?<!…)`), which RE2 syntax excludes by design.

**Resolution.** Restructure the pattern, or use the JVM regex
backend, which supports lookaround.

### `SN-500.13` — `PossessiveQuantifier`

The pattern contains a possessive quantifier (`*+`, `++`, `?+` or
`{n,m}+`). Possessive matching is a backtracking-control device, and
RE2's matching never backtracks, so the construct is meaningless
here.

**Resolution.** Use the plain greedy quantifier.

### `SN-500.14` — `AtomicGroup`

The pattern contains an atomic group (`(?>…)`), which, like
possessive quantifiers, controls backtracking and has no meaning in
RE2 matching.

**Resolution.** Use a plain group.

### `SN-500.15` — `UnsupportedGroup`

The pattern uses a group syntax which is not supported, such as a
named group (`(?<name>…)` or `(?P<name>…)`).

**Resolution.** Use a plain capturing group.

### `SN-500.16` — `Flag`

The pattern contains inline flags (`(?i)`, `(?m)`, `(?s)`, …), which
are not yet supported.

**Resolution.** Express the intent directly in the pattern, for
example `[Aa]` in place of a case-insensitivity flag.

### `SN-500.17` — `RepetitionTooLarge`

A repetition bound in `{n,m}` exceeds 1000, the same limit RE2
imposes, since bounded repetitions are compiled by expansion.

**Resolution.** Use an unbounded quantifier, or restructure the
pattern.

### `SN-500.18` — `BudgetExceeded`

A containment analysis (`subsumes` or `intersects`) explored more
states than its budget allows. Containment of regular languages is
decidable but worst-case exponential.

The budget covers the product of every program being explored, so the
`subsumes` form taking a list of candidates — which decides
`L(⋂candidates) ⊆ L(cover)` over the candidates' product automaton —
can exhaust it on patterns that would each be decided comfortably on
their own.

**Resolution.** Simplify one or both patterns, or reduce the number of
candidates in an intersection.

### `SN-500.19` — `Unverifiable`

A containment analysis was attempted on a pattern containing a
construct the analysis cannot model: a word boundary (`\b` or `\B`),
or a line anchor under the `m` flag, both of which depend on the
symbols surrounding a position rather than on the position alone.

**Resolution.** Remove the boundary from the patterns being compared.

### `SN-500.20` — `InvalidPosixClass`

A `[[:name:]]` character class named something outside the POSIX set
(`alnum`, `alpha`, `ascii`, `blank`, `cntrl`, `digit`, `graph`,
`lower`, `print`, `punct`, `space`, `upper`, `word`, `xdigit`).

**Resolution.** Correct the class name. Note that `[:name:]` outside a
surrounding character class is an ordinary class of those characters,
not a POSIX class.

### `SN-500.21` — `UnknownUnicodeClass`

A `\p{…}` or `\P{…}` escape named neither a Unicode general category
(`L`, `Lu`, `Nd`, …) nor a script (`Greek`, `Han`, …).

**Resolution.** Correct the class name. Script names are the Unicode
ones, spelled as RE2 spells them — `\p{Greek}`, not Java's
`\p{IsGreek}`.
