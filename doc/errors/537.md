# `SN-537` — `Pty.Error`

Raised when Yossarian encounters an ANSI escape code in a PTY stream
that it cannot handle. Each variant identifies the specific kind of
malformed escape.

## Cause

Yossarian decodes terminal escape sequences as it processes a PTY
stream. When a sequence is malformed or refers to a parameter outside
the supported range, parsing stops with this error. The message is
`an ANSI escape code could not be handled because $reason`.

## Variants
```tabular
column  Code
column  Reason
column  Meaning
column  Message
column  Resolution
row  `SN-537.1`  `BadSgrParameters`  An SGR (Select Graphic Rendition) parameter sequence is not valid.  `[↯SN-537.1] an ANSI escape code could not be handled because [38;9 is not a valid SGR parameter sequence`  Check the producer of the escape sequence: SGR parameters are semicolon-separated integers in the documented ranges.
row  `SN-537.2`  `BadCsiParameter`  A CSI command received a parameter outside the values it accepts.  `[↯SN-537.2] an ANSI escape code could not be handled because 99 is not a valid CSI parameter for the H command`  Constrain the parameter to the range allowed for that command.
row  `SN-537.3`  `NonintegerSgrParameter`  An SGR parameter that should be a number was not numeric.  `[↯SN-537.3] an ANSI escape code could not be handled because abc is not a numerical SGR parameter`  Emit only digit-only parameters between `;` separators in SGR sequences.
row  `SN-537.4`  `BadColor`  A 256-colour or palette parameter referenced a colour index outside the valid range.  `[↯SN-537.4] an ANSI escape code could not be handled because 300 is not a valid color number`  Use a colour index between 0 and 255 (or 0 and 15 for the basic palette).
row  `SN-537.5`  `BadOscParameter`  An OSC (Operating System Command) used a parameter that is not recognised.  `[↯SN-537.5] an ANSI escape code could not be handled because 999 is not a recognized OSC parameter`  Use an OSC parameter from the documented set.
row  `SN-537.6`  `BadCsiCommand`  The terminating character of a CSI sequence is not a recognised CSI command for the given parameters.  `[↯SN-537.6] an ANSI escape code could not be handled because Z (with parameter 1) is not a valid CSI command`  Use a documented CSI final byte for the parameter set in question.
row  `SN-537.7`  `BadCsiEscape`  A character appeared inside a CSI sequence that is not allowed there.  `[↯SN-537.7] an ANSI escape code could not be handled because @ is not valid in a CSI escape sequence`  CSI sequences allow only the documented intermediate and parameter bytes; review the producer.
row  `SN-537.8`  `BadFeEscape`  The character following `ESC` is not a valid Fe (C1) escape.  `[↯SN-537.8] an ANSI escape code could not be handled because Q is not a valid Fe escape`  Use a documented C1 introducer (`[`, `]`, `P`, etc.) after `ESC`.
```
