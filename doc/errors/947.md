# `SN-947` — `BoundsError` (retired)

**This code is no longer raised, and the type no longer exists.** `BoundsError`
duplicated `JsonBlueprint.Error`'s `IntOutOfRange` reason — the same failure, with
the same three fields, raised from the same object — so the `"integer!"` blueprint
now raises `SN-624.3` instead. It was declared in gossamer, which never used it.

It was raised when a numeric value fell outside a permitted range.

## Cause

Gossamer uses `BoundsError` to signal that a value is not within
its declared minimum/maximum bounds.

## Example message

```
[↯SN-947] the value 7.5 is not in the range 0.0-5.0
```

## Resolution

Constrain the value to the documented range, or relax the bounds
if the broader range is intentional.
