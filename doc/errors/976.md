# `SN-976` — `Git.RefError`

Raised when a value is not a valid Git reference name.

## Cause

Octogenarian validates reference names against `git
check-ref-format`'s rules. The constructor records the offending
`value` and a `reason: Reason`; the rendered message is `$value
is not a valid Git reference because $reason`.

## Variants
```tabular
column  Code
column  Reason
column  Meaning
column  Message
column  Resolution
row  `SN-976.1`  `LeadingOrTrailingDot`  A path segment of the reference starts or ends with `.`.  `[↯SN-976.1] .foo is not a valid Git reference because a path segment starts or ends with .`  Trim the leading or trailing dot from the segment.
row  `SN-976.2`  `ReservedSuffix`  A path segment matches `*.lock`, a pattern which Git reserves for lock files.  `[↯SN-976.2] feature.lock is not a valid Git reference because a path segment ends with the reserved suffix .lock`  Choose a name which does not match `*.lock`.
row  `SN-976.3`  `ReservedSequence`  The name contains `@{`, which Git reserves for reflog selectors (e.g. `HEAD@{1}`).  `[↯SN-976.3] foo@{bar} is not a valid Git reference because the name contains the reserved sequence @{`  Remove or replace the `@{` sequence.
row  `SN-976.4`  `DoubleDot`  The name contains `..`, which Git reserves for range selectors.  `[↯SN-976.4] foo..bar is not a valid Git reference because the name contains ..`  Replace the `..` with a single `.` or another separator.
row  `SN-976.5`  `EmptySegment`  The name contains an empty path segment — typically a leading, trailing, or doubled `/`.  `[↯SN-976.5] foo//bar is not a valid Git reference because the name contains an empty path segment`  Remove the empty segment.
row  `SN-976.6`  `InvalidCharacter`  The name contains a character Git forbids in references: any of `*`, `[`, `\`, ` `, `^`, `~`, `:`, or `?`.  `[↯SN-976.6] foo bar is not a valid Git reference because the name contains a character forbidden by Git`  Replace the forbidden character with `-` or `_`.
row  `SN-976.7`  `BadHash`  The value passed to `Git.Hash` was not a 40-character lowercase hexadecimal string.  `[↯SN-976.7] abc is not a valid Git reference because the value is not a 40-character hexadecimal hash`  Provide the full 40-character SHA-1 commit hash.
row  `SN-976.8`  `BadRefspec`  The value passed to `Git.Refspec.parse` was not a refspec: it had more than one `:` separating source and destination.  `[↯SN-976.8] a:b:c is not a valid Git reference because the value is not a valid refspec`  Write the refspec as `source`, `source:destination` or `:destination`, with an optional leading `+`.
```
