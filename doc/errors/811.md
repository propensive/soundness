# `SN-811` — Multi-line block bracket spacing (retired)

This error no longer exists. The page is kept so that the code is not reused, and so
that a reference to it from an older release can still be resolved.

## What became of it

The Decorum compiler plugin, which raised this error, was extracted from Soundness and
is now [Consequent](https://github.com/propensive/consequent), a standalone checker for
Consequent Style. The rule survives there under a new identifier, in which the letter
names the principle it derives from:
[`B4`](https://github.com/propensive/consequent/blob/main/doc/rules/B4.md).
