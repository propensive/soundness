# `SN-420` — `Geolocation.Error`

Raised when Geodesy cannot parse a value as a `geo:` URI.

## Cause

Geodesy parses RFC 5870 geo URIs of the form
`geo:<lat>,<lon>[,<alt>][;<param>=<value>]…`. If any part of the URI
fails to satisfy the syntax, this error is thrown with the variant
identifying which part. The message is `the geo URI is not in the
correct format because $reason`.

## Variants
```tabular
column  Code
column  Reason
column  Meaning
column  Message
column  Resolution
row  `SN-420.1`  `MissingEquals`  A parameter component had no `=` to separate name from value.  `` [↯SN-420.1] the geo URI is not in the correct format because the parameter does not contain an `=` ``  Write parameters as `name=value`.
row  `SN-420.2`  `MultipleEquals`  A single parameter contained more than one `=`.  `` [↯SN-420.2] the geo URI is not in the correct format because the parameter contains more than one `=` ``  Percent-encode `=` characters that should appear in the value.
row  `SN-420.3`  `BadScheme`  The URI did not start with `geo:`.  `` [↯SN-420.3] the geo URI is not in the correct format because the value does not begin with the `geo:` URI scheme ``  Prefix the URI with `geo:`.
row  `SN-420.4`  `ExpectedSemicolon`  After the altitude value, a `;` was expected but not found.  `` [↯SN-420.4] the geo URI is not in the correct format because a `;` was expected after the altitude value ``  Separate altitude from any subsequent parameters with `;`.
row  `SN-420.5`  `UnexpectedSuffix`  Content followed the coordinates that began with neither `,` nor `;`.  `` [↯SN-420.5] the geo URI is not in the correct format because a `,` or `;` was expected ``  Use `,` to introduce altitude and `;` to introduce parameters.
row  `SN-420.6`  `ExpectedCoordinates`  Latitude and longitude were missing or could not be parsed as numbers.  `[↯SN-420.6] the geo URI is not in the correct format because latitude and longitude coordinates were expected`  Provide two comma-separated decimal numbers immediately after `geo:`.
row  `SN-420.7`  `BadUncertainty`  The value of a `u=` (uncertainty) parameter was not a valid number.  `` [↯SN-420.7] the geo URI is not in the correct format because the `uncertainty` parameter vas not a valid number ``  Provide a non-negative decimal value for `u=`.
```
