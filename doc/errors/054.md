# `SN-054` — `Discovery.Error`

Raised when DNS-SD service discovery (`syndesis`) cannot advertise, browse or resolve, or when
a service, instance or TXT value is not valid.

## Cause

`Discovery.Service`, `Discovery.Instance` and `Discovery.Txt` validate their parts on
construction; an advertisement probes for its name and gives up after too many conflicts; a
resolution waits for the instance's records within a timeout; and a backend must be able to
start. The message is `service discovery failed because $reason`.

## Variants
```tabular
column  Code
column  Reason
column  Meaning
column  Message
column  Resolution
row  `SN-054.1`  `Conflict`  Another host kept claiming every name tried for an advertisement, through the renaming limit.  `[↯SN-054.1] service discovery failed because the name Hamlet._fury._tcp.local could not be claimed after repeated conflicts`  Choose a distinct instance name, or stop the other advertiser.
row  `SN-054.2`  `Timeout`  An instance's SRV, TXT or address records did not arrive within the resolution's timeout.  `[↯SN-054.2] service discovery failed because the instance Hamlet._fury._tcp.local did not resolve before the timeout`  The instance may have left the network; browse again, or lengthen the timeout.
row  `SN-054.3`  `InvalidName`  An instance label is empty, or a label or name exceeds the DNS limits (63 octets to a label, 255 to a name).  `[↯SN-054.3] service discovery failed because the name is not a valid DNS-SD name`  Shorten the label; it may contain any UTF-8, including dots and spaces.
row  `SN-054.4`  `InvalidTxt`  A TXT key is empty, not printable ASCII, or contains `=`; or a `key=value` pair exceeds 255 octets.  `[↯SN-054.4] service discovery failed because the TXT entry a=b is not valid`  Keys are short printable ASCII names; put the `=` in the value, and split long values across keys.
row  `SN-054.5`  `InvalidService`  A service name is empty, longer than fifteen characters, or begins with the underscore that the DNS form adds.  `[↯SN-054.5] service discovery failed because the service name _fury is not valid`  Give the registered service name without its underscore: `fury`, not `_fury`.
row  `SN-054.6`  `Unavailable`  The backend could not start: the socket responder found no multicast-capable interface, or could not join the mDNS group.  `[↯SN-054.6] service discovery failed because no service discovery backend could be started`  Check the host's network interfaces, and that port 5353 can be bound with reuse.
```
