# `↯/s.60.3` — `Structural.Error`

Raised when a record of fixed layout is read from fewer bytes than its layout needs.

## Cause

`unpack` checks the whole record against the bytes it is reading before it loads any field.
The error is raised when `width` bytes are not there at `offset`: the offset is negative, or
the record (or the repeated section of records) would run past the `size` of the data or
expanse.

## Example message

```
[↯/s.60.3] a record of 12 bytes cannot be read at offset 4 of 12 bytes
```

## Resolution

Check the offset against the format's specification, and that the input is complete. A file
which is shorter than its own headers claim is truncated or is not in the format expected.
