# `SN-900` — `Enumerable.Error`

Raised when a text is decoded as a value of a Scala enumeration but is not the name of any of its
values.

## Cause

`distillate.Decodable.enumeration` decodes a `reflect.Enum` by its (possibly relabelled) name.
The rendered message is `the specified variant ($inputLabel) is not one of the valid variants
($validVariants) of the enumeration $sum`.

**Example.** `[↯SN-900] the specified variant (blue) is not one of the valid variants (red,
green) of the enumeration Colour`

## Resolution

Use one of the listed names; if the wire form differs from the Scala name, relabel the value with
`@name` or an `Identifiable` instance.

Before this error existed, the same failure raised `wisteria.Variant.Error`.
