# `SN-751` — `Zip.Error`

Raised when a ZIP-archive operation cannot complete.

## Cause

Zeppelin manages ZIP entries by path. This error reports duplicate
or missing paths and invalid entry names. The message is `the ZIP
operation failed because $reason`.

## Variants
```tabular
column  Code
column  Reason
column  Meaning
column  Message
column  Resolution
row  `SN-751.1`  `DuplicateEntry`  An entry being added has the same path as one already in the archive.  `[↯SN-751.1] the ZIP operation failed because the path /hamlet/act1.txt is a duplicate entry`  Choose a different path, or remove the existing entry first.
row  `SN-751.2`  `NotFound`  An operation referenced an entry path that does not exist in the archive.  `[↯SN-751.2] the ZIP operation failed because path /hamlet/act1.txt was not found in the ZIP file`  List entries before reading; check for typos in the path.
row  `SN-751.3`  `InvalidName`  An entry name is not valid for a ZIP entry — for example contains characters disallowed by the format.  `[↯SN-751.3] the ZIP operation failed because the name hamlet\act1 is not valid for a ZIP entry`  Sanitise the name to a valid entry path.
row  `SN-751.4`  `UnsupportedMethod`  The entry is compressed with a method other than *stored* or *deflate*.  `[↯SN-751.4] the compression method 12 is not supported`  Recompress the archive with deflate, or store the entry uncompressed.
row  `SN-751.5`  `MissingEocd`  No end-of-central-directory record was found, so the archive's index cannot be located.  `[↯SN-751.5] no end-of-central-directory record could be found`  The file is not a ZIP archive, or its tail is missing. Check that it downloaded completely.
row  `SN-751.6`  `TruncatedArchive`  The archive ends before a structure it declared was complete.  `[↯SN-751.6] the ZIP archive ended unexpectedly`  The file is incomplete. Obtain it again.
row  `SN-751.7`  `BadSignature`  A record does not begin with the four-byte signature the format requires there.  `[↯SN-751.7] an expected record signature (67324752) was absent`  The archive is corrupt, or the offset was computed from a damaged index. Recovering the entries by scanning may work where the index does not.
row  `SN-751.8`  `Zip64Error`  The ZIP64 extensions, which carry sizes and offsets too large for the original format, could not be interpreted.  `[↯SN-751.8] the ZIP64 metadata could not be interpreted`  The archive uses ZIP64 in a way this reader does not support, or the metadata is damaged.
row  `SN-751.9`  `WriteUnsupported`  The archive was opened with the `Write` grant, which opening as `Zip` does not offer.  `[↯SN-751.9] ZIP archives cannot yet be opened for writing`  Build a new `Zipfile` from the entries and write it (`path.write(Zipfile(entries))`), rather than opening an existing archive for modification.
row  `SN-751.10`  `AlreadyExists`  Creating an archive found something already at the path.  `[↯SN-751.10] an archive already exists at this path`  Choose another path, or pass `CreateFlag.Replace` to overwrite deliberately.
row  `SN-751.11`  `CannotWrite`  The archive could not be written, for a reason the underlying filesystem reported.  `[↯SN-751.11] the archive could not be written: permission denied`  The detail carries the operating system's explanation; act on that.
```
