# `SN-055` — `Mdns.Error`

Raised when the socket-based mDNS responder (`syndesis`) cannot start.

## Cause

The responder joins the mDNS multicast group (`224.0.0.251:5353`) on every interface that is up
and multicast-capable. With no such interface, or a join the operating system refuses, there is
nothing to speak through. The message is `the mDNS responder could not start because $reason`.

## Variants

### `SN-055.1` — `Join`

The multicast group could not be joined: binding port 5353 with reuse failed, or the join was
refused on every interface.

**Example.** `[↯SN-055.1] the mDNS responder could not start because the multicast group 224.0.0.251:5353 could not be joined`

**Resolution.** Check that port 5353 is not held without reuse by another program, and that the
interfaces have IPv4 addresses.

### `SN-055.2` — `NoInterface`

No network interface is up and multicast-capable (loopback does not count).

**Example.** `[↯SN-055.2] the mDNS responder could not start because no interface is up and capable of multicast`

**Resolution.** mDNS needs a link; in a sandbox without one, use the in-memory `Mdns.Transport.Bus`.
