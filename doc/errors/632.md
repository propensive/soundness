# `SN-632` — `Httpd.Error`

Raised when Scintillate cannot start an HTTP server on the
requested port.

## Cause

The OS refused to bind the listener — typically because the port is
already in use, or it is privileged and the process lacks
permission.

This is **not** an HTTP 5xx response. That is
`Http.Status.Category.ServerError` in telekinesis, and it describes a
response the server sent; this describes a server that never started.
The error was called `ServerError` until the two were told apart.

## Example message

```
[↯SN-632] could not start an HTTP server on port 80
```

## Resolution

Choose a different port, free the conflicting one, or run with
sufficient privilege.
