# `↯/s.105.2` — `Crypto.Error`

Raised when Enigmatic cannot decode encrypted data.

## Cause

The cryptographic primitive (cipher, signature, or MAC) rejected the
input. The constructor takes a `reason: Reason` indicating why the
operation failed; the rendered message is `could not decode the
encrypted data because $reason`.

## Variants

### `↯/s.105.2.1` — `BadPadding`

The padding bytes did not match the cipher's expectations — typically
because the ciphertext was corrupted or the wrong key was supplied
(authentication-tag mismatch in AEAD modes).

**Example.** `[↯/s.105.2.1] could not decode the encrypted data because the ciphertext was corrupted or the key was wrong`

**Resolution.** Confirm the key and IV match those used at encryption
time; verify the ciphertext has not been truncated or modified in
transit.

### `↯/s.105.2.2` — `IllegalBlockSize`

The input length was not a multiple of the cipher's block size, or
otherwise incompatible with the cipher's framing.

**Example.** `[↯/s.105.2.2] could not decode the encrypted data because the input length was not valid for the cipher`

**Resolution.** Verify the ciphertext is complete and was produced by
the same cipher and mode now being used to decrypt it.

### `↯/s.105.2.3` — `InvalidKey`

The key bytes were rejected by the cipher — wrong size, invalid
format, or unsupported parameters.

**Example.** `[↯/s.105.2.3] could not decode the encrypted data because the key was not valid for the cipher`

**Resolution.** Confirm the key was produced for the same cipher and
parameter set.

### `↯/s.105.2.4` — `InvalidAlgorithm`

The requested algorithm or mode is not available in the JVM's
configured providers.

**Example.** `[↯/s.105.2.4] could not decode the encrypted data because the algorithm was not available`

**Resolution.** Install or enable a JCA provider that supports the
algorithm; check `java.security` policy.

### `↯/s.105.2.5` — `IoFailure`

The cipher implementation could not read or write the data buffers —
typically a low-level I/O fault.

**Example.** `[↯/s.105.2.5] could not decode the encrypted data because data could not be read or written`

**Resolution.** Inspect the cause chain for the underlying I/O error.

### `↯/s.105.2.6` — `BadTag`

An authenticated cipher's tag did not verify: the ciphertext, the associated data or the
nonce is not what was sealed, or the key is not the one it was sealed with.

**Example.** `[↯/s.105.2.6] could not decrypt the data because the authentication tag did not verify`

**Resolution.** Treat the data as forged or corrupt, and do not use any part of it. Confirm
that the nonce and the associated data are exactly those given to `seal`.

### `↯/s.105.2.7` — `BadWrap`

Wrapped key material did not pass the integrity check that key wrapping builds in: it was
wrapped under a different key, or has been altered, or is not a whole number of 64-bit blocks.

**Example.** `[↯/s.105.2.7] could not decrypt the data because the wrapped key did not pass its integrity check`

**Resolution.** Confirm that the key-encryption key is the one the material was wrapped
under, and that the wrapped material arrived complete.
