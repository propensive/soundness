# Changes since 0.75.0

This file is read by an LLM agent to upgrade code that consumes Soundness libraries from
0.75.0 to the next release. Each entry states precisely what changed; see `AGENTS.md` for the
format. Entries are grouped by module, most-recently-added last within a module.

## caesura

- `caesura.dsvRedesignations.lowerDottedRedesignation` now joins the lower-cased words of a field
  name with `.` (`targetPerson` → `target.person`), and
  `caesura.dsvRedesignations.lowerSlashedRedesignation` with `/` (`targetPerson` →
  `target/person`); both previously joined them with a space, as `lowerWordsRedesignation` does.
  A file read or written under either given must use the dotted or slashed headers. (#2439)

## perihelion

- `perihelion.Websocket.Error.Reason.Truncated` now renders as "the connection closed before the
  frame was complete"; its `Communicable` instance previously had no case for it, so describing
  such an error threw a `MatchError`. (#2439)

## contingency

- `contingency.survive` on a `scala.collection.Iterable[element]` receiver
  (`extension [element](sequence: Iterable[element]) transparent inline def survive[result](using
  erased Void)[error <: Hazard](lambda): Iterable[result]`) removed. The remaining
  `contingency.survive` on any `self is murmuration.Traversable by element` (which includes every
  stdlib `Iterable`) applies, returning `proscenium.List[result]` instead of `Iterable[result]`.
  (#2442)

## mercator

- `mercator.sequence` changed from `extension [monad[_], collection[element] <: Iterable[element],
  element](elems: collection[monad[element]])(using Monad[monad]) def sequence(using
  BuildFrom[scala.collection.immutable.List[element], element, collection[element]]):
  monad[collection[element]]` to `extension [self](self: self)(using traversable: self is
  murmuration.Traversable) def sequence[monad[_], element, result](using traversable.Operand <:<
  monad[element], Monad[monad], self is murmuration.Reshapable by element to result):
  monad[result]`. It now applies to `proscenium.List`, `Set`, `Sequence`, `Chain`, frozen `Array`
  and every other `Traversable` with a `Reshapable` instance, rebuilding the same shape; it no
  longer applies to stdlib collections (`scala.collection.immutable.List`, `Seq`, `Set`, …),
  which have no `Reshapable`, except `scala.collection.immutable.IndexedSeq`: convert them with
  `proscenium.List.from(…)` first. (#2442)
- `mercator.traverse` changed in the same way: from `extension [collection[element] <:
  Iterable[element], element](elems: collection[element]) def traverse[element2,
  monad[_]](lambda: element => monad[element2])(using Monad[monad],
  BuildFrom[scala.collection.immutable.List[element2], element2, collection[element2]]):
  monad[collection[element2]]` to `extension [self](self: self)(using traversable: self is
  murmuration.Traversable) def traverse[element2, monad[_], result](lambda: traversable.Operand
  => monad[element2])(using Monad[monad], self is murmuration.Reshapable by element2 to result):
  monad[result]`. Same receivers as `sequence`; stdlib collections other than
  `scala.collection.immutable.IndexedSeq` no longer apply. (#2442)

## polysyllabic

- `polysyllabic.Hyphenation#extending(patterns: Iterable[Text] = Iterable(), exceptions:
  Iterable[Text] = Iterable(), leftMin: Optional[Int] = Unset, rightMin: Optional[Int] = Unset)`
  now takes `patterns: proscenium.List[Text] = List()` and `exceptions: proscenium.List[Text] =
  List()`. Behaviour unchanged. (#2442)

## vacuous

- `vacuous.compact` on `Iterable[Optional[value]]` (`transparent inline def compact:
  Iterable[value]`) replaced by `extension [self](self: self)(using traversable: self is
  murmuration.Traversable) def compact[value, result](using traversable.Operand <:<
  Optional[value], self is murmuration.Reshapable by value to result): result`. It now applies to
  `proscenium.List`, `Set`, `Sequence`, `Chain`, frozen `Array` and other `Traversable`s with a
  `Reshapable`, returning the same shape (`List[Optional[Text]]` → `List[Text]`), and no longer
  applies to stdlib collections other than `scala.collection.immutable.IndexedSeq`, including
  varargs `Seq`s: convert them with `.to(proscenium.List)` (or `proscenium.List.from(…)`) first. Code calling `.stdlib.compact` should drop the `.stdlib`. The
  `compact` on `murmuration.Iterator[Optional[value]]^` is unchanged. (#2442)
- `vacuous.entire` on `Iterable[Optional[value]]` (`def entire: Optional[proscenium.List[value]]`)
  replaced by `extension [self](self: self)(using traversable: self is murmuration.Traversable)
  def entire[value, result](using traversable.Operand <:< Optional[value], self is
  murmuration.Reshapable by value to result): Optional[result]`: the result has the receiver's
  shape rather than always being a `List`: a `scala.collection.immutable.IndexedSeq` receiver
  (such as `(0 until n).map(…)`) now yields `Optional[IndexedSeq[value]]`, and other stdlib
  collections no longer apply. (#2442)

## digression

- `digression.StackTrace.legend: Map[Text, Text]` is now keyed by the bare glyph (`λ`, `ⲛ`, `δ`,
  `⁅⁆`) rather than the glyph padded to two characters (`λₙ`, `ⲛ `, `δ `); it is derived from the
  new `digression.StackTrace.Marker.all`. `ⲛ` is described as "constructor" (previously "class
  initializer"); `Σ` is listed as before, `ζ` is no longer produced, and `Ξ`, `Λ`, `ι`, `ℓ`,
  `⇢`, `≔`, `∂`, `⊡` and `⊙` are listed. (#2442)
- `digression.StackTrace.rewrite(name: String, method: Boolean = false): Text` changes its output
  for these inputs: `$adapted` marks the preceding `λ` as `Λ` (`lam$$anonfun$1$adapted` →
  `lam.Λ₁()`, previously `lam.λ₁.adapted()`); `<clinit>` and `$init$` → `ι` (previously
  unchanged and `.init.`); `$lzyINIT`, `$lzy` and `$lzyHandle` → `ℓ` (previously `#ℓ`, `#lzy`,
  `#lzyHandle`); `protected$`, `inline$` and `$accessor` → `⇢`; `$_setter_$` → `≔`;
  `$retainedBody` → `⊡`; `$outer` → `⊙`; `$$Lambda` → `#λ`/`.λ`; `$uXXXX` → the character;
  `$mc…$sp` consumes the tags, so `apply$mcII$sp` → `applyΣ(Int -> Int)()` (previously
  `applyΣ(Int -> Int)IIζ()`) and the parameters of a specialized method of arity above one are
  now in order with the result last (`apply$mcJII$sp` → `applyΣ((Int, Int) -> Long)()`, likewise
  `scala.runtime.java8.JFunction2$mcJII$sp` → `((Int, Int) => Long)`); a bare `$sp` is no longer
  `ζ`; `Play$$cue` (an expanded private name) → `Play.cue()` with one separator (previously
  `Play..cue()`), though `$$` followed by an operator encoding still decodes as the operator;
  `initial$` and `$_avoid_name_clash_$`, which the compiler no longer emits, are no longer
  rewritten to `ι` and `′`. Numbers after `$`, operators, `$anonfun`, `$anon`, `<init>`,
  `super$`, `$extension`, `$direct`, `$default`, `$package` and module classes are unchanged.
  (#2442)
- `digression.StackTrace.Marker` added: `case class Marker(jvm: Text, glyph: Text, meaning: Text,
  kind: Optional[StackTrace.Frame.Kind] = Unset)`, with `Marker.all: List[Marker]` and
  `Marker.operators: List[(Text, Char)]`. (#2442)

## hyperbole

- `hyperbole.StackResolver.hint(method: Text): Optional[StackTrace.Frame.Kind]` now reads
  `digression.StackTrace.Marker.all`: a name containing `$adapted` is `Bridge` even when it also
  contains `$anonfun` (previously `Lambda`); `super$`, `protected$`, `inline$` and `$accessor`
  give `Forwarder` and `$_setter_$` and `$retainedBody` give `Synthetic` (previously `Unset`);
  `$lzy` without `INIT` no longer gives `Initializer`. (#2442)

## jacinta

- `jacinta.JsonSchema.requiredLabels(labels: proscenium.Array[Optional[Text]]^{}):
  proscenium.List[Text]` added: the present labels of a derived schema's fields, which
  `jacinta.JsonSchema.conjunction` calls. Nothing existing changes. (#2442)

## build

- The pinned compiler is Proscala `1.1.0` (`3.10.0-pro-1.1.0`, was `3.10.0-pro-1.0.7`). Soundness's
  published artifacts are compiled with it, so a consumer compiling against them pins the same
  build. (#2443)
- Every Soundness module above `proscenium` is compiled with Proscala's `-Zgatherable-varargs`:
  inside a method, a repeated parameter (`parts: Text*`) is a `proscenium.List[Text]` rather than
  a `scala.collection.immutable.Seq[Text]`. No signature changes, and no call site is affected:
  callers pass and splice arguments exactly as before. A consumer who wants the same in their own
  code adds `-Zgatherable-varargs` and `-experimental` to their compiler options and brings
  `proscenium.listGatherable` into scope (`-Yimports:java.lang,proscenium`, or
  `import proscenium.listGatherable`); without the flag nothing changes for them. (#2443)

## proscenium

- `proscenium.listGatherable` added: `given listGatherable: [element] => (scala.Gatherable[element]
  { type Out = proscenium.List[element] })`, the instance `-Zgatherable-varargs` receives repeated
  parameters through. (#2443)

## adversaria

- `adversaria.relabelling[self, format]: Map[Text, Text]` and
  `adversaria.variantRelabelling[self, format]: Map[Text, Text]` are now macros resolved when the
  calling derivation expands, with the same signatures and results: a `@name` argument written as
  a literal (`@name(t"…")`, `@name("…")`) is a string constant in the generated code, and any other
  is rebuilt and read once at the expansion site rather than every time the derived instance runs.
  No caller changes. (#2475)
- `adversaria.annotatedFields[self, annotation <: StaticAnnotation]: Set[Text]` added: the names
  of the fields of `self` carrying an `annotation`, as a literal `Set`. Use it instead of
  `fieldAnnotations[self, annotation].defines(label)` when only the *presence* of an annotation on
  a field matters; `fieldAnnotations` is unchanged. (#2475)
- `adversaria.typeAnnotation[self, annotation <: StaticAnnotation]: Optional[annotation]` added:
  the `annotation` on the type `self` itself (the last declared), or `Unset`. Use it instead of
  `summonInline[self is Annotated by annotation]` followed by `.annotations.head`. (#2475)

## xylophone

- `Xml.DecodableDerivation` and `Xml.EncodableDerivation` read a type's `@attribute`,
  `@unqualified`, `@xmlns` and `@name[Xml]` annotations through `adversaria.annotatedFields`,
  `adversaria.typeAnnotation` and the macro `adversaria.relabelling`; wire names and the attribute
  and namespace decisions are unchanged. (#2475)

## probably

- `soundness.Arithmetic` and `soundness.Geometric` no longer refer to probably's
  `Baseline.Mode` cases, and `probably.Arithmetic`/`probably.Geometric` are removed: write
  `Baseline.Mode.Arithmetic` and `Baseline.Mode.Geometric`. `soundness.Arithmetic` is now
  unambiguously hypotenuse's `Arithmetic` (holding `Arithmetic.Error`).
- `Value`, a coordinate on a test axis, is renamed `Axis.Value`: `Value.Discrete(label)` becomes
  `Axis.Value.Discrete(label)`.

## ultimatum

- ultimatum's layout types are nested in a new `object Tui`, and are no longer exported
  individually: `Pane`, `Panes`, `Frame`, `Placement`, `Sizing`, `Limits`, `Arrangement` and
  `Occupancy` become `Tui.Pane`, `Tui.Panes`, `Tui.Frame`, `Tui.Placement`,
  `Tui.Sizing`, `Tui.Limits`, `Tui.Arrangement` and `Tui.Occupancy`; write the
  qualified name, or `import ultimatum.Tui.{Pane, Sizing}` (naming only what is used).
  For example, `conduct(Occupancy.Inline)(…)` becomes `conduct(Tui.Occupancy.Inline)(…)`
  and `val body: Pane = …` becomes `val body: Tui.Pane = …`.
- `ultimatum.Rect` is renamed `Tui.Region`, and every member named `rect` is renamed
  `region`: `Tui.Placement#region`, `Extent#region`, `FlowExtent#region` and
  `Form.Entry#region`. `Rect(left, top, width, height)` becomes
  `Tui.Region(left, top, width, height)`.
- The inline rendering policies are nested in `InlineRoot`: `InlineAnchoring`, `InlineGrowth`
  and `InlineShrink` become `InlineRoot.Anchoring`, `InlineRoot.Growth` and
  `InlineRoot.Shrink`. The `inlineAnchoring`, `inlineGrowth` and `inlineShrink` givens are
  unchanged.

## octogenarian

- `soundness.Commandline` and `soundness.Native` no longer refer to octogenarian's git
  backends: the names are exoskeleton's parsed command line and xenophile's C interface. Select
  a backend with `gitBackends.commandlineGit` or `gitBackends.soundnessGit` as before, or write
  the classes qualified: `octogenarian.Native(List(SmartHttp(), SshCommand()))`,
  `octogenarian.Commandline.Event`.
- The patch and remote types are nested in `Git`: `Remote`, `Patch`, `FileDiff`, `Hunk` and
  `ChangeKind` become `Git.Remote`, `Git.Patch`, `Git.FileDiff`, `Git.Hunk` and
  `Git.ChangeKind`; `Patch.parse(text)` becomes `Git.Patch.parse(text)`.

## embarcadero

- The containerd protobuf records are nested in `object Containerd` and no longer exported
  individually: `Container`, `Mount`, `Namespace`, `Runtime`, `Empty`, `AnyMessage`,
  `ContentDescriptor`, `ImageRecord`, `ProcessStatus`, `Timestamp`, and every service request
  and response (`ListContainersRequest`, `CreateTaskResponse`, `WaitResponse`, …) become
  `Containerd.Container`, `Containerd.Mount` and so on. `embarcadero.Timestamp` becomes
  `Containerd.Timestamp`. Write the qualified name, or import the members used, e.g.
  `import embarcadero.Containerd.{Container, Mount}`.
- `DockerEvent` is renamed `Containerd.Event`; a `DockerEvent is Loggable` given becomes
  `Containerd.Event is Loggable`. Its cases are unchanged.

## coaxial

- `coaxial.DomainSocket` is renamed `Uds` (a UNIX domain socket), and `DomainSocket.Endpoint`
  becomes `Uds.Endpoint`: `DomainSocket(% / "var" / "run" / "docker.sock")` becomes
  `Uds(% / "var" / "run" / "docker.sock")`. The companion givens `Bindable.domainSocket`,
  `Connectable.domainSocket` and `Serviceable.domainSocket` are renamed `uds`.

## telekinesis

- `telekinesis.domainSocketFetchable` and `telekinesis.domainSocketHttpClient` are renamed
  `udsFetchable` and `udsHttpClient`; update any by-name import of them
  (`import soundness.{udsFetchable, udsHttpClient}`).

## rudiments

- `rudiments.Bytes`, the opaque byte count made by `4.b`, `8.kib`, `data.bytes` and so on, is
  renamed `Memory`: `Bytes(1024L)` becomes `Memory(1024L)`, and a `Bytes` type ascription
  becomes `Memory`. Its operations are unchanged. The givens named after it are renamed
  `memory`: `hypotenuse.Commensurable.memory` (`Memory is Orderable`),
  `spectacular.Showable.memory`, `spectacular.Inspectable.memory`, jacinta's `Json.memory` and
  ypsiloid's `Yaml.memory` decoders.

## quantitative

- The `Information` dimension, its unit `Bytes[power]`, the `MetricUnit` `Byte`, and the
  `B` designation (`Designation.bytes`) now belong to quantitative. They were ultimatum's
  (`ultimatum.Information`, `ultimatum.Bytes`, `ultimatum.Byte`, `ultimatum.informationDesignation`),
  which are removed; code using `soundness.*` needs no change, but a by-name
  `import soundness.informationDesignation` should be deleted, since the designation is now
  found in `Designation`'s companion. A local re-declaration of `Information`, `Bytes` and
  `Byte` may be deleted in favour of these.

## espionage

- `Acp.Agent`, the enum saying where an agent is, is renamed `Acp.Endpoint`:
  `Acp.connect(Acp.Agent(sh"…"))` becomes `Acp.connect(Acp.Endpoint(sh"…"))`,
  `Acp.Agent.streams(input, output)` becomes `Acp.Endpoint.streams(input, output)`, and the
  cases are `Acp.Endpoint.Process` and `Acp.Endpoint.Streams`.
- The `@rpc` wire traits are nested in `Acp` and no longer exported individually: `AcpAgent`
  becomes `Acp.Agent`, `AcpAgentLifecycle` and `AcpAgentSession` become `Acp.Agent.Lifecycle`
  and `Acp.Agent.Session`, `AcpClient` becomes `Acp.Client`, and `AcpClientSession`,
  `AcpClientFs` and `AcpClientTerminal` become `Acp.Client.Session`, `Acp.Client.Fs` and
  `Acp.Client.Terminal`.

## enigmatic

- The block-cipher modes and paddings are nested in `BlockCipher` and no longer exported
  individually: `Cbc`, `Ecb`, `Ctr`, `Cfb`, `Ofb`, `Pkcs7`, `Iso10126` and `NoPadding` become
  `BlockCipher.Cbc` and so on, and the typeclasses `BlockCipherMode` and `BlockCipherPadding`
  become `BlockCipher.Mode` and `BlockCipher.Padding`. `Aes[256] over Cbc against Pkcs7`
  becomes `Aes[256] over BlockCipher.Cbc against BlockCipher.Pkcs7`, or import the members:
  `import enigmatic.BlockCipher.{Cbc, Pkcs7}`. The `blockCipherModes` and
  `blockCipherPaddings` givens are unchanged.

## anthology

- The compilation types are nested in `Compiler` and no longer exported individually:
  `CompileProcess`, `CompileResult`, `CompileEvent` and `CompileProgress` become
  `Compiler.Process`, `Compiler.Result`, `Compiler.Event` and `Compiler.Progress`, and
  `CompileEvents.relay` becomes `Compiler.Event.relay`. A `given (CompileEvent is Loggable)`
  becomes `given (Compiler.Event is Loggable)`.
- `Notice` is renamed `Compiler.Notice`, and `Universe`, `Tool` and `Triple` are nested in
  `Toolchain`: `Scalac[3.8, Universe.Classfile]` becomes
  `Scalac[3.8, Toolchain.Universe.Classfile]`, `extends Tool` becomes `extends Toolchain.Tool`,
  and `Triple.X64Linux` becomes `Toolchain.Triple.X64Linux`. Or import the members:
  `import anthology.Toolchain.{Tool, Universe}`.

## escritoire

- The table types are nested in `Table` and no longer exported individually: `TableCell`,
  `TableRow`, `TableSection`, `TableStyle` and `TableRelabelling` become `Table.Cell`,
  `Table.Row`, `Table.Section`, `Table.Style` and `Table.Relabelling`. A
  `given TableRelabelling[Codebase]` becomes `given Table.Relabelling[Codebase]`; the
  `tableStyles` givens are unchanged.

## dendrology

- The diagram tiles and styles are nested in their diagrams and no longer exported
  individually: `TreeTile`, `TreeStyle` and `TextualTreeStyle` become `TreeDiagram.Tile`,
  `TreeDiagram.Style` and `TreeDiagram.TextualStyle`; `DagTile`, `DagStyle` and
  `TextualDagStyle` become `DagDiagram.Tile`, `DagDiagram.Style` and
  `DagDiagram.TextualStyle`; `LaneDagStyle` and `TextualLaneDagStyle` become
  `LaneDagDiagram.Style` and `LaneDagDiagram.TextualStyle`. The `treeStyles`, `dagStyles` and
  `laneDagStyles` givens are unchanged.

## exoskeleton

- `MissingFlagError` and `InvalidFlagError` are merged into `Flag.Error(flag, reason)`, whose
  `reason` is `Flag.Error.Reason.Missing` or `Flag.Error.Reason.Invalid(detail)` (the former
  `InvalidFlagError#reason` is now `detail`). `catch case error: MissingFlagError =>` becomes
  `catch case error: Flag.Error =>`, testing `error.reason` if the distinction matters; a
  `Tactic[MissingFlagError]` or `Tactic[InvalidFlagError]` becomes `Tactic[Flag.Error]`.

## kaleidoscope

- `RegexBackend` is renamed `Regex.Backend`: a `RegexBackend[Re2]` type becomes
  `Regex.Backend[Re2]`. The `regexBackends` givens are unchanged.

## parasite

- `SharedProbate` is renamed `Probate.Shared`: a `using SharedProbate` parameter becomes
  `using Probate.Shared`. It is the same alias, `Probate^{caps.any.only[Durable]}`.

## aviation

## cataclysm

  becomes `Css.Syntax.Matcher.check(grammar, value)`.

## fulminate

  still made by `Error(throwable)`. A `case error: UncheckedError` pattern becomes
  `case error: Error.Unchecked`.

## degustation

  `ClassSource` becomes `Universe.Source` and `ClassInfo` becomes `Universe.ClassInfo`.

  them: `import dissonance.Diff.{Del, Ins, Par}`.

## gesticulate

## orthodoxy

## stratiform

  renamed `Tel.Mutation` and `Tel.Revision`; `Mutation.Error` becomes `Tel.Mutation.Error`.
