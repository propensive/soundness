# Changes since 0.75.0

This file is read by an LLM agent to upgrade code that consumes Soundness libraries from
0.75.0 to the next release. Each entry states precisely what changed; see `AGENTS.md` for the
format. Entries are grouped by module, most-recently-added last within a module.

## caesura

- `caesura.dsvRedesignations.lowerDottedRedesignation` now joins the lower-cased words of a field
  name with `.` (`targetPerson` → `target.person`), and
  `caesura.dsvRedesignations.lowerSlashedRedesignation` with `/` (`targetPerson` →
  `target/person`); both previously joined them with a space, as `lowerWordsRedesignation` does.
  A file read or written under either given must use the dotted or slashed headers. (#2439)

## perihelion

- `perihelion.Websocket.Error.Reason.Truncated` now renders as "the connection closed before the
  frame was complete"; its `Communicable` instance previously had no case for it, so describing
  such an error threw a `MatchError`. (#2439)

## contingency

- `contingency.survive` on a `scala.collection.Iterable[element]` receiver
  (`extension [element](sequence: Iterable[element]) transparent inline def survive[result](using
  erased Void)[error <: Hazard](lambda): Iterable[result]`) removed. The remaining
  `contingency.survive` on any `self is murmuration.Traversable by element` (which includes every
  stdlib `Iterable`) applies, returning `proscenium.List[result]` instead of `Iterable[result]`.
  (#2442)

## mercator

- `mercator.sequence` changed from `extension [monad[_], collection[element] <: Iterable[element],
  element](elems: collection[monad[element]])(using Monad[monad]) def sequence(using
  BuildFrom[scala.collection.immutable.List[element], element, collection[element]]):
  monad[collection[element]]` to `extension [self](self: self)(using traversable: self is
  murmuration.Traversable) def sequence[monad[_], element, result](using traversable.Operand <:<
  monad[element], Monad[monad], self is murmuration.Reshapable by element to result):
  monad[result]`. It now applies to `proscenium.List`, `Set`, `Sequence`, `Chain`, frozen `Array`
  and every other `Traversable` with a `Reshapable` instance, rebuilding the same shape; it no
  longer applies to stdlib collections (`scala.collection.immutable.List`, `Seq`, `Set`, …),
  which have no `Reshapable`, except `scala.collection.immutable.IndexedSeq`: convert them with
  `proscenium.List.from(…)` first. (#2442)
- `mercator.traverse` changed in the same way: from `extension [collection[element] <:
  Iterable[element], element](elems: collection[element]) def traverse[element2,
  monad[_]](lambda: element => monad[element2])(using Monad[monad],
  BuildFrom[scala.collection.immutable.List[element2], element2, collection[element2]]):
  monad[collection[element2]]` to `extension [self](self: self)(using traversable: self is
  murmuration.Traversable) def traverse[element2, monad[_], result](lambda: traversable.Operand
  => monad[element2])(using Monad[monad], self is murmuration.Reshapable by element2 to result):
  monad[result]`. Same receivers as `sequence`; stdlib collections other than
  `scala.collection.immutable.IndexedSeq` no longer apply. (#2442)

## polysyllabic

- `polysyllabic.Hyphenation#extending(patterns: Iterable[Text] = Iterable(), exceptions:
  Iterable[Text] = Iterable(), leftMin: Optional[Int] = Unset, rightMin: Optional[Int] = Unset)`
  now takes `patterns: proscenium.List[Text] = List()` and `exceptions: proscenium.List[Text] =
  List()`. Behaviour unchanged. (#2442)

## vacuous

- `vacuous.compact` on `Iterable[Optional[value]]` (`transparent inline def compact:
  Iterable[value]`) replaced by `extension [self](self: self)(using traversable: self is
  murmuration.Traversable) def compact[value, result](using traversable.Operand <:<
  Optional[value], self is murmuration.Reshapable by value to result): result`. It now applies to
  `proscenium.List`, `Set`, `Sequence`, `Chain`, frozen `Array` and other `Traversable`s with a
  `Reshapable`, returning the same shape (`List[Optional[Text]]` → `List[Text]`), and no longer
  applies to stdlib collections other than `scala.collection.immutable.IndexedSeq`, including
  varargs `Seq`s: convert them with `.to(proscenium.List)` (or `proscenium.List.from(…)`) first. Code calling `.stdlib.compact` should drop the `.stdlib`. The
  `compact` on `murmuration.Iterator[Optional[value]]^` is unchanged. (#2442)
- `vacuous.entire` on `Iterable[Optional[value]]` (`def entire: Optional[proscenium.List[value]]`)
  replaced by `extension [self](self: self)(using traversable: self is murmuration.Traversable)
  def entire[value, result](using traversable.Operand <:< Optional[value], self is
  murmuration.Reshapable by value to result): Optional[result]`: the result has the receiver's
  shape rather than always being a `List`: a `scala.collection.immutable.IndexedSeq` receiver
  (such as `(0 until n).map(…)`) now yields `Optional[IndexedSeq[value]]`, and other stdlib
  collections no longer apply. (#2442)

## digression

- `digression.StackTrace.legend: Map[Text, Text]` is now keyed by the bare glyph (`λ`, `ⲛ`, `δ`,
  `⁅⁆`) rather than the glyph padded to two characters (`λₙ`, `ⲛ `, `δ `); it is derived from the
  new `digression.StackTrace.Marker.all`. `ⲛ` is described as "constructor" (previously "class
  initializer"); `Σ` is listed as before, `ζ` is no longer produced, and `Ξ`, `Λ`, `ι`, `ℓ`,
  `⇢`, `≔`, `∂`, `⊡` and `⊙` are listed. (#2442)
- `digression.StackTrace.rewrite(name: String, method: Boolean = false): Text` changes its output
  for these inputs: `$adapted` marks the preceding `λ` as `Λ` (`lam$$anonfun$1$adapted` →
  `lam.Λ₁()`, previously `lam.λ₁.adapted()`); `<clinit>` and `$init$` → `ι` (previously
  unchanged and `.init.`); `$lzyINIT`, `$lzy` and `$lzyHandle` → `ℓ` (previously `#ℓ`, `#lzy`,
  `#lzyHandle`); `protected$`, `inline$` and `$accessor` → `⇢`; `$_setter_$` → `≔`;
  `$retainedBody` → `⊡`; `$outer` → `⊙`; `$$Lambda` → `#λ`/`.λ`; `$uXXXX` → the character;
  `$mc…$sp` consumes the tags, so `apply$mcII$sp` → `applyΣ(Int -> Int)()` (previously
  `applyΣ(Int -> Int)IIζ()`) and the parameters of a specialized method of arity above one are
  now in order with the result last (`apply$mcJII$sp` → `applyΣ((Int, Int) -> Long)()`, likewise
  `scala.runtime.java8.JFunction2$mcJII$sp` → `((Int, Int) => Long)`); a bare `$sp` is no longer
  `ζ`; `Foo$$bar` (an expanded private name) → `Foo.bar()` with one separator (previously
  `Foo..bar()`), though `$$` followed by an operator encoding still decodes as the operator;
  `initial$` and `$_avoid_name_clash_$`, which the compiler no longer emits, are no longer
  rewritten to `ι` and `′`. Numbers after `$`, operators, `$anonfun`, `$anon`, `<init>`,
  `super$`, `$extension`, `$direct`, `$default`, `$package` and module classes are unchanged.
  (#2442)
- `digression.StackTrace.Marker` added: `case class Marker(jvm: Text, glyph: Text, meaning: Text,
  kind: Optional[StackTrace.Frame.Kind] = Unset)`, with `Marker.all: List[Marker]` and
  `Marker.operators: List[(Text, Char)]`. (#2442)

## hyperbole

- `hyperbole.StackResolver.hint(method: Text): Optional[StackTrace.Frame.Kind]` now reads
  `digression.StackTrace.Marker.all`: a name containing `$adapted` is `Bridge` even when it also
  contains `$anonfun` (previously `Lambda`); `super$`, `protected$`, `inline$` and `$accessor`
  give `Forwarder` and `$_setter_$` and `$retainedBody` give `Synthetic` (previously `Unset`);
  `$lzy` without `INIT` no longer gives `Initializer`. (#2442)

## jacinta

- `jacinta.JsonSchema.requiredLabels(labels: proscenium.Array[Optional[Text]]^{}):
  proscenium.List[Text]` added: the present labels of a derived schema's fields, which
  `jacinta.JsonSchema.conjunction` calls. Nothing existing changes. (#2442)
