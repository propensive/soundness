# Changes since 0.72.0

This file is read by an LLM agent to upgrade code that consumes Soundness libraries from
0.72.0 to the next release. Each entry states precisely what changed; see `AGENTS.md` for the
format. Entries are grouped by module, most-recently-added last within a module.

## zephyrine

- New: `zephyrine.Cursor.Snapshot[medium, operand]`, an inline trait (Scala 3.10,
  `-language:experimental.inlineTraits` is needed only by zephyrine, not by a consumer) that a
  fast parser over a `Cursor[medium, {}]` extends to get the parser-local snapshot of the
  cursor's buffer that jacinta, xylophone, stratiform, ypsiloid, honeycomb, locomotion and
  breviloquence previously each wrote out by hand: the fields `cells: scala.Array[operand]`
  (a `byte[]` for `Snapshot[Data, Byte]`, a `char[]` for `Snapshot[Text, Char]`), `pos`,
  `bufEnd`, `base`, `lineationPos` and `cursor0: AnyRef` (the cursor, re-pointed at each
  reset), the accessor `cursor`, and `syncTo()`, `syncFrom()`, `more`, `moreSlow()`, `peek`,
  `advance()`, `position`, `reconcileLineation()`, `reconcileUtf8()` and `reconcileUtf16()`.
  A parser extending it must be a `caps.Stateful` class and implement the two abstract hooks
  `protected update def reconcile(): Unit` (called before every refill) and `protected update
  def resynced(): Unit` (called after every `syncFrom()`), as `()` where it has nothing to do.
  It must not override any other member: an inline trait's own calls to a member the
  receiver overrides bind to the trait's copy, not to the override. No existing API changed.
- `zephyrine.Cursor` extension methods `peek: Datum` and `expect[error <: Hazard](target: Char)
  (failure)(using Tactic[error])`, previously defined twice, as `@targetName("peekByte")`/
  `("peekChar")` and `("expectByte")`/`("expectChar")` extensions on `Cursor[Data, cap]` and
  `Cursor[Text, cap]`, are now one definition each, on `Cursor[data, cap]` with an additional
  `(using data is Addressable)` clause on the extension (resolved from the medium's companion,
  so no import changes), selecting the byte or char read by the medium's `Operand`. Call
  sites are unchanged; a cursor over any other medium gets a compile-time error from `peek`,
  where it previously had no `peek` at all. (#2279)
- `zephyrine.Cursor#seek(target: addressable.Operand): Boolean` is no longer `inline`
  (a plain `update def`); same semantics, and it now compares bytes and chars without
  boxing. (#2279)

## rudiments

- New: `rudiments.Scroll[element]` (in the `concordance` module, like `Scribe`), a growable array
  appended to and indexed by position — the unboxed replacement for `scala.collection.mutable.
  ArrayBuffer[Int|Long|Byte|…]`, whose backing store holds boxed elements. `Scroll[Int]()`
  (optionally with a capacity), then `append(value)`, `append(other: Scroll[element])`,
  `append(array, from, count)`, `apply(index: Int)`, `update(index: Int, value)`, `length`,
  `isEmpty`, `last`, `retract(count)` (forgets the last `count` elements), `clear()` and
  `freeze: Array[element]^{}` (an exact-size frozen copy). Indices are plain `Int`s checked
  against `length`. Not exported by the `soundness` umbrella (as `Scribe` is not); it is reached
  through `import rudiments.*`. jacinta, xylophone and ypsiloid's position-index buffers,
  jacinta's BCD number buffers, turbulence's `StreamOutputStream`, escapade's style stacks,
  exegesis's line index and facsimile's `Gathering` now use it. (#PENDING-SCROLL)

## symbolism

- The primitive arithmetic instances in `symbolism.Addable`, `Subtractable`, `Multiplicable`,
  `Divisible` and `Negatable` (`double`, `float`, `long`, `int`, `short`, `byte`, and the mixed
  `int2`/`int3`/`double2`/`float2`/`float3`/`long2`/`short2`/`byte2`) keep their names but are
  now `inline given`s typed by singleton objects — `Addable.DoubleAddition.type`,
  `Subtractable.IntSubtraction.type`, `Divisible.FloatDoubleDivision.type`, `Negatable.LongNegation.type`
  and so on — whose `add`/`subtract`/`multiply`/`divide`/`negate` are `inline def`s. Code that
  summons `Double is Addable by Double to Double` still gets them; code that named the given's
  previous type (`val a: Double is Addable by Double to Double = Addable.double`) still compiles
  by widening. Inline code that reaches one through symbolism's `+`, `-`, `*`, `/` or `unary_-`
  now compiles to the primitive instruction instead of a boxed `Function2` call. (#2282)
