# Changes since 0.77.0

This file is read by an LLM agent to upgrade code that consumes Soundness libraries from
0.77.0 to the next release. Each entry states precisely what changed; see `AGENTS.md` for the
format. Entries are grouped by module, most-recently-added last within a module.

## murmuration

- `xs.to[Map]` (the given `murmuration.Convertible.map`) builds its result with
  `proscenium.Map.build` instead of the standard library's map builder. A result of five or more
  entries is backed by a flat hash table rather than `scala.collection.immutable.HashMap`, so
  its iteration order — as seen by `each`, `fold`, `remap`, `keys`, `values`, `inspect` and
  `.stdlib.iterator` — differs from before; neither order is specified. A result of four or
  fewer entries still iterates in insertion order. Equality, `hashCode`, `at`, `defines`,
  `define`, `omit` and which of two pairs with equal keys is kept (the later) are unchanged.
  The runtime class of such a result's `.stdlib` is no longer `HashMap`; it is still a
  `scala.collection.immutable.Map`. Code that depends on the order must sort, or use `Ledger`.
