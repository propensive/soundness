# Changes since 0.71.0

This file is read by an LLM agent to upgrade code that consumes Soundness libraries from
0.71.0 to the next release. Each entry states precisely what changed; see `AGENTS.md` for the
format. Entries are grouped by module, most-recently-added last within a module.

## aviation

- `Tzdb.Entry.Rule#letters`, `Tzdb.Entry.Zone#location` and `Tzdb.ZoneInfo#until` changed from
  `Option[Text]` to `Optional[Text]`. Replace `Some(x)` with `x` and `None` with `Unset` when
  constructing them; when reading, use `.let`, `.or` and `.absent` in place of `.map`,
  `.getOrElse` and `.isEmpty`, or `.option` to recover an `Option`. (#2190)

## build

- Soundness is compiled with Proscala `3.9.1-dev-p18` (was `3.9.1-dev-p17`); `build.mill`'s
  defaults for `SOUNDNESS_SCALA_RELEASE` and `SOUNDNESS_SCALA_VERSION` are both `3.9.1-dev-p18`.
  The release adds `scala.caps.SharedUnscoped` (the shared, level-exempt classifier
  `contingency`'s ambient strategies now carry) and fixes a capture-checker crash
  (`attempting to add any to {any} of value …$proxyN`) when an inferred value type holds two
  fresh capabilities of unrelated classifiers. A consumer compiles against the same fork
  version. (#2195)
- Soundness is compiled with Proscala `3.9.1-dev-p19` (was `3.9.1-dev-p18`), in which
  `scala.caps.SharedUnscoped` ships in the supplementary `proscala-library` jar rather than in
  `scala-library`, which is again byte-identical to upstream's; the compiler looks the trait up
  leniently, so a classpath without that jar simply has no capability classified that way. A
  consumer resolving `dev.propensive:scala-library` gets `proscala-library` as its dependency,
  as before. (#2202)
- `make test`, `make test.<lib>`, `make ci`, `make bench` and `make bench.<lib>` run fume through
  `etc/ci/fume-run.sh`, which gives each run a private daemon and a private temporary directory
  (`java.io.tmpdir` for the suites, `TMPDIR` for what they shell out to) and removes both when
  the run ends, so a suite's scratch files never outlive the run and no fume daemon is left
  behind. A test that wants a scratch directory uses galilei's existing loan,
  `temporaryDirectory[Path on Linux].open[Scratch](Read & Write): handle ?=> …`, rather than
  `temporaryDirectory / Uuid()`, which nothing deletes. No library's API changes. (#2207)
- Benchmark modules (`trait Benchmarks` in `build.mill`) compile with separation checking by
  default, like libraries and test suites; a bench against a rival library that cannot take the
  fork's flags opts down in its own `scalacOptions`. No library's API changes. (#2202)
- The tools in `etc/tools` are flair 0.6.0 (the compiler plugin Soundness is compiled with),
  fume 0.7.0 (the test runner) and flame 0.6.0, each built against Soundness 0.71.0 and
  Pyrocosm 0.6.0 (were flair 0.5.0, fume 0.6.0 and flame 0.5.0). No library's API changes.
- `etc/xek.tsv` pins xek 1.3.0 (was 1.2.0), and `etc/ci/xek-fetch.sh` fetches only releases
  tagged with the bare version, from 1.0.0; a pin naming an `xek-0.x` or `xeq-0.x` builder no
  longer resolves. The build fetches the builder safely when several test modules resolve it
  at once on a cold cache, which failed when they shared one temporary file. No library's API
  changes.

## contingency

- `contingency.Emit` (and so `Tactic`) extends `caps.SharedCapability` instead of
  `caps.ExclusiveCapability`. Aliasing one tactic — a codec capturing the ambient tactic that
  the same call also takes as evidence, as `Json#as` does — is no longer a separation failure,
  so a `caps.unsafe.unsafeAssumeSeparate(json.as[…])` (or around `Llm.fetch`, `JsonRpc.serve`,
  an `abort(…)` thunk) can be deleted. A subclass of `Emit` may retain only shared capabilities
  and pure values: one holding an exclusive capability or an impure function must drop it, and
  one that also extended `caps.Unscoped` fails with "inherits two unrelated classifier traits" —
  extend `caps.SharedUnscoped` instead, as `ThrowTactic`, `UncheckedTactic` and `FatalTactic` now
  do. (#2195)
- `Emit#contramap` and `Tactic#contramap` take a pure `error2 -> error` (was `error2 => error`)
  and return `Emit[error2]^{this}` / `Tactic[error2]^{this}` (was `^`). An error transformer that
  captured a capability no longer compiles; every existing caller passed an error constructor,
  which is pure. (#2195)
- `Emit.apply` takes `consume handler: error ->{caps.any.only[caps.SharedCapability]} Unit` (was
  `error => Unit`): a `handle` case body may raise into an outer tactic but may not use an
  exclusive capability (a log sink, a stream, a mutable handle); move such work out of the case
  body. (#2195)
- `accrue(initial)(combine)`'s `combine`, and `Accrual.AccrueTactic`'s and `Accrual`'s, is
  `(accrual, Exception) -> accrual` (was `=>`), as its contract already required. (#2195)
- `import strategies.throwUnsafely` inside a method that decodes a derived codec with an
  `Optional`/collection field no longer needs any workaround under the new release; on
  `3.9.1-dev-p17` the same code fails with "capability `any` cannot flow into capture set {any²}
  … not visible from any² in value wisteria$field$N" — if a consumer must stay on p17, bind a
  local `given tactic: Tactic[Json.Error] = ThrowTactic()` instead of the import. (#2195)

## gossamer

- `Text#sub(from: Text, to: Text)` and `sub(from: Text, to: Text, count: Int)` now insert `to`
  verbatim: a `\` or `$` in the replacement is no longer interpreted as a Java replacement
  escape or group reference (`t"a.b".sub(t".", t"\\.")` gives `a\.b`, was `a.b`, and
  `t"x".sub(t"x", t"$1")` gives `$1`, where it threw). The `Regex` overloads are unchanged, so
  `$1` in a regex substitution still refers to the first group. Code that relied on doubling a
  backslash in a literal replacement to insert one should write it singly. (#2182)

## guillotine

- The `Pid is Decodable in Text` given now raises `Number.Error(text, Long, Unparseable)` for a
  malformed value, rather than `Number.Error(text, Int, Unparseable)`; it parses a `Long`. (#2190)

## hellenism

- `ClassRef[T]` and `Classloader[T]` resolve a nested type: a proper type is linked with
  `classOf`, and an unapplied type constructor is looked up by its JVM binary name
  (`ethereal.Launcher$Message`), where both were looked up by the dotted source name and threw
  `ClassNotFoundException` for a type nested in an object or class. A `ClassRef[T]` for a
  proper type now binds the class the caller links against, not whatever the caller's defining
  loader finds by name. (#2188)

## honeycomb

- The extensions `values`, `toList`, `map` and `foreach` on `honeycomb.Attributes` removed.
  `Attributes` is now `Traversable by (Text, Optional[Text])`, in document order, so write
  `attributes.to[List]` for `attributes.toList` (it yields a `proscenium.List` rather than a
  stdlib `List`); `attributes.iterator` still yields the pairs, and `attributes.each` and
  `attributes.toMap` remain. A `for` loop over an `Attributes` value, which used `foreach`, must
  iterate `attributes.iterator` or use `each`. (#2190)

## sibylline

- `Llm.Dialect#stream(turn: Exchange)` returns `Iterator[Event]^{this, caps.any}` rather than
  `Iterator[Event]^{this}`: the iterator also captures the fresh streaming state it advances. An
  implementation of `Dialect` (a custom provider adapter, or a test fake) must declare the wider
  result type on its override; a caller that stores the iterator in a value typed `^{dialect}`
  widens that type likewise. The `Session`/`Response` API is unchanged, including the guarantee
  that a streamed `Response` cannot outlive its session. (#PR6)

## stratiform

- `stratiform.Tel.Metadata` gains a fourth, defaulted parameter, `continuation: Optional[Int] =
  Unset`: the 1-indexed source line on which the content after the document separator (`##`)
  begins, or `Unset` when the document ended at end of input. Construction with three arguments
  is unchanged; a pattern `case Tel.Metadata(directive, pragma, lineEndings)` must add a fourth
  binder. (#2196)

## syndesis

- `syndesis.Discovery.Backend#advertise(service: Discovery.Service, description:
  Discovery.Description)(using Monitor^, Probate^, Tactic[Discovery.Error])` now returns
  `Discovery.Advertising` (new trait, one member `def instance: Discovery.Instance`) instead of
  `Discovery.Instance`, and `Discovery.Backend#withdraw` takes `(advertising:
  Discovery.Advertising)(using Monitor^)` instead of `(instance: Discovery.Instance)(using
  Monitor^)`. A `Backend` implementation must return a handle and accept it back; a caller using
  the seam directly reads the name as `advertising.instance`. The loan
  `service.advertise(description) { … }` is unchanged. (#2186)
- `syndesis.Discovery.Advertisement`'s constructor takes `(advertising: Discovery.Advertising)`
  instead of `(val instance: Discovery.Instance)`; `instance` is now a `def` that reads the
  backend's current name. Its value may change during the block: after RFC 6762 §9 re-probing,
  `Mdns.Responder` renames an established instance (`Gondor` → `Gondor (2)`) when another host
  is found to hold its name, where previously such a response was only cached. Code that reads
  `instance` once and reuses it must re-read it when the name matters. (#2186)
- `syndesis.Mdns.Transport` replaces `def receive(): Packet raises Socket.Error` with `def
  inlets: List[Mdns.Transport.Inlet]`, where `Mdns.Transport.Inlet` (new trait) has `def
  receive(): Packet raises Socket.Error`; `Mdns.Transport.sockets` now joins `ff02::fb` as well
  as `224.0.0.251` (one inlet each) on interfaces with an address of that family, and fails only
  if neither group can be joined. A `Transport` implementation with one socket extends `Inlet` too and
  returns `List(this)`. `Mdns.Transport.Bus#join` now returns `Transport & Transport.Inlet`
  (previously `Transport`), so `receive()` on a bus member is unchanged. (#2186)
- `syndesis.Discovery.Backend#advertise`, `#browse` and `#resolve` take an additional using
  parameter `(Discovery.Activity is Loggable)^` in their final `using` clause (after
  `Tactic[Discovery.Error]`), and `#withdraw` takes `(using Monitor^, (Discovery.Activity is
  Loggable)^)` instead of `(using Monitor^)`; `Discovery.Activity` is a new enum (`Probing`,
  `Yielded`, `Conflicted`, `Claimed`, `Withdrawn`, `Browsing`, `Resolved`) with a `Communicable`
  given. The loans `service.advertise(description) { … }`, `service.browse { … }` and
  `instance.resolve(timeout)` likewise require `(Discovery.Activity is Loggable)^` in scope,
  which `anticipation.Loggable.fanOut` derives from the `Communicable` with no further import
  (silent with no `LogSink` in scope), so call sites compile unchanged; a `Backend`
  implementation must add the parameters. (#2186)

## telekinesis

- `telekinesis.Hpack` is a stateful, exclusive capability (`caps.ExclusiveCapability`,
  `caps.Stateful`): `Hpack()` returns `Hpack^`, and `encode` and `decode` are `update` methods,
  since each changes the codec's dynamic table. A codec is owned by one reader or writer: hold it
  in a local or pass it as a parameter typed `Hpack^`, and do not call it from a closure or a
  local `def` that captures it (the captured reference is read-only, and the call is rejected).
  `decode` takes its `Tactic[Http2.Error]` as a `using` parameter rather than `raises`; call
  sites are unchanged. (#PR6)

## synesthesia

- A derived `Mcp.Specification` no longer lists every tool parameter as `required`, and no
  longer throws when a client omits one. A parameter whose type admits `Unset` (an
  `Optional[…]`) or that has a default argument is omitted from the input schema's `required`;
  when absent from a call it is `Unset` or the default. A required parameter that is absent
  raises `Mcp.Error(Mcp.Error.Reason.MissingParameter)` (was a `NoSuchElementException`). A
  parameter's own `@about` becomes its property's `description` in the schema (was ignored), and
  a prompt argument's description is the parameter's `@about` (was the method's). (#2187)
- `tools/call` answers a tool that throws with a `CallTool` whose `isError` is `true` and whose
  content is the exception's message (was a JSON-RPC `-32603` error with a `null` id). An
  `Mcp.Error` (unknown tool, missing parameter) is still a JSON-RPC error, now `-32602`, and
  every JSON-RPC error `Mcp.send` answers carries the request's `id` and the `Mcp-Session-Id`
  header. (#2187)
- `synesthesia.resource` takes a second parameter, `mimeType: Optional[Text] = Unset`, which
  `resources/read` and `resources/list` report. Without it, a resource whose URI a tool's `@ui`
  names is `text/html;profile=mcp-app` (as every text resource was), and otherwise a text
  resource is `text/plain` and a binary one `application/octet-stream`. (#2187)
- A derived `Mcp.Specification` compiles in a module compiled with capture checking (`-Ycc-new`
  with separation checking), so a server object no longer needs to live in an unchecked module,
  and a `@ui` tool no longer needs a `(List[Text] & Populated) is Encodable in Text` at the
  expansion site. (#2187)
