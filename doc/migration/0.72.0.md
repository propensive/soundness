# Changes since 0.71.0

This file is read by an LLM agent to upgrade code that consumes Soundness libraries from
0.71.0 to the next release. Each entry states precisely what changed; see `AGENTS.md` for the
format. Entries are grouped by module, most-recently-added last within a module.

## acyclicity

- `acyclicity.Dag#sorted: List[node] raises Dag.Error` renamed to `linearized: proscenium.List[node]`,
  which no longer raises: a `Dag` is acyclic by construction. Every node still follows its
  dependencies; the order is now the order in which nodes were first given, where that is a valid
  order, rather than hash order. (#2227)
- `acyclicity.Dag#keys: Set[node]` renamed to `nodes: proscenium.Set[node]`; `Dag#apply(key: node):
  Set[node]` renamed to `successors(node: node): proscenium.Set[node]`; `Dag#edgeMap: Map[node,
  Set[node]]` removed — read the graph through `edges`, `successors` and `predecessors` (the last
  needs `import dysasymptotics.linearScan`). Every `Dag` result that was a
  `scala.collection.immutable.Set`, `Map` or `List` is now the `proscenium` one. (#2227)
- `acyclicity.Dag#has(key: node): Boolean` is no longer a method: `Dag[node]` (and `Digraph[node]`
  and a frozen `Topology[node]^{}`) now have `murmuration.Inclusive by node`,
  `murmuration.Traversable by node` (the nodes, in topological order for a `Dag`) and
  `denominative.Countable` instances, so `dag.has(node)`, `dag.size`, `dag.each`, `dag.fold` and
  the rest of the collection vocabulary come from the typeclass extensions, which `import
  soundness.*` provides. (#2227)
- `acyclicity.Dag.apply(edges: (node, node)*)`, `Dag.apply(nodes: (node, Set[node])*)` and
  `Dag.apply(keys: Set[node])(dependencies: node => Set[node])` now check for a cycle and
  `raises Dag.Error` (`Reason.Cyclic`); the last takes its `Tactic[Dag.Error]` as an explicit
  `using` parameter rather than through `raises`. The unchecked forms are
  `acyclicity.Digraph.apply` with the same signatures, answering a `Digraph[node]` (a graph that
  may contain a cycle), and `digraph.acyclic: Dag[node] raises Dag.Error` is the conversion.
  Every edge target becomes a node in all of them. (#2227)
- `acyclicity.Dag#hasCycle(start: node): Boolean raises Dag.Error` removed; a `Dag` has no cycle.
  On a `Digraph`, `cycle: Optional[proscenium.List[node]]` answers a witness (each node pointing at
  the next, ending where it began) or `Unset`, for the whole graph. (#2227)
- `acyclicity.Dag#sources` is unchanged in meaning (nodes depending on nothing); `sinks:
  proscenium.Set[node]` is added (nodes nothing depends on). (#2227)
- `acyclicity.Dag#remove(element: node): Dag[node]` renamed to `bypass(node: node)(using
  Dysasymptotic.LinearScan): Dag[node]`, and `Dag#filter(predicate: node => Boolean): Dag[node]` to
  `bypassAll(nodes: proscenium.Set[node])(using Dysasymptotic.LinearScan): Dag[node]`, which takes
  the nodes to *drop* rather than a predicate on the nodes to keep. Both now reroute correctly
  when adjacent nodes are dropped. `Dag#-(key: node)` now also takes `(using
  Dysasymptotic.LinearScan)` and drops the edges pointing at the node (it previously left them
  dangling). `ancestors` and `lineage` take the same `using`. Open the gate with
  `import dysasymptotics.linearScan`. (#2227)
- `acyclicity.Dag#subgraph(keep: Set[node]): Dag[node]` now takes `(using
  Dysasymptotic.LinearSize)` (`import dysasymptotics.linearSize`) and is the induced subgraph:
  it drops the edges to nodes outside `keep` rather than rerouting through them. (#2227)
- `acyclicity.Dag#add(key: node, value: node): Dag[node]` now `raises Dag.Error`
  (`Reason.Cyclic`) when the edge would close a cycle; `Dag#++(dag: Dag[node])` and the new
  `Dag#+(edge: (node, node))` answer a `Digraph[node]`, since the result may be cyclic. (#2227)
- `acyclicity.Dag#map[node2](lambda: node => node2): Dag[node2]` is now the `murmuration.Mappable`
  instance's `map` (`Result[node2] = Digraph[node2]`), reached through the collection `map`
  extension: it answers `Digraph[node2]` and, where two nodes map to one, unites their edges (it
  previously kept one node's edges and lost the other's). `Dag#flatMap[node2](lambda: node => Dag[node2])` likewise answers `Digraph[node2]` and
  no longer applies a transitive reduction to its result. (#2227)
- `acyclicity.Dag#reduction` now removes every edge implied by a longer path (it previously
  removed only those implied by a path of two edges, so was correct only on transitively closed
  input). `Dag#closure`, `reachable`, `descendants`, `ancestors` and `lineage` no longer recurse,
  so they neither overflow on deep graphs nor loop on cyclic ones; on a `Digraph`, `reachable`,
  `descendants`, `ancestors`, `lineage` and `closure` are total. (#2227)
- `acyclicity.Dag#traversal[node2](lambda: (Set[node2], node) => node2): (Tactic[Dag.Error]^)
  ?->{lambda} Map[node, node2]` is now `traversal[result](lambda: (proscenium.Set[result], node)
  => result): proscenium.Map[node, result]`, with no `Tactic`. (#2227)
- `acyclicity.Dag` is no longer a `case class`: `Dag.unapply` and `Dag#copy` are gone, and
  equality is on the adjacency as before. (#2227)
- `acyclicity.explore` (`start.explore(dependencies: node => Iterable[node])`) now answers a
  `Digraph[node]` rather than a `Dag[node]`. (#2227)
- The DOT constructor objects `acyclicity.Digraph`, `acyclicity.Graph` and `acyclicity.Subgraph`
  are removed and their methods moved: `Digraph(id, statements*)` → `Dot.digraph(id, statements*)`,
  `Digraph(statements*)` → `Dot.digraph(statements*)`, `Digraph.strict(id, statements*)` →
  `Dot.strictDigraph(id, statements*)`, `Graph(id, statements*)` → `Dot.graph(id, statements*)`,
  `Graph.strict(id, statements*)` → `Dot.strictGraph(id, statements*)`, `Subgraph(id,
  statements*)` → `Dot.subgraph(id, statements*)`, `Subgraph(statements*)` →
  `Dot.subgraph(statements*)`. `acyclicity.Digraph` now names the graph type. (#2227)
- `acyclicity.Hasse#parents`, `children`, `elements`, `maxima` and `minima` now answer
  `proscenium.Set[element]` rather than `scala.collection.immutable.Set[element]`; the fields
  `greater`, `lesser` and `aliases` are no longer public. `Hasse.apply(elements: Set[element])`
  takes a `proscenium.Set`. (#2227)
- `acyclicity.Poset#elements` is a `proscenium.Set[element]`; `Poset.apply(elements: element*)`
  is unchanged. `Poset#dag` is computed through `Hasse` and no longer depends on `reduction`;
  its edges are unchanged. (#2227)

## anthology

- `anthology.CompileProcess#abort()` is reliably observed by the compiler thread (the cancellation
  flag is atomic), so an aborted compilation stops at its next progress tick rather than possibly
  running to completion. Signatures unchanged. (#2238)
- `anthology.Format` renamed to `anthology.Artifact`, with its members unchanged
  (`Artifact.Source`, `Artifact.Ir`, `Artifact.Application`, `Artifact.Kind`,
  `Artifact.source`/`ir`/`application`, `Artifact(kind, id)`), and now exported by `soundness`:
  zephyrine's `Format` keeps that name there. Replace `anthology.Format` with `Artifact`. (#2263)
- The application nodes `anthology.Jar` and `anthology.Binary(triple)` moved into the companion,
  as `Artifact.Jar` and `Artifact.Binary(triple)`, reachable through `import soundness.*`
  (where `Jar` is zeppelin's and `Binary` monotonous's). `anthology.Triple` moved from the `nir`
  component to `core`; its package and name are unchanged. (#2263)

## anticipation

- `anticipation.LogSink` is classified `caps.SharedUnscoped` rather than `caps.Unscoped`, and
  `anticipation.Loggable` extends `caps.SharedCapability`: a logger is a shared capability
  (written to from every task at once) that captures its shared sinks. A task body may now
  capture and use a logger. A `given … is Loggable` that was typed without `^` and built with
  `new Loggable` must be typed `(… is Loggable)^`, since an instance of a capability class is
  `^`-typed; code classifying a sink or logger as exclusive must use `SharedCapability`. (#2212)
- New classifiers `anticipation.Durable` (`caps.SharedCapability`, safe to retain across a thread
  boundary) and `anticipation.DurableUnscoped` (a `Durable` that is also level-exempt, as
  `caps.SharedUnscoped`). `Loggable` is now `Durable` and `LogSink` `DurableUnscoped`; code that
  classified them as `SharedCapability`/`SharedUnscoped` still sees them as such, since both derive
  from those. (#2217)

## aperture

- New typeclass `aperture.Archivable` (`target is Archivable in Form to Result`, with an
  `Operand` flag type), applier `aperture.Archiver`, and extension `value.archive[form](flags*)`,
  the archiving counterpart of `open[form]`/`create[form]`: `directory.archive[Tar]()` yields a
  `Tarfile`, `directory.archive[Zip]()` a `Zipfile`, `directory.archive[Ar]()` an `Arfile`.
  Exported into `soundness` as `archive`, `Archivable` and `Archiver`. (#1713)
- `aperture.session` (the extension `value.session[result](using sessional: (target is
  Sessional)^)(lambda: (session: sessional.Result) ?=> result): result`) is no longer
  `transparent inline`, and is now `session[result, instance^, block^](using sessional: (target is
  Sessional)^{instance})(lambda: (session: sessional.Result^) ?->{block} result): result`.
  Capture checking now confines the handle to the block: a `result` whose type captures the
  handle — the handle itself, a closure over it, or a collection or other value holding it — is
  rejected as a capability that "outlives its scope", where before it compiled and outlived the
  closed session. Call sites that returned such a value from `session` must consume the handle
  inside the block; session-independent results are unaffected, and an explicit type argument
  `session[T]` must now also bind or omit the two capture-set parameters. (#2216)

## aviation

- `Tzdb.Entry.Rule#letters`, `Tzdb.Entry.Zone#location` and `Tzdb.ZoneInfo#until` changed from
  `Option[Text]` to `Optional[Text]`. Replace `Some(x)` with `x` and `None` with `Unset` when
  constructing them; when reading, use `.let`, `.or` and `.absent` in place of `.map`,
  `.getOrElse` and `.isEmpty`, or `.option` to recover an `Option`. (#2190)
- `Tzdb.parse` (and `Tzdb.parseFile`) accept a negative `STDOFF` or `SAVE` field, such as
  `-5:00`, and an hour count of 24 or more. A negative `Tzdb.Duration` has every component
  negated: `-0:30` is `Duration(0, -30, 0)` and `-4:56:02` is `Duration(-4, -56, -2)`. (#2258)

## baroque

- `baroque.Complex` can be scaled by a `Double` on either side: `Complex.multiplicableByDouble`
  (`Complex[component] is Multiplicable by Double`, for any `component` multiplicable by
  `Double`) and `Complex.doubleMultiplicable` (`Double is Multiplicable by Complex[component]`),
  so `i*1.8` and `2.0*complex` compile. (#2262)

## bitumen

- The `Tarfile.from(directory)` extension (`bitumen.from`, jvm component) is removed; write
  `directory.archive[Tar]()`. The receiver is any `Path on plane` with a `FilesystemBackend on
  plane` in scope, and the result is a `Tarfile` as before. A `DereferenceSymlinks` is still
  required (`filesystemOptions.preserveSymlinks` stores a `Symlink` entry, `dereferenceSymlinks`
  the target's contents); `TraversalOrder` and `plane is Explorable` are no longer needed, and
  the entries are now always sorted pre-order, each directory's children in codepoint order, so
  two archivings of one tree produce identical bytes. `bitumen.from` is no longer exported into
  `soundness`, so `soundness.from` is unambiguously rudiments' `value.from(ordinal)`. (#1713)
- `directory.archive[Tar](flags*)` takes `LongNameFormat.Pax | Gnu` (default `Pax`) and the new
  `bitumen.Archive.Flag`s: `Archive.Flag.Owner(user: UnixUser, group: UnixGroup)` and
  `Archive.Flag.Mtime(seconds: Long)` (also `Mtime(instant)` for any `Abstractable across
  Instants`), which replace the owner and timestamp recorded for every entry. The instances are
  `Tar.Archivable[plane]` and `Ar.Archivable[plane]`, nested in the format companions
  (`bitumen.core`, so available on every platform galilei supports). (#1713)
- New `directory.archive[Ar](flags*)`: `ar` has no directories, so every regular file beneath
  the root becomes a member named by its slash-joined relative path, symbolic links are followed,
  and a FIFO or device raises the new `Ar.Error.Reason.Unrepresentable(name: Text)` (`SN-286.9`).
  `mode` is the whole `st_mode`, as `ar` stores it. (#1713)
- `bitumen.Tar.Entry.apply` no longer takes an `mtime` parameter, nor an `instant` type
  parameter: it stamps the entry with the current time. A call that passed `mtime = instant`
  becomes `Tar.Entry.at(name, data, instant, …)`, whose `mtime` is the third parameter and
  whose `mode`, `user` and `group` keep their defaults, in the manner of `zeppelin.Zip.Entry.at`.
  (#2259)

## breviloquence

- `Cbor.Parser` (nested in `object Cbor`) is replaced by the top-level class
  `breviloquence.CborParser`, a stateful capability (`caps.ExclusiveCapability, caps.Stateful`)
  with a private constructor, built only by breviloquence's read paths; its direct-rim methods
  keep their names and signatures but are `update def`s, callable only through a `CborParser^`.
  Code that named `Cbor.Parser` as a type names `CborParser`; nothing outside breviloquence
  could construct one before either. (#1249)
- `Cbor.Ast.parse` gains a `Chain[Data]` overload; the `Data` overload is unchanged. (#1249)
- New public `inline def`s `Cbor.Reader.of(carrier: AnyRef): Cbor.Reader^` and
  `CborParser.of(carrier: AnyRef): CborParser^`, the reassertion points for generated
  parsers spliced into user modules (as `Cbor.Parsable.parseField` is). Hand-written code
  has no use for them. (#1249)
- Behaviour: `read[Cbor.Ast]`, `read[Cbor]` and `read[T in Cbor]` over a `Chain[Data]` or a
  `Stream[Data]` no longer assemble the input into one array before parsing; the chunks are read
  as they are pulled. A read through a `Cbor.Parsable` holds at most the one item being read (a
  sum's discriminant scan holds its map), so a large document streams in bounded memory. Error
  offsets are unchanged: absolute positions in the input. (#1249)
- `breviloquence.Inlinable` (with its companion) moved from the `breviloquence.staged` artifact
  to `breviloquence.core`; the fully-qualified name is unchanged, and `breviloquence.staged`
  still depends on `core`. A user-written `Inlinable` instance, and a sealed sum's
  `Discriminable in Cbor`, are still evaluated at expansion time only when `breviloquence.staged`
  is on the compile classpath; without it, `Inlinable.parsable` of a sum reports that the sum is
  not inlinable. `breviloquence.stagedInternal` is renamed to `breviloquence.inlining`. (#2251)
- `aggregableParsed` and `readableParsed` are typed with the capture of their `parsable` and
  `tactic`, as in `((value in Cbor) is Aggregable by Data)^{parsable, tactic}`, rather than
  being sealed pure. A summon that names the type must allow the capture, as in `summon[(… )^]`; resolving through `read`, `as` or derivation needs no change. (#2229)

## build

- Soundness is compiled with Proscala `3.9.1-dev-p18` (was `3.9.1-dev-p17`); `build.mill`'s
  defaults for `SOUNDNESS_SCALA_RELEASE` and `SOUNDNESS_SCALA_VERSION` are both `3.9.1-dev-p18`.
  The release adds `scala.caps.SharedUnscoped` (the shared, level-exempt classifier
  `contingency`'s ambient strategies now carry) and fixes a capture-checker crash
  (`attempting to add any to {any} of value …$proxyN`) when an inferred value type holds two
  fresh capabilities of unrelated classifiers. A consumer compiles against the same fork
  version. (#2195)
- Soundness is compiled with Proscala `3.9.1-dev-p19` (was `3.9.1-dev-p18`), in which
  `scala.caps.SharedUnscoped` ships in the supplementary `proscala-library` jar rather than in
  `scala-library`, which is again byte-identical to upstream's; the compiler looks the trait up
  leniently, so a classpath without that jar simply has no capability classified that way. A
  consumer resolving `dev.propensive:scala-library` gets `proscala-library` as its dependency,
  as before. (#2202)
- `make test`, `make test.<lib>`, `make ci`, `make bench` and `make bench.<lib>` run fume through
  `etc/ci/fume-run.sh`, which gives each run a private daemon and a private temporary directory
  (`java.io.tmpdir` for the suites, `TMPDIR` for what they shell out to) and removes both when
  the run ends, so a suite's scratch files never outlive the run and no fume daemon is left
  behind. A test that wants a scratch directory uses galilei's existing loan,
  `temporaryDirectory[Path on Linux].open[Scratch](Read & Write): handle ?=> …`, rather than
  `temporaryDirectory / Uuid()`, which nothing deletes. No library's API changes. (#2207)
- Benchmark modules (`trait Benchmarks` in `build.mill`) compile with separation checking by
  default, like libraries and test suites; a bench against a rival library that cannot take the
  fork's flags opts down in its own `scalacOptions`. No library's API changes. (#2202)
- The tools in `etc/tools` are flair 0.7.0 (the compiler plugin Soundness is compiled with),
  fume 0.8.1 (the test runner) and flame 0.7.1, the last two built against Pyrocosm 0.7.0
  (were flair 0.5.0, fume 0.6.0 and flame 0.5.0). No library's API changes.
- `etc/xek.tsv` pins xek 1.3.0 (was 1.2.0), and `etc/ci/xek-fetch.sh` fetches only releases
  tagged with the bare version, from 1.0.0; a pin naming an `xek-0.x` or `xeq-0.x` builder no
  longer resolves. The build fetches the builder safely when several test modules resolve it
  at once on a cold cache, which failed when they shared one temporary file. No library's API
  changes.
- The pinned compiler is proscala `3.9.1-dev-p20`, which adds `classifiermeet`: a class may
  inherit two unrelated capture classifiers when another classifier among its base classes
  derives from both (their meet). Needed for `anticipation.DurableUnscoped`. (#2217)
- Soundness is compiled with Proscala `1.0.0`'s build for Scala `3.10.0`, version
  `3.10.0-pro-1.0.0` (was `3.9.1-dev-p20`). A Proscala release from 1.0.0 is built for several
  Scala versions, each shipped as `proscala-<scala version>.tar.gz` and versioned
  `<scala version>-pro-<release>`: `build.mill`'s `SOUNDNESS_SCALA_RELEASE` (default `1.0.0`)
  selects the release and the new `SOUNDNESS_SCALA_BASE` (default `3.10.0`) the Scala version,
  so `SOUNDNESS_SCALA_BASE=3.9.0` selects the 3.9 build; `SOUNDNESS_SCALA_VERSION` overrides the
  composed version, a release from before 1.0.0 is still named by its tag, and
  `SOUNDNESS_SCALA_HOME` still names a local build. `rep/toolchain.sh` takes the same
  variables. The published artifacts carry Scala 3.10 TASTy, which a 3.9 compiler cannot read:
  a consumer compiles with the same fork build, and on the 3.10 stream Scala Native's
  `nscplugin`/`scala3lib_native` artifacts are those published for `3.10.0` (`3.9.0-RC3` on
  the 3.9 build). (#2269)
- The pinned compiler is Proscala `1.0.1` (`3.10.0-pro-1.0.1`, was `3.10.0-pro-1.0.0`), which
  restores the Scala.js scalalib's link-time Wasm guards on Scala 3.10.0 (1.0.0's `ArrayBuilder`,
  `Buffer` and `IndexedBuffer` lacked them), so a Wasm-only component links again. `make attest` runs the `wasm-e2e` stage on every toolchain
  once more; the skip for 1.0.0 is gone (#2272). No library's API changes.

## cacophony

- `Audio.apply(format, data)` takes the samples as a frozen `Array[Byte]^{}` (was a mutable
  `scala.Array[Byte]`), and `Audio` extends `caps.Pure`: an audio value never shares a writable
  array with its caller, so it is immutable and may be shared freely. Freeze the array before
  constructing: `Audio[Wav](format, Array.freeze(samples))` for an exclusive proscenium
  `Array[Byte]^`, or `Array.unsafeFrozen(bytes)` for a JVM array the caller provably no longer
  writes (a fresh copy, or `readAllBytes`'s result). (#2221)
- `cacophony.Playback#stop()` returned by `Outlet#play` is reliably observed by the playback
  thread (the flag is atomic), and the line is stopped and closed exactly once whether `stop()`
  or the end of the audio comes first. Signatures unchanged. (#2238)

## caesura

- The primitive cell decoders (`int`, `long`, `double`, `float`, `boolean`, `text`, `string`),
  `optionalDecodable`, the `Sheet` and direct-read `aggregable`s, and the `Dsv.Field` bridge
  are typed with the capture of the tactic or decoder they hold, as in
  `(Int is Decodable in Dsv)^{tactic}`, rather than being sealed pure. `Dsv#as` and `Sheet#as`
  take capturing evidence, `(using decodable: (value is Decodable in Dsv)^)`, followed by
  plain `Tactic[Dsv.Error]` and `Foci[CellRef]` parameters, rather than a context bound and a
  `raises … tracks …` result; calls are unchanged. A summon that names the type must allow the capture, as in `summon[(… )^]`; resolving through `read`, `as` or derivation needs no change. (#2229)
- `caesura.Dsv2.aggregableIn` (`read[Foo in Dsv]` without a `Dsv.Parsable`) takes an additional
  `using` parameter `buffering: zephyrine.Buffering`, which resolves to `Buffering.standard`
  unless one is in scope. From a stream source it now reads only the first record, as far as it
  extends, instead of parsing every row into a `Sheet` first. (#2252)

## clavichord

- `clavichord.Keypress.EditKey` is `Keypress & Keypress.Editing`, an intersection with the new
  sealed marker trait `Keypress.Editing` that the fourteen editing-key cases (`Tab` … `Down`)
  extend, rather than a union of those cases' singleton types. `Keypress.Shift(Keypress.Enter)`
  and the other modifier cases now typecheck through `soundness.Keypress`; the by-name
  `import clavichord.Keypress` workaround can go. (#2257)

## coaxial

- `listenConnections`'s `handler` is `Connection ->{caps.any.only[caps.SharedCapability]} Unit`:
  each connection is handled on a task, so the handler may capture only shared capabilities.
  (#2212)
- The DNS extension `endpoint.lookup(name, rtype)` on `Endpoint[Udp.Port]` is now an overload of
  `query`: `endpoint.query(name: Dns.Name, rtype: Dns.Type = Dns.Type.A): List[Dns.Record]`,
  beside `query(message: Dns.Message): Dns.Message`. `soundness` exports anamnesis's
  `lookup`, which keeps the name. Replace `.lookup(` with `.query(` on a nameserver endpoint.
  (#2256)

## contingency

- `contingency.Emit` (and so `Tactic`) extends `caps.SharedCapability` instead of
  `caps.ExclusiveCapability`. Aliasing one tactic — a codec capturing the ambient tactic that
  the same call also takes as evidence, as `Json#as` does — is no longer a separation failure,
  so a `caps.unsafe.unsafeAssumeSeparate(json.as[…])` (or around `Llm.fetch`, `JsonRpc.serve`,
  an `abort(…)` thunk) can be deleted. A subclass of `Emit` may retain only shared capabilities
  and pure values: one holding an exclusive capability or an impure function must drop it, and
  one that also extended `caps.Unscoped` fails with "inherits two unrelated classifier traits" —
  extend `caps.SharedUnscoped` instead, as `ThrowTactic`, `UncheckedTactic` and `FatalTactic` now
  do. (#2195)
- `Emit#contramap` and `Tactic#contramap` take a pure `error2 -> error` (was `error2 => error`)
  and return `Emit[error2]^{this}` / `Tactic[error2]^{this}` (was `^`). An error transformer that
  captured a capability no longer compiles; every existing caller passed an error constructor,
  which is pure. (#2195)
- `Emit.apply` takes `consume handler: error ->{caps.any.only[caps.SharedCapability]} Unit` (was
  `error => Unit`): a `handle` case body may raise into an outer tactic but may not use an
  exclusive capability (a log sink, a stream, a mutable handle); move such work out of the case
  body. (#2195)
- `accrue(initial)(combine)`'s `combine`, and `Accrual.AccrueTactic`'s and `Accrual`'s, is
  `(accrual, Exception) -> accrual` (was `=>`), as its contract already required. (#2195)
- `import strategies.throwUnsafely` inside a method that decodes a derived codec with an
  `Optional`/collection field no longer needs any workaround under the new release; on
  `3.9.1-dev-p17` the same code fails with "capability `any` cannot flow into capture set {any²}
  … not visible from any² in value wisteria$field$N" — if a consumer must stay on p17, bind a
  local `given tactic: Tactic[Json.Error] = ThrowTactic()` instead of the import. (#2195)

## dendrology

- `dendrology.DagDiagram.apply[node](dag: Dag[node]): DagDiagram[node] raises Dag.Error`,
  `LaneDagDiagram.apply` and `LayeredDagDiagram.apply` are now
  `apply[graph, node](graph: graph)(using graph is acyclicity.Nodal by node, graph is
  acyclicity.Topological): …Diagram[node]`, with no `raises`: any graph that admits a topological
  order draws — a `Dag`, a frozen `Topology[node]^{}`, a `Hasse`. A `Dag` argument needs no
