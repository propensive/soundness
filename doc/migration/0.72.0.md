# Changes since 0.71.0

This file is read by an LLM agent to upgrade code that consumes Soundness libraries from
0.71.0 to the next release. Each entry states precisely what changed; see `AGENTS.md` for the
format. Entries are grouped by module, most-recently-added last within a module.

## anticipation

- `anticipation.LogSink` is classified `caps.SharedUnscoped` rather than `caps.Unscoped`, and
  `anticipation.Loggable` extends `caps.SharedCapability`: a logger is a shared capability
  (written to from every task at once) that captures its shared sinks. A task body may now
  capture and use a logger. A `given … is Loggable` that was typed without `^` and built with
  `new Loggable` must be typed `(… is Loggable)^`, since an instance of a capability class is
  `^`-typed; code classifying a sink or logger as exclusive must use `SharedCapability`. (#2212)
- New classifiers `anticipation.Durable` (`caps.SharedCapability`, safe to retain across a thread
  boundary) and `anticipation.DurableUnscoped` (a `Durable` that is also level-exempt, as
  `caps.SharedUnscoped`). `Loggable` is now `Durable` and `LogSink` `DurableUnscoped`; code that
  classified them as `SharedCapability`/`SharedUnscoped` still sees them as such, since both derive
  from those. (#2217)

## aviation

- `Tzdb.Entry.Rule#letters`, `Tzdb.Entry.Zone#location` and `Tzdb.ZoneInfo#until` changed from
  `Option[Text]` to `Optional[Text]`. Replace `Some(x)` with `x` and `None` with `Unset` when
  constructing them; when reading, use `.let`, `.or` and `.absent` in place of `.map`,
  `.getOrElse` and `.isEmpty`, or `.option` to recover an `Option`. (#2190)

## build

- Soundness is compiled with Proscala `3.9.1-dev-p18` (was `3.9.1-dev-p17`); `build.mill`'s
  defaults for `SOUNDNESS_SCALA_RELEASE` and `SOUNDNESS_SCALA_VERSION` are both `3.9.1-dev-p18`.
  The release adds `scala.caps.SharedUnscoped` (the shared, level-exempt classifier
  `contingency`'s ambient strategies now carry) and fixes a capture-checker crash
  (`attempting to add any to {any} of value …$proxyN`) when an inferred value type holds two
  fresh capabilities of unrelated classifiers. A consumer compiles against the same fork
  version. (#2195)
- Soundness is compiled with Proscala `3.9.1-dev-p19` (was `3.9.1-dev-p18`), in which
  `scala.caps.SharedUnscoped` ships in the supplementary `proscala-library` jar rather than in
  `scala-library`, which is again byte-identical to upstream's; the compiler looks the trait up
  leniently, so a classpath without that jar simply has no capability classified that way. A
  consumer resolving `dev.propensive:scala-library` gets `proscala-library` as its dependency,
  as before. (#2202)
- `make test`, `make test.<lib>`, `make ci`, `make bench` and `make bench.<lib>` run fume through
  `etc/ci/fume-run.sh`, which gives each run a private daemon and a private temporary directory
  (`java.io.tmpdir` for the suites, `TMPDIR` for what they shell out to) and removes both when
  the run ends, so a suite's scratch files never outlive the run and no fume daemon is left
  behind. A test that wants a scratch directory uses galilei's existing loan,
  `temporaryDirectory[Path on Linux].open[Scratch](Read & Write): handle ?=> …`, rather than
  `temporaryDirectory / Uuid()`, which nothing deletes. No library's API changes. (#2207)
- Benchmark modules (`trait Benchmarks` in `build.mill`) compile with separation checking by
  default, like libraries and test suites; a bench against a rival library that cannot take the
  fork's flags opts down in its own `scalacOptions`. No library's API changes. (#2202)
- The tools in `etc/tools` are flair 0.6.0 (the compiler plugin Soundness is compiled with),
  fume 0.7.0 (the test runner) and flame 0.6.0, each built against Soundness 0.71.0 and
  Pyrocosm 0.6.0 (were flair 0.5.0, fume 0.6.0 and flame 0.5.0). No library's API changes.
- `etc/xek.tsv` pins xek 1.3.0 (was 1.2.0), and `etc/ci/xek-fetch.sh` fetches only releases
  tagged with the bare version, from 1.0.0; a pin naming an `xek-0.x` or `xeq-0.x` builder no
  longer resolves. The build fetches the builder safely when several test modules resolve it
  at once on a cold cache, which failed when they shared one temporary file. No library's API
  changes.
- The pinned compiler is proscala `3.9.1-dev-p20`, which adds `classifiermeet`: a class may
  inherit two unrelated capture classifiers when another classifier among its base classes
  derives from both (their meet). Needed for `anticipation.DurableUnscoped`. (#2217)

## contingency

- `contingency.Emit` (and so `Tactic`) extends `caps.SharedCapability` instead of
  `caps.ExclusiveCapability`. Aliasing one tactic — a codec capturing the ambient tactic that
  the same call also takes as evidence, as `Json#as` does — is no longer a separation failure,
  so a `caps.unsafe.unsafeAssumeSeparate(json.as[…])` (or around `Llm.fetch`, `JsonRpc.serve`,
  an `abort(…)` thunk) can be deleted. A subclass of `Emit` may retain only shared capabilities
  and pure values: one holding an exclusive capability or an impure function must drop it, and
  one that also extended `caps.Unscoped` fails with "inherits two unrelated classifier traits" —
  extend `caps.SharedUnscoped` instead, as `ThrowTactic`, `UncheckedTactic` and `FatalTactic` now
  do. (#2195)
- `Emit#contramap` and `Tactic#contramap` take a pure `error2 -> error` (was `error2 => error`)
  and return `Emit[error2]^{this}` / `Tactic[error2]^{this}` (was `^`). An error transformer that
  captured a capability no longer compiles; every existing caller passed an error constructor,
  which is pure. (#2195)
- `Emit.apply` takes `consume handler: error ->{caps.any.only[caps.SharedCapability]} Unit` (was
  `error => Unit`): a `handle` case body may raise into an outer tactic but may not use an
  exclusive capability (a log sink, a stream, a mutable handle); move such work out of the case
  body. (#2195)
- `accrue(initial)(combine)`'s `combine`, and `Accrual.AccrueTactic`'s and `Accrual`'s, is
  `(accrual, Exception) -> accrual` (was `=>`), as its contract already required. (#2195)
- `import strategies.throwUnsafely` inside a method that decodes a derived codec with an
  `Optional`/collection field no longer needs any workaround under the new release; on
  `3.9.1-dev-p17` the same code fails with "capability `any` cannot flow into capture set {any²}
  … not visible from any² in value wisteria$field$N" — if a consumer must stay on p17, bind a
  local `given tactic: Tactic[Json.Error] = ThrowTactic()` instead of the import. (#2195)

## espionage

- `Acp.Observer`, `Acp.Registry`, `Acp.Connection` and `Acp.Service` are `caps.SharedCapability`,
  for the reasons given for their exegesis counterparts; `Acp.Observer.Silent` is a `val` of
  type `Observer^{}`. `Acp.connect` loses its `capture^` type parameter: its connection block
  is `(connection: Acp.Connection) ?=> result` and it takes `using Monitor^`, since a monitor
  is shared and the block may capture it freely. (#2212)
- `Acp.Connection`, `Acp.Registry` and `Acp.Service` are `anticipation.Durable`, and `Acp.Observer`
  is `anticipation.DurableUnscoped`. (#2217)

## ethereal

- `ethereal.cli`'s block is `(Resident over bus, Interface, Environment, Monitor)
  ?->{caps.any.only[caps.SharedCapability]} Return`: it runs once per client connection, on that
  connection's task, so it may capture only shared capabilities (the daemon's monitor, logger
  and standard streams are). A block that closed over an exclusive resource must open and own
  it inside the block. (#2212)

## exegesis

- `Lsp.Observer` is a `caps.SharedCapability` (called from the writer and reader tasks at once);
  `Lsp.Observer.Silent` is a `val` of type `Observer^{}` rather than an object, and the given
  `Lsp.Observer.silent` is typed `Observer^{}`. `Lsp.Registry` and `Lsp.Connection` are
  `caps.SharedCapability` (registered before serving and read from every task; driven by the
  writer, reader and caller at once). `Lsp.Registry#adjust0` holds a shared-only function. (#2212)
- `Lsp.proxy` loses its `capture^` type parameter: its registration block is
  `(proxy: Lsp.Proxy^) ?=> Unit` and it takes `using Monitor^`. `Lsp.Client`, `Lsp.Connection` and
  `Lsp.Registry` are `anticipation.Durable`, and `Lsp.Observer` is `anticipation.DurableUnscoped`;
  `JsonRpc.serve`'s dispatcher is `Json ->{caps.any.only[Durable]} Optional[Json]`. (#2217)

## exoskeleton

- `exoskeleton.Enclave.Tool` (the test rig's built-tool descriptor) is classified
  `caps.SharedCapability` rather than `caps.ExclusiveCapability`: every tmux session of a suite
  drives the one tool, so a session's action may capture it while the `tmux` loan receives it.
  The `caps.unsafe.unsafeAssumeSeparate(Shell.tmux()(…))` wrappers this needed can go. (#2212)

## galilei

- `Platform.pathReadable` and `Platform.pathWritable` are declared for a bounded subject,
  `[plane <: Platform: Filesystem, path <: Path on plane]`, rather than for exactly `Path on
  plane`. `p"/tmp/x.txt".read[Text]`, `(% / "tmp" / name).on[Posix].read[Text]` and
  `path.write(…)` on any subtype of `Path on plane` now resolve, where they previously needed an
  ascription to `Path on plane` (`Self` is invariant). Code that applies either given explicitly
  passes the path type: `Platform.pathReadable[plane, Path on plane, result]`. The write body
  is the new public method `Platform.writeWhole[plane](path, stream)`. (#2191)
- A `p"…"` literal's `Topic` is the tuple of its elements' literal types, leaf first, as `/`
  builds it: `p"/foo/bar/baz"` is a `Path of ("baz", "bar", "foo") under %.type on Posix`
  (was `Path of Tuple …`), and `p"""C:\Windows\System32"""` is a `Path of ("System32",
  "Windows") under Drive on Windows`. A value typed exactly `Path of Tuple` is no longer a
  supertype of a literal; drop the `of Tuple`. (#2198)

## gossamer

- `Text#sub(from: Text, to: Text)` and `sub(from: Text, to: Text, count: Int)` now insert `to`
  verbatim: a `\` or `$` in the replacement is no longer interpreted as a Java replacement
  escape or group reference (`t"a.b".sub(t".", t"\\.")` gives `a\.b`, was `a.b`, and
  `t"x".sub(t"x", t"$1")` gives `$1`, where it threw). The `Regex` overloads are unchanged, so
  `$1` in a regex substitution still refers to the first group. Code that relied on doubling a
  backslash in a literal replacement to insert one should write it singly. (#2182)

## guillotine

- The `Pid is Decodable in Text` given now raises `Number.Error(text, Long, Unparseable)` for a
  malformed value, rather than `Number.Error(text, Int, Unparseable)`; it parses a `Long`. (#2190)
- `guillotine.Process` and `guillotine.Job` are classified `caps.SharedCapability` rather than
  `caps.ExclusiveCapability`: a job's output streams are drained by one task each while another
  awaits its exit, and the handle may be aborted from a third. A task body may therefore capture
  a `Job^`; code that classified a job as exclusive (an `only[ExclusiveCapability]` set) must use
  `SharedCapability`. (#2212)
- `Process` and `Job` are `anticipation.Durable`. (#2217)

## hellenism

- `ClassRef[T]` and `Classloader[T]` resolve a nested type: a proper type is linked with
  `classOf`, and an unapplied type constructor is looked up by its JVM binary name
  (`ethereal.Launcher$Message`), where both were looked up by the dotted source name and threw
  `ClassNotFoundException` for a type nested in an object or class. A `ClassRef[T]` for a
  proper type now binds the class the caller links against, not whatever the caller's defining
  loader finds by name. (#2188)

## honeycomb

- The extensions `values`, `toList`, `map` and `foreach` on `honeycomb.Attributes` removed.
  `Attributes` is now `Traversable by (Text, Optional[Text])`, in document order, so write
  `attributes.to[List]` for `attributes.toList` (it yields a `proscenium.List` rather than a
  stdlib `List`); `attributes.iterator` still yields the pairs, and `attributes.each` and
  `attributes.toMap` remain. A `for` loop over an `Attributes` value, which used `foreach`, must
  iterate `attributes.iterator` or use `each`. (#2190)
- `Document[Html]#metadata` is now an `Html.Provenance` (was the bare `Dom`), with the DOM at
  `metadata.dom` and, when the document was loaded under `parsing.trackPositions`, its
  position index at `metadata.positionIndex`. Construct a document with
  `Document(root, Html.Provenance(dom))` in place of `Document(root, dom)`, and read
  `document.metadata.dom` where `document.metadata` was used as a `Dom`. The index takes no
  part in equality, so a tracked and an untracked load compare equal.
- `Html` now records source positions on `load` when `parsing.trackPositions` is in scope,
  through the shared scheme: `given Document[Html] is Positionable by Html.Path to
  Html.Position` resolves `document.locate(path)` to the line, column and char length of the
  element (or attribute) a root-first `Html.Path` names, built as
  `Html.Path().element(t"html").element(t"body").element(t"p", 2).attribute(t"class")`;
  `locateKey` is always `Unset`. New types `Html.Path`, `Html.Path.Step` and
  `Html.PositionIndex`. `read[Html]` fragments stay untracked.

## obligatory

- `JsonRpc.serve[interface](interface)` returns `Json ->{caps.any.only[caps.SharedCapability]} Optional[Json]`
  rather than `Json => Optional[Json]`: a dispatcher closes over its interface alone, and may be
  called from a task when the interface is pure or shared. (#2212)

## parasite

- `parasite.delay[duration: Abstractable across Durations to Long](duration: duration)(using
  Monitor^): Unit` removed. Replaced by `parasite.sleep(duration)`. Behaviour change: `delay`
  was documented as uninterruptible but a cancelled task's `delay` in fact ended at once with
  `InterruptedException`; `sleep` always waits out its whole duration, and the cancelled task
  stops at its next `snooze` or `relent()` instead. (#2209)
- `parasite.hibernate[instant: Abstractable across Instants to Long](instant: instant)(using
  Monitor^): Unit` removed. Replaced by `parasite.sleep(instant)`, with the same behaviour
  change as `delay`. (#2209)
- `parasite.sleep` retyped from `[instant: Abstractable across Instants to Long](instant:
  instant)` to `[time: Schedulable](time: time)`, and its meaning changed: it now waits out its
  whole deadline whether given a duration or an instant (formerly `delay` and `hibernate`),
  where before it was the *interruptible* instant form. Code that called `sleep(instant)` and
  relied on cancellation waking it must call `snooze(instant)` instead. (#2209)
- `parasite.snooze` retyped from `[duration: Abstractable across Durations to Long](duration:
  duration)` to `[time: Schedulable](time: time)`. It now also accepts an instant, pausing
  interruptibly until it arrives; for a duration its behaviour is unchanged. (#2209)
- `parasite.Task.sleep` retyped from `[duration: Abstractable across Durations to Long]` to
  `[time: Schedulable]`; it accepts instants too. (#2209)
- New typeclass `parasite.Schedulable` (exported by `soundness`), the bound shared by
  `snooze` and `sleep`, with companion givens `Schedulable.duration` for any `Abstractable across
  Durations to Long` and `Schedulable.instant` for any `Abstractable across Instants to Long`.
  Consequence: a bare `Long` passed to `snooze` or `sleep` in a file with both a duration unit
  given (`abstractables.nanosecondsAbstractable`, `microsecondsAbstractable` or
  `millisecondsAbstractable`) and `abstractables.epochMillisecondsAbstractable` in scope is now
  an ambiguous-given error, where previously `snooze(long)` read it as a duration and
  `sleep(long)` as an instant. Import exactly one of the two readings in such a file. (#2209)
- `parasite.Monitor` is classified `caps.SharedCapability` rather than `caps.ExclusiveCapability`.
  A task handle still captures the monitor it was spawned under and cannot leave its `supervise`
  block, but separation checking no longer reports an overlap when a handle that captures a
  monitor is joined with the same monitor as a using-argument — `task.await()` under `supervise`,
  or a loan such as `Shell.tmux()(Tmux.completions(…))` — so the
  `caps.unsafe.unsafeAssumeSeparate(…)` wrappers those calls needed can be removed. Code that
  classifies capabilities by `Monitor`'s classifier (a `caps.any.only[ExclusiveCapability]` set
  expected to include a monitor) must use `SharedCapability`. (#2212)
- Because a task handle is a shared `Monitor`, what a task retains must be shared: the bodies of
  `async`, `task`, `Task.apply`, `Task#map`/`bind`, `Timeout`'s action and `concurrently`'s job
  are typed `->{caps.any.only[caps.SharedCapability]}`. A body may capture a `Monitor`, a task
  handle, a `Tactic`/`Emit`, and plain values, but no longer an *exclusive* capability (a
  `Producer^`, a stateful parser, an open file handle): such code now fails with "Reference `x`
  is not included in the allowed capture set {any.only[SharedCapability]}". Move the exclusive
  resource inside the body (open and own it there), or pass data rather than the handle. A
  `Probate` a task retains is `parasite.SharedProbate` (`Probate^{caps.any.only[caps.SharedCapability]}`),
  which every `(using Monitor^, Probate^)` signature becomes; pure probates and `failProbate`
  conform. `daemon` bodies were already pure and are unchanged. (#2212)
- New: `resource.transfer(body)` and `resource.transfer(name)(body)` spawn a task that
  *owns* an exclusive resource. The resource is consumed from the caller (it may not be used
  afterwards) and reaches the body as its first context parameter, a `Task.Owned[resource]`
  carrier read with `apply()`: `producer.transfer: (producer, _, _) ?=> producer().put(…)`.
  This is how a task feeds a `Producer`, pumps a `Stream`, or runs a loop object under the
  shared-only body rule; take a producer's `iterator` (the reader side) before transferring it.
  (#2212)
- `concurrently`'s job is `Int ->{caps.any.only[caps.SharedCapability]} result`, `Timeout`'s
  action `->{caps.any.only[caps.SharedCapability]} Unit`, and `Task#map`/`bind`'s lambdas
  likewise: each runs on a task. (#2212)
- `parasite.Timeout` is classified `caps.SharedCapability` rather than `caps.ExclusiveCapability`:
  it is nudged from whichever task sees activity. (#2212)
- Task bodies are `->{caps.any.only[anticipation.Durable]}` rather than
  `->{caps.any.only[caps.SharedCapability]}`, and `SharedProbate` is `Probate^{caps.any.only[Durable]}`:
  a body may capture monitors, task handles, loggers, processes, connections and other `Durable`
  capabilities, but no longer a `Tactic` or `Emit`, which belongs to the stack that installed it.
  Raise from a task through its own tactic (the body's context `Tactic[error]`), whose errors
  arrive at `await`. Code that raised through an outer tactic from a task body now fails with
  "Reference `tactic` is not included in the allowed capture set {any.only[Durable]}". The same
  restriction applies to `Task#map`/`bind`, `Timeout`'s action and `concurrently`'s job; `Monitor`
  and `Timeout` are `Durable`. (#2217)

## rudiments

- `rudiments.Loop` is a `caps.SharedCapability`: it runs on one task and is stopped from another.
  `loop(block)`'s block is `->{caps.any.only[caps.SharedCapability]} Unit` and `loop` returns
  `Loop^{block, caps.any}`; a block that mutated a captured local `var` keeps its state in an
  `Atomic` cell instead. (#2212)
- `Loop` is `anticipation.Durable`, and `loop`'s block is `->{caps.any.only[Durable]}`. (#2217)

## coaxial

- `listenConnections`'s `handler` is `Connection ->{caps.any.only[caps.SharedCapability]} Unit`:
  each connection is handled on a task, so the handler may capture only shared capabilities.
  (#2212)

## probably

- `Benchmark` gains `operationQuantity: Optional[Double]` (default `Unset`), the size of one
  operation as a number in the unit `operationSize` names. `TestEvent` is unchanged, so the
  event stream's layout and fingerprint are as before.

## savagery

- `Svg.aggregable`, `Svg.loadable` and `Svg.loadableData` no longer take an `XmlSchema`: the
  XML beneath an SVG is parsed against `XmlSchema.Freeform`, since SVG's vocabulary is fixed and
  validated by the figure types. A `given XmlSchema = XmlSchema.Freeform` written to satisfy
  them can be removed; a different schema was never meaningful there. (#2194)
- `Svg` has two new fields with defaults, `unit: Optional[Svg.Units] = Unset` (the unit its
  `width` and `height` carry, `Svg.Units.Mm` for `width="48.5mm"`; `Unset` is user units) and
  `viewBox: Optional[Svg.ViewBox] = Unset` (`Svg.ViewBox(x, y, width, height)`; `Unset` is the
  viewport from the origin). `Svg.Parser` reads the SVG `<length>` grammar for the root
  `width`/`height` (a unit suffix previously made both `0.0`) and the `viewBox` on its own, and
  `svg.in[Xml]` writes the unit back and the viewBox it read. A present but unparsable
  `width`/`height` or `viewBox`, or a `width` and `height` with different units, raises
  `Svg.Error` with the new reasons `MalformedLength`, `MalformedViewBox` and `MismatchedUnits`
  (was silently `0.0`). The rendered `viewBox` of an `Svg` with no `viewBox` set now writes its
  origin as `0.0 0.0` (was `0 0`), so it reads back as what it wrote; `width="100.0"` and
  `height="100.0"` are unchanged. (#2192)
## sedentary

- `OperationSize` gains a third field, `value: Double`, the quantity in its base unit; the
  `Quantity` conversion supplies it. Code constructing `OperationSize(sizeText, rateText)`
  directly must pass the value.
- `Bench.Plan#sized` sizes each cell of an axial benchmark by its coordinates:
  `plan.sized((_: Parser, document: Document) => size(document))` followed by
  `.over(Axis(Parser), Axis(Document))(body)`, or a one-argument function for a single
  axis. It returns `Bench.Plan.Uniaxial[value]` or
  `Bench.Plan.Biaxial[left, right]`, whose `over` takes `Axis` values only (wrap an enum
  companion in `Axis(...)`); a cell for which the function answers `Unset` uses the plan's
  `operationSize`. The unsized `Plan#over` overloads are unchanged.

## sibylline

- `Llm.Dialect#stream(turn: Exchange)` returns `Iterator[Event]^{this, caps.any}` rather than
  `Iterator[Event]^{this}`: the iterator also captures the fresh streaming state it advances. An
  implementation of `Dialect` (a custom provider adapter, or a test fake) must declare the wider
  result type on its override; a caller that stores the iterator in a value typed `^{dialect}`
  widens that type likewise. The `Session`/`Response` API is unchanged, including the guarantee
  that a streamed `Response` cannot outlive its session. (#2210)

## jacinta

- `Json.parseTracked` (the `Data`, `Iterator[Data]` and `Text` overloads) removed, along with
  the public `Json.Ast.parseTracked`. Position tracking is selected by the shared
  `zephyrine.PositionTracking` toggle: replace `Json.parseTracked(source).locate(p)` with
  `source.read[Json].locate(p)` under `import parsing.trackPositions` (a `Text` source still
  needs a `Codepage` in scope, as for any `read[Json]`).

## stratiform

- `stratiform.Tel.Metadata` gains a fourth, defaulted parameter, `continuation: Optional[Int] =
  Unset`: the 1-indexed source line on which the content after the document separator (`##`)
  begins, or `Unset` when the document ended at end of input. Construction with three arguments
  is unchanged; a pattern `case Tel.Metadata(directive, pragma, lineEndings)` must add a fourth
  binder. (#2196)

## profanity

- `profanity.Board` extends `caps.ExclusiveCapability, caps.Stateful`, and its drawing
  operations — `move`, `put` (both overloads), `clear`, `clearLine`, `cursor`, `showCaret`,
  `flush` — are `update def`s. An implementation marks its overrides `update def` (and any
  helper that assigns its state); a caller holds a board as `Board^` and may not draw through a
  read-only alias. `width`/`height` stay read-only, so an implementation may not compute them
  from a captured impure function: `TerminalBoard`'s size thunks are
  `() ->{caps.any.rd} Int`. (#2206)
- `TerminalBoard.apply(terminal: Terminal)` returns `TerminalBoard^{terminal.rd, caps.any}`
  (was `TerminalBoard^{terminal}`); `TerminalBoard.apply(width, height)` and
  `InlineBoard.apply(terminal)` return a fresh `^` (were plain); `Board.inlineBoard` gives
  `Board^`. Bind the result to a `val` before passing it where a fresh `Board^` is expected. (#2206)
- `profanity.Terminal` extends `caps.Stateful`; its `mode_=`, `rows_=` and `columns_=` setters
  are `update def`s, so assigning them needs an exclusive `Terminal^`. Reading `knownColumns`/
  `knownRows` from a closure captures `terminal.rd`. (#2206)


## ultimatum

- `GridSurface`, `ScreenRoot`, `InlineRoot`, `FlowExtent` and `Extent` follow `Board`: their
  drawing and framing methods (`reshape`, `reframe`, `reset`, `anchor`, `finish`, …) are
  `update def`s. `ScreenRoot.apply(terminal)`/`InlineRoot.apply(terminal)` return
  `X^{terminal.rd, caps.any}` (were `X^{terminal}`); `ScreenRoot.apply(width, height)` and
  `InlineRoot.apply(width, height)` return a fresh `X^`. `ScreenRoot` and `InlineRoot` take
  size thunks typed `() ->{caps.any.rd} Int` (were `() => Int`). A `FlowExtent` used as a
  `Stdio` is given as `(Stdio^{extent})`. (#2206)
- `ultimatum.Form` is a stateful, exclusive capability (`caps.ExclusiveCapability`,
  `caps.Stateful`): `Form(...)` is a companion `apply` with the constructor's parameters and
  defaults, returning `Form^{root, wake, scheduleWake, caps.any}` — the form retains its board and
  its wake callbacks — and `run` is an `update` method. A form is owned by the call that runs
  it: hold it in a local or pass it as `Form^`; a closure that captures it holds it read-only and
  cannot call `run`. The `ultimatum.form` entry points are unchanged. (#2210)


## syndesis

- `syndesis.Discovery.Backend#advertise(service: Discovery.Service, description:
  Discovery.Description)(using Monitor^, Probate^, Tactic[Discovery.Error])` now returns
  `Discovery.Advertising` (new trait, one member `def instance: Discovery.Instance`) instead of
  `Discovery.Instance`, and `Discovery.Backend#withdraw` takes `(advertising:
  Discovery.Advertising)(using Monitor^)` instead of `(instance: Discovery.Instance)(using
  Monitor^)`. A `Backend` implementation must return a handle and accept it back; a caller using
  the seam directly reads the name as `advertising.instance`. The loan
  `service.advertise(description) { … }` is unchanged. (#2186)
- `syndesis.Discovery.Advertisement`'s constructor takes `(advertising: Discovery.Advertising)`
  instead of `(val instance: Discovery.Instance)`; `instance` is now a `def` that reads the
  backend's current name. Its value may change during the block: after RFC 6762 §9 re-probing,
  `Mdns.Responder` renames an established instance (`Gondor` → `Gondor (2)`) when another host
  is found to hold its name, where previously such a response was only cached. Code that reads
  `instance` once and reuses it must re-read it when the name matters. (#2186)
- `syndesis.Mdns.Transport` replaces `def receive(): Packet raises Socket.Error` with `def
  inlets: List[Mdns.Transport.Inlet]`, where `Mdns.Transport.Inlet` (new trait) has `def
  receive(): Packet raises Socket.Error`; `Mdns.Transport.sockets` now joins `ff02::fb` as well
  as `224.0.0.251` (one inlet each) on interfaces with an address of that family, and fails only
  if neither group can be joined. A `Transport` implementation with one socket extends `Inlet` too and
  returns `List(this)`. `Mdns.Transport.Bus#join` now returns `Transport & Transport.Inlet`
  (previously `Transport`), so `receive()` on a bus member is unchanged. (#2186)
- `syndesis.Discovery.Backend#advertise`, `#browse` and `#resolve` take an additional using
  parameter `(Discovery.Activity is Loggable)^` in their final `using` clause (after
  `Tactic[Discovery.Error]`), and `#withdraw` takes `(using Monitor^, (Discovery.Activity is
  Loggable)^)` instead of `(using Monitor^)`; `Discovery.Activity` is a new enum (`Probing`,
  `Yielded`, `Conflicted`, `Claimed`, `Withdrawn`, `Browsing`, `Resolved`) with a `Communicable`
  given. The loans `service.advertise(description) { … }`, `service.browse { … }` and
  `instance.resolve(timeout)` likewise require `(Discovery.Activity is Loggable)^` in scope,
  which `anticipation.Loggable.fanOut` derives from the `Communicable` with no further import
  (silent with no `LogSink` in scope), so call sites compile unchanged; a `Backend`
  implementation must add the parameters. (#2186)

## telekinesis

- `telekinesis.Hpack` is a stateful, exclusive capability (`caps.ExclusiveCapability`,
  `caps.Stateful`): `Hpack()` returns `Hpack^`, and `encode` and `decode` are `update` methods,
  since each changes the codec's dynamic table. A codec is owned by one reader or writer: hold it
  in a local or pass it as a parameter typed `Hpack^`, and do not call it from a closure or a
  local `def` that captures it (the captured reference is read-only, and the call is rejected).
  `decode` takes its `Tactic[Http2.Error]` as a `using` parameter rather than `raises`; call
  sites are unchanged. (#2210)

## synesthesia

- A derived `Mcp.Specification` no longer lists every tool parameter as `required`, and no
  longer throws when a client omits one. A parameter whose type admits `Unset` (an
  `Optional[…]`) or that has a default argument is omitted from the input schema's `required`;
  when absent from a call it is `Unset` or the default. A required parameter that is absent
  raises `Mcp.Error(Mcp.Error.Reason.MissingParameter)` (was a `NoSuchElementException`). A
  parameter's own `@about` becomes its property's `description` in the schema (was ignored), and
  a prompt argument's description is the parameter's `@about` (was the method's). (#2187)
- `tools/call` answers a tool that throws with a `CallTool` whose `isError` is `true` and whose
  content is the exception's message (was a JSON-RPC `-32603` error with a `null` id). An
  `Mcp.Error` (unknown tool, missing parameter) is still a JSON-RPC error, now `-32602`, and
  every JSON-RPC error `Mcp.send` answers carries the request's `id` and the `Mcp-Session-Id`
  header. (#2187)
- `synesthesia.resource` takes a second parameter, `mimeType: Optional[Text] = Unset`, which
  `resources/read` and `resources/list` report. Without it, a resource whose URI a tool's `@ui`
  names is `text/html;profile=mcp-app` (as every text resource was), and otherwise a text
  resource is `text/plain` and a binary one `application/octet-stream`. (#2187)
- A derived `Mcp.Specification` compiles in a module compiled with capture checking (`-Ycc-new`
  with separation checking), so a server object no longer needs to live in an unchecked module,
  and a `@ui` tool no longer needs a `(List[Text] & Populated) is Encodable in Text` at the
  expansion site. (#2187)

## urticose

- `urticose.Internet` (and so `Online`) is classified `caps.SharedUnscoped` rather than
  `caps.Unscoped`: network access is ambient and may be used from any task. (#2212)
- `Internet` (`Online`) is `anticipation.DurableUnscoped`. (#2217)

## vivisection

- `vivisection.Jdwp.Connection` is classified `caps.SharedCapability` rather than
  `caps.ExclusiveCapability`: it is driven by its writer, reader and dispatcher tasks and by the
  session's thread at once. (#2212)
- `vivisection.Dap.listen`'s `observer` is `Text ->{caps.any.only[caps.SharedCapability]} Unit` (it
  runs on the writer task), and its `stdio` parameter is `consume`d: the writer task owns the
  standard streams, so the caller may not use `stdio` after calling `listen`. (#2212)

## xylophone

- The choice package `xmlSchemas` exports `freeformXmlSchema: XmlSchema`, and the umbrella
  mirrors it, so `import xmlSchemas.freeformXmlSchema` supplies the schema every `Xml` read,
  load or `Provider` needs, in the style of `charsets.utf8Charset`. A hand-written
  `given XmlSchema = XmlSchema.Freeform` still works and can be replaced by the import. (#2194)

## ypsiloid

- `Yaml.Tracking` (the `On`/`Off` enum and its `default` given) removed; YAML position
  tracking is selected by the shared `zephyrine.PositionTracking` toggle, as for JSON, TEL,
  XML and HTML. Replace `given Yaml.Tracking = Yaml.Tracking.On` with
  `import parsing.trackPositions` (or `given PositionTracking = PositionTracking.On`), and a
  `Yaml.Tracking` using-parameter with `PositionTracking`.
- `Yaml.parseAll` is no longer public. Read a multi-document stream with
  `text.read[List[Yaml]]`, which honours `parsing.trackPositions` in the same way.

## zephyrine

- New: `intake.ingest(stream)` takes in a whole stream, as `stream.pump(intake)` does, and returns
  the intake (typed as the caller's own class), so what it gathered can be read without a second
  reference: `Gather().ingest(bytes.stream).data`. `pump` still consumes its intake. (#2217)
