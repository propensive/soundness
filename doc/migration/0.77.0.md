# Changes since 0.76.0

This file is read by an LLM agent to upgrade code that consumes Soundness libraries from
0.76.0 to the next release. Each entry states precisely what changed; see `AGENTS.md` for the
format. Entries are grouped by module, most-recently-added last within a module.

## abacist

- With a `UnitsNames` given in scope, a `Quanta` value's `Showable` pairs each component with the
  name at its own unit's position; it previously took names from the end of the list, so a value
  with a zero in any unit but the smallest was mislabelled (`(Quanta(5, 0): Height).show` gave `5"`,
  now `5'`). (#PR)
- A `Quanta` value whose components are all zero shows as `0` followed by its smallest unit's name
  (`0oz`; with `UnitsNames`, the last name); it previously showed as empty text, or threw
  `NoSuchElementException` with `UnitsNames` in scope. (#PR)

## anamnesis

- `anamnesis.Database#store`, `#assign` and `#unassign` hold the database's lock for the whole of
  their read-modify-write, so concurrent calls no longer lose updates or give one value two
  references. Signatures unchanged. (#PR)

## anthology

- `anthology.Compiler.Notice` gained a sixth parameter, `code: Optional[fulminate.Bolt] = Unset`,
  after `markup`: the bolt code Proscala gives an error or a warning under `-Zbolt-codes`
  (`anthology.scalacOptions.boltCodes`), and `Unset` otherwise. Construction is unaffected; a
  positional pattern needs the added wildcard: `case Compiler.Notice(importance, file, message,
  span, markup)` becomes `case Compiler.Notice(importance, file, message, span, markup, _)`.
  (#2512)

## caduceus

- `caduceus.couriers.resendCourier` sends the envelope's reply-to addresses as the JSON field
  `reply_to`, which Resend reads; it previously sent `replyTo`, which Resend ignored. (#PR)

## capricious

- `capricious.toss()` draws from the contextual `Random` (`true` when `random.long() < 0L`); it
  previously drew from `scala.math.random` and was not reproducible under a `Seed`. (#PR)
- `capricious.Random.apply(seed: Seed)(using Randomization): Random` is now `inline def apply(seed:
  Seed): Random`: the `Randomization` is resolved inside, with `seed` as the `Seed` in scope, so
  under `randomization.seededRandomization` the generator starts from `seed` (it was previously
  never read). A call passing a `Randomization` explicitly must instead have it in scope. (#PR)
- Derived `Randomizable` instances (`Randomizable.derived`, `conjunction`, `disjunction`) draw every
  field and variant from the `Random` passed to `randomize`. They previously built a new generator
  from the `Randomization` (and `Seed`) in scope where the instance was derived, so under
  `seededRandomization` every derived value restarted from that seed; deriving no longer needs a
  `Randomization` in scope. (#PR)

## charisma

- `Reaction.Stoichiometric` shows as `=` and `Reaction.Resonance` as `↔`; each previously showed as
  the other's glyph. (#PR)
- `charisma.PeriodicTable.element` elides one `n` where `enn` precedes `nil` in a systematic name:
  element 190 is `Unennilium` (previously `Unennnilium`), and likewise 290, 390, 490, 590, 690, 790,
  890, 900–909 and 990. (#PR)

## coaxial

- The DNS extension methods `coaxial.query` on an `Endpoint[Udp.Port]` (both overloads, in
  `coaxial.dns`) are renamed `ask`: `resolver.query(dns"example.com")` becomes
  `resolver.ask(dns"example.com")`, and `resolver.query(message)` becomes `resolver.ask(message)`.
  The name collided with telekinesis's `query` in `soundness`; delete any `import coaxial.query`
  written to work around that. (#PR)

## cosmopolite

- `cosmopolite.Locale.decodable` lower-cases its input and ignores everything from the first `-` or
  `_`, so `t"FR"`, `t"fr-CA"` and `t"fr_CA"` decode as `Locale(fr)` (likewise `pl`, `de`, `es`);
  these previously decoded as `Locale(en)`. Unrecognised codes still decode as `Locale(en)`. (#PR)

## distillate

- `distillate.Irrefutable.intDoule` renamed to `distillate.Irrefutable.intDouble`. (#PR)
- `distillate.Decodable.int` and `distillate.Decodable.long` raise `Number.Error` with
  `Number.Error.Reason.OutOfRange` for text matching `[+-]?[0-9]+` which does not fit the type; they
  previously raised it with `Reason.Unparseable`. `Decodable.byte` and `Decodable.short` likewise
  give `OutOfRange` for such text beyond the range of an `Int`, where they gave `Unparseable`. (#PR)

## diuretic

- `diuretic.JavaLongDuration` fixes `type Domain = Durations`, so
  `anticipation.durationInterfaces.javaLongDuration` now satisfies `Long is Abstractable across
  Durations to Long`. (#PR)

## escapade

- `escapade.escapes.foreground.BrightWhite` resets with `[39m` (the foreground default) instead of
  `[49m`. (#PR)
- An `Escape` constructed without a `reset` no longer inserts a bare `\e` where its bracketed span
  closes; nothing is inserted there. (#PR)

## eucalyptus

- `eucalyptus.dateFormat` is a `java.time.format.DateTimeFormatter` (pattern `yyyy-MMM-dd
  HH:mm:ss.SSS`, the system default zone); it was a `java.text.SimpleDateFormat`. A call
  `dateFormat.format(millis: Long)` becomes
  `dateFormat.format(java.time.Instant.ofEpochMilli(millis))`. (#PR)
- Records formatted by `eucalyptus.logFormats.ansiTimestampedLogFormat` and
  `eucalyptus.logFormats.googleCloudPlatformLogFormat` end with `\n`, as those of
  `timestampedLogFormat` and `untimestampedLogFormat` do; they previously had no line ending. (#PR)
- `eucalyptus.Logger.apply` keeps one spool and writer daemon for each pair of call site
  (`Codepoint`) and `destination` (compared with `==`); it previously kept one for each call site,
  so loggers made at one source position for different destinations all wrote to the first. (#PR)

## galilei

- The extension `published[record]` on a `Path on plane` renamed to `observe[record]`, and the
  capability it lends, `galilei.Published[record]`, renamed to `galilei.Observer[record]`
  (likewise `soundness.Published` to `soundness.Observer`, and the exported `published` to
  `observe`). Signatures and behaviour are unchanged: `file.published[Ratel] { reader => … }`
  becomes `file.observe[Ratel] { reader => … }`. The source file is
  `galilei.Observer.scala`; `Edition` and `Owner` are unchanged. (#2518)
- `galilei.FilesystemBackend` gained an abstract member, `holding(path: Path on Plane,
  reserve: Long, mode: Optional[Int])(using Tactic[Io.Error]): FilesystemBackend.Hold^`,
  which an implementation of the trait must define; one with no writable memory mapping
  aborts with `Io.Error(path, Operation.Open, Reason.Unsupported)`, as the Scala Native and
  WASI backends do. (#2518)
- The searchpath extension `galilei.search` on a `Path on <plane <: Searchpath>` is renamed
  `discover`: `path.search()` becomes `path.discover()`. The name collided with gossamer's `search`
  in `soundness`; delete any `import galilei.search` written to work around that. `locations`,
  `listing` and `destination` are unchanged. (#PR)

## gastronomy

- `gastronomy.Sha384` and `gastronomy.Sha512` removed, with their `gastronomy.Multicodec.sha384` and
  `gastronomy.Multicodec.sha512` givens; use `Sha2[384]` and `Sha2[512]` (and `Multicodec.sha2_384`,
  `Multicodec.sha2_512`, which have the same codes). Neither removed type had a `Hash` instance.
  (#PR)

## hallucination

- The empty `hallucination-ansi` artifact (component `hallucination.ansi`, which had no sources) is
  no longer published; remove any dependency on it. Nothing was exported from it. (#PR)

## honeycomb

- `honeycomb.Whatwg#Area.Default`, `Area.Rect`, `Area.Circle` and `Area.Poly` are `Tag.Void of
  "area"` and serialize as `<area shape="…">`; they were `Tag.Void of "input"` and serialized as
  `<input shape="…">`. (#PR)
- `honeycomb.Whatwg#Legend` is a `Tag.Container of "legend"` and serializes as `<legend>`; it had
  the label and topic `"label"`, so it serialized as `<label>` and was rejected by `Fieldset`. (#PR)
- `honeycomb.Whatwg#Iframe` is `Tag.container["iframe", "", Whatwg]()`, not a `Tag.Void`: it
  serializes with an end tag (`<iframe …></iframe>`), and the parser expects `</iframe>`. (#PR)
- `honeycomb.Whatwg.usemap` is the attribute `usemap` (type `"usemap" is Attribute on "img" |
  "input" | "object" of HashName`); it was registered as `usemaptype`. (#PR)
- `honeycomb.Whatwg.headingreset` is the attribute `headingreset` (type `"headingreset" is Attribute
  of Presence`); it was registered as a second `headingoffset`. (#PR)
- `honeycomb.Whatwg.acceptCharset` is the attribute `accept-charset` (type `"accept-charset" is
  Attribute on "form" of Utf8`), as `honeycomb.Html4Transitional.acceptCharset` is; it was
  registered as `acceptCharset`. (#PR)
- `honeycomb.Whatwg#Meta` fixes `type Topic = "meta"`, `type Transport = ""` and `type Form =
  Whatwg`, as `Area`, `Input`, `Link` and `Track` do. (#PR)

## hyperbole

- `hyperbole.tastySymbolTeletypeable` draws a set flag on `TastyPalette#flagOn`; it previously used
  `flagOff` for both set and unset flags. (#PR)

## hypotenuse

- `binary` on `B8`, `B16`, `B32` and `B64` now terminates and returns the bitmap's own bits, most
  significant first, zero-padded to the type's width (8, 16, 32 or 64 characters); it previously
  never returned. (#PR)
- `U8#hex` returns hexadecimal (`U8` 255 gives `t"ff"`); it previously returned the octal form,
  identical to `U8#octal`. (#PR)
- A `U8` literal above 255 is a compile error (`↯/s.27.9`); values from 256 to 65535 were previously
  accepted and truncated to their low eight bits. (#PR)
- `Byte#int` returns `Int` and `Byte#short` returns `Short` (the extensions in `hypotenuse`); both
  previously returned `Long`. (#PR)
- `B8#ones`, `B8#zeros`, `B8#leadingZeros`, `B16#ones`, `B16#zeros` and `B16#leadingZeros` count
  only the type's own bits; with the top bit set they previously counted the sign extension (`B8`
  `0x80` gave 25 ones and -17 zeros). `B64#zeros` counts all 64 bits, where it counted only the low
  32. (#PR)
- `<=` and `>=` on `U16` compare unsigned, as `<` and `>` already did; values of 32768 or more
  previously compared as negative. (#PR)
- `F32.apply(sign: Boolean, exponent: B16, mantissa: B32)` builds IEEE 754 binary32: sign at bit 31,
  the low 8 bits of `exponent` at bits 23-30, and the low 23 bits of `mantissa`. Previously `sign =
  true` gave `-0.0f` whatever the other arguments, and the exponent was placed at bit 22 with a
  22-bit mantissa. `F64.apply(sign: Boolean, exponent: B16, mantissa: B64)` uses the low 11 bits of
  `exponent`, where it used the low 8. (#PR)

## iridescence

- `iridescence.Palette#selectDynamic` panics with `field <name> is not defined for this palette` for

## octogenarian

  with no user; it previously rendered `user:@hostnamepath` (and `@hostnamepath` with no user).
  (#PR)
- The message of `octogenarian.Commandline.Event.Exec(event)` is `git: <event>`; it was `the git
  operation did not execute: <event>`. (#PR)

## phoenicia

- The font coverage type `phoenicia.Coverage` is nested as `phoenicia.Font.Coverage`, and is no
  longer exported into `soundness` under its bare name, where it collided with probably's test
  `Coverage`. Replace `Coverage`, `Coverage.Entry`, `Coverage.Unknown`, `Coverage.Entries`,
  `Coverage.of`, `Coverage.combine` and `Coverage(…)` with the same names prefixed by `Font.`
  (`Font.Coverage.of(file)`); with `import soundness.*`, a bare `Coverage` now always means
  `probably.Coverage`. Members and behaviour are unchanged. (#PR)

## quantitative

- The values of `quantitative.Dyne`, `Erg`, `Maxwell`, `Gauss`, `Stokes`, `Phot` and `Lambert`, and
  of `quantitative.constants.MagneticConstant`, are one tenth of what they were: 10⁻⁵ N, 10⁻⁷ J,
  10⁻⁸ Wb, 10⁻⁴ T, 10⁻⁴ m²·s⁻¹, 10⁴ lx, 10⁴/π cd·m⁻² and 4π×10⁻⁷ N·A⁻² respectively. (#PR)
- `quantitative.constants.BoltzmannConstant` is 1.380649×10⁻²³ J·K⁻¹; it was 1.380649×10⁻¹³. (#PR)
- `quantitative.constants.GravitationalConstant` has the dimension N·m²·kg⁻²

- `quantitative.Poise` is `MetricUnit(0.1*Pascal*Second)`, a dynamic viscosity; it was `0.1*Pascal`,

## sedentary

## stratiform

- The bytes of a RaTEL image changed, to those of the RaTEL specification as tel#52 left it,
  under the same version byte: a 200-byte header whose directory entries are `(offset,
  length, capacity)`; an 8-byte header on every row (`u32` parent, `u16` link, `u16` flags)
  before its presence bitmap; a repeatable struct member stored as a `u32` ref to a child list
  in place of `(start, count)`; arrays, ref arrays and select lists stored as `(capacity,
  count, elements)`, an empty one as the ref `0xFFFFFFFF`; 32-byte table and index directory
  entries; each index a B+tree of 4096-byte pages; and a digests section of two digests (the
  body, then the header) in place of six. An image written by 0.76.0 is not read: it is
  refused with whichever of `BadDirectory`, `ReservedSet` or `InvalidState` its header first
  meets. There is no conversion: write such an image again from its document. The signatures
  of `Ratel.encode`, `tel.ratel(schema)` and `value.ratel` are unchanged, and what they write
  is a sealed image (header flag bit 2), always with the value hash. (#2518)
- `stratiform.Ratel.Error.Reason` follows the specification's `↯/t.5` codes, which gained
  three. Renamed: `SectionsOverlap` to `ExtentsOverlap` (6; now also a table's rows or an
  index's pages overlapping anything), `IndexUnsorted` to `BadTree` (24; now any breach of the
  B+tree's invariants). Added: `InvalidState` (28), `Dirty` (29), `BadRowHeader` (30).
  Renumbered, so that the variant in the bolt code of a `Ratel.Error` with one of these
  reasons changes: `NestingLimitExceeded` 28 to 31, `Unencodable` 29 to 32, `Oversized` 30 to
  33, `Unindexed` 31 to 34, `Unknown` 32 to 35, `Inapplicable` 33 to 36, `Absent` 34 to 37,
  `Unwritable` 35 to 38, `Mismatched` 36 to 39. `BadRecordIndex` (15) is now also raised for a
  record index which names a free row, and `DigestMismatch` (7) for a digests section which is
  not the last 64 bytes of the file. (#2518)
- `stratiform.Ratel.Reader` gained `state: Ratel.State` (`Sealed` or `Unsealed`). A reader
  refuses a file whose header has the dirty flag (`Reason.Dirty`). `Reader#verify()`
  additionally checks each row's header against the slot which reaches it, that every live
  row is reached, each index as a B+tree, and, of a sealed image, that it is compact. (#2518)
- `stratiform.Tels.tels[value]` no longer leaves a scalar which declares an encoding within
  the field which holds it. A field whose type has a `Tel.Encoded[name]` instance was
  declared with `Tels.Scalar(Array.empty, name)`; it is now declared with
  `Tels.Reference(typeName)`, and the schema's `scalars` holds `Tels.ScalarDefinition(typeName,
  Array.empty, Unset, name)`, where `typeName` is the encoding's name with each run of ASCII
  letters and digits capitalised and everything else dropped (`decimal-varint` gives
  `DecimalVarint`), with `Scalar` appended if a record, select or scalar of the schema already
  has that name. Such a schema can now be rendered (`Tels.Renderer.element` raised
  `InlineScalar` for it), so it has a signature, and `value.ratel` with no schema argument
  works for the type. Code which matches the field's `fieldType` against `Tels.Scalar` to read
  its encoding must resolve the reference through `schema.scalars`. A schema with any scalar
  definition, key or index is additionally checked as `Tels.Validation.validate` checks a
  composed schema, so `Tels.tels` may raise those `Tel.Error` reasons for it. The schema of a
  type with no encoded scalar is unchanged. (#2518)
- `stratiform.Ratel` gained an abstract type member, `Topic`, and the extension `value.ratel`
  which takes no schema returns `Ratel of value` (`Ratel { type Topic = value }`) where it
  returned `Ratel`. A `Ratel of T` is a `Ratel`, so code which takes the result as a `Ratel`
  is unaffected; a `val` whose type was inferred from it is now the refined type. `Ratel(data)`,
  `Ratel.encode` and `tel.ratel(schema)` still give a plain `Ratel`. (#2518)
- The givens `stratiform.Ratel.encodable` and `stratiform.Ratel.viewable` are generic in the
  image's type: `[ratel <: Ratel] => ratel is Encodable in Data` and `[ratel <: Ratel] =>
  ratel is Viewable`, where each was an instance for `Ratel` alone. A use which names either
  given and ascribes it as `Ratel is Encodable in Data` or `Ratel is Viewable` still compiles;
  one which passes it where a non-generic value is expected needs `Ratel.encodable[Ratel]`.
  (#2518)
- Opening as `Ratel` (or `Ratel of T`) with a mode which includes `aperture.Write` no longer
  always aborts with `Ratel.Error.Reason.Unwritable`. Where the target can lend its bytes for
  changing -- a `Path` on a backend which maps files for writing, or a `zephyrine.Holding` --
  the image is opened for changing in place (RaTEL §10): an exclusive lock is taken on a
  file, a sealed image is unsealed (header flag bits 0 to 2 and the value hash cleared, the
  digests section emptied), the dirty flag is set for the length of the block and cleared
  when it ends, and the reader given to the block accepts `Rows#insert`, `Rows#move`,
  `Row#set` (also written as an assignment, `row.lines = value`, whose name is the keyword in
  camel case), `Row#unset`, `Row#delete` and `Row#replace`. A target which cannot (a `Ratel`
  value, a read-only `Terrain`) still aborts with `Unwritable`, as do those operations
  through a reader which was not opened for writing. Code which relied on `Write` being
  refused for a path must not pass it. (#2518)

## turbulence

- The variadic `Out.println(lines*)` and `Err.println(lines*)` take `(using Stdio^)`, like `print`,
  `write` and the zero-argument `println`; they previously took an untracked `Stdio`, so a tracked
  `Stdio^` in scope could not be passed to them. No change is needed at existing call sites. (#PR)

## zephyrine

- New constructor `zephyrine.Spring.apply`: `Spring[Data](expression)` makes a `Spring` which
  evaluates `expression` for a fresh stream at each `apply()`, replacing the anonymous class `new
  Spring[Data]: def apply()(using Tactic[Truncation.Error]): (Stream[Data] over Credit)^ =
  expression`. The anonymous-class form still compiles; no change is required. Give the type
  argument explicitly where the compiler otherwise reports a capture mismatch on the element type.
  (#PR)
