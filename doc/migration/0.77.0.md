# Changes since 0.76.0

This file is read by an LLM agent to upgrade code that consumes Soundness libraries from
0.76.0 to the next release. Each entry states precisely what changed; see `AGENTS.md` for the
format. Entries are grouped by module, most-recently-added last within a module.

## anthology

- `anthology.Compiler.Notice` gained a sixth parameter, `code: Optional[fulminate.Bolt] = Unset`,
  after `markup`: the bolt code Proscala gives an error or a warning under `-Zbolt-codes`
  (`anthology.scalacOptions.boltCodes`), and `Unset` otherwise. Construction is unaffected; a
  positional pattern needs the added wildcard: `case Compiler.Notice(importance, file, message,
  span, markup)` becomes `case Compiler.Notice(importance, file, message, span, markup, _)`.
  (#2512)

## stratiform

- The bytes of a RaTEL image changed, to those of the RaTEL specification as tel#52 left it,
  under the same version byte: a 200-byte header whose directory entries are `(offset,
  length, capacity)`; an 8-byte header on every row (`u32` parent, `u16` link, `u16` flags)
  before its presence bitmap; a repeatable struct member stored as a `u32` ref to a child list
  in place of `(start, count)`; arrays, ref arrays and select lists stored as `(capacity,
  count, elements)`, an empty one as the ref `0xFFFFFFFF`; 32-byte table and index directory
  entries; each index a B+tree of 4096-byte pages; and a digests section of two digests (the
  body, then the header) in place of six. An image written by 0.76.0 is not read: it is
  refused with whichever of `BadDirectory`, `ReservedSet` or `InvalidState` its header first
  meets. There is no conversion: write such an image again from its document. The signatures
  of `Ratel.encode`, `tel.ratel(schema)` and `value.ratel` are unchanged, and what they write
  is a sealed image (header flag bit 2), always with the value hash. (#NNNN)
- `stratiform.Ratel.Error.Reason` follows the specification's `↯/t.5` codes, which gained
  three. Renamed: `SectionsOverlap` to `ExtentsOverlap` (6; now also a table's rows or an
  index's pages overlapping anything), `IndexUnsorted` to `BadTree` (24; now any breach of the
  B+tree's invariants). Added: `InvalidState` (28), `Dirty` (29), `BadRowHeader` (30).
  Renumbered, so that the variant in the bolt code of a `Ratel.Error` with one of these
  reasons changes: `NestingLimitExceeded` 28 to 31, `Unencodable` 29 to 32, `Oversized` 30 to
  33, `Unindexed` 31 to 34, `Unknown` 32 to 35, `Inapplicable` 33 to 36, `Absent` 34 to 37,
  `Unwritable` 35 to 38, `Mismatched` 36 to 39. `BadRecordIndex` (15) is now also raised for a
  record index which names a free row, and `DigestMismatch` (7) for a digests section which is
  not the last 64 bytes of the file. (#NNNN)
- `stratiform.Ratel.Reader` gained `state: Ratel.State` (`Sealed` or `Unsealed`). A reader
  refuses a file whose header has the dirty flag (`Reason.Dirty`). `Reader#verify()`
  additionally checks each row's header against the slot which reaches it, that every live
  row is reached, each index as a B+tree, and, of a sealed image, that it is compact. (#NNNN)
