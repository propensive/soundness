# Changes since 0.74.0

This file is read by an LLM agent to upgrade code that consumes Soundness libraries from
0.74.0 to the next release. Each entry states precisely what changed; see `AGENTS.md` for the
format. Entries are grouped by module, most-recently-added last within a module.

## proscenium

- `Array.thaw[element: ClassTag](array: Array[element]^{caps.any.rd}): Array[element]^` is
  new: an exclusive copy of any readable array, the inverse of `Array.freeze`. Write through it
  with `copy(index) = value` and freeze it again; the source is never changed. Code that built
  `scala.collection.mutable.ArrayBuffer.from(xs.stdlib)` to edit several slots and then
  `Array.from(buffer)` should thaw, write and freeze instead. (#2337)
- `Array.concat` gains a three-operand overload, `concat[element: ClassTag](left, middle,
  right: Array[element]^{caps.any.rd}): Array[element]^{}`, beside the two-operand form, for
  splicing. A splice `Array.from(xs.stdlib.take(i) ++ ys.stdlib ++ xs.stdlib.drop(i + 1))` is
  `Array.concat(xs.before(i.z), ys, xs.after(i.z))`. (#2337)

- `List.quoted[element: Type](elements: List[Expr[element]])(using Quotes): Expr[List[element]]`
  and `Array.quoted[element: Type](elements: List[Expr[element]] | Array[Expr[element]]^{})(using
  Quotes): Expr[Array[element]^{}]` (two overloads) are new: the native counterparts of
  `Expr.ofList`, for macro code holding lifted elements. `Expr.ofList(xs.stdlib)` wrapped in
  `List.from(…)` is `List.quoted(xs)`; `'{Array.from(${Expr.ofList(xs.stdlib)})}` is
  `Array.quoted(xs)`, which resolves the element's `ClassTag` at the expansion site.
  `gigantism.Lifts.list` is unchanged and now delegates to `List.quoted`. (#2339)
- The prelude no longer exports `scala.Iterator`: `export scala.{Iterable, Iterator}` is now
  `export scala.Iterable`. In a file compiled against Soundness, a bare `Iterator` now means
  `murmuration.Iterator` (through `import rudiments.*` or `import soundness.*`); a file that
  imports neither and used the bare name must add `import murmuration.Iterator`, or write
  `scala.collection.Iterator` where a stdlib iterator is genuinely meant. (#2235)

## denominative

- `Omissible` gains an instance for the frozen array, `Omissible.frozenArray`, gated on
  `Dysasymptotic.LinearSize` like `Definable.frozenArray`, so `xs.omit(ordinal)` (in
  `rudiments` and the umbrella) now resolves on an `Array[element]^{}` under `import
  denominative.dysasymptotics.linearSize`: a copy without the slot at `ordinal`, or the array
  unchanged when `ordinal` is out of range. Previously `omit` was available only on `Map` and
  `Ledger`. (#2337)
- `Interval` gains `all(predicate)`, with a branded overload on `Interval in form` whose
  predicate receives `Ordinal in form`: `xs.extent.all: i => xs(i) == ys.readUnchecked(i.n0)`
  replaces `xs.stdlib.indices.forall`. (#2337)

## hypotenuse

- `hypotenuse.maximize` and `hypotenuse.minimize` (both the `Traversable`-receiver and the
  `Iterable`-receiver overloads) are removed. They are now `rudiments.maximize` and
  `rudiments.minimize` (exported by the umbrella), on any `Traversable` receiver, with the
  key constrained by symbolism's `Comparable` rather than by `Commensurable against` itself:
  every numeric key still works, and a `Text`, `String`, `Ordinal` or any other `Comparable`
  key now does too. The result is unchanged, `Optional[element]` (`Unset` on an empty
  receiver), and the first of several elements with equal keys is chosen. A by-name import
  `import hypotenuse.{maximize, minimize}` must become `import rudiments.{maximize, minimize}`;
  with `import rudiments.*` or `import soundness.*` nothing changes. (#2337)

## stenography

- `Syntax.name` now renders a capability's `except` restriction: `Text^{alpha.except[Reader]}`
  was written as `Text^{alpha}`, dropping the restriction silently, and is now written in full,
  matching the existing `.only[…]` and `.rd` forms. Code comparing rendered type names (tests,
  golden files) against the truncated form must expect the restriction.

## obligatory

- `frames[frame]` (the extension that applies a `Framable` framer) now also has a `Chain[element]`
  receiver beside the `Iterator[element]^` one, returning the same one-shot
  `Iterator[element]^{framable}`. `stream.chain.stdlib.iterator.frames[Linefeed]` is
  `stream.chain.frames[Linefeed]`. (#2341)
- `Framable.frames(frame: => Optional[data]): Iterator[data]^{frame, caps.any}` and the
  `frames[frame]` extension return `murmuration.Iterator`; the extension's iterator receiver is
  taken as `consume`. (#2235)

## plutocrat

- `share(right: Int): List[Money in currency]` (on `Money in currency`) now returns `right`
  amounts of the receiver's currency that differ by at most one minor unit and sum exactly to the
  receiver, the larger first: `Eur(3.01).share(3)` is `List(Eur(1.01), Eur(1.00), Eur(1.00))`.
  It previously divided the packed representation, currency code included, so each share was
  not a valid amount of that currency and only their raw sum recovered the original. No call
  site changes; code that worked around the old results should use them directly.

## murmuration

- `murmuration.Iterator[+element]` is new, exported by rudiments and the umbrella: a
  separation-checked, non-allocating one-shot iterator that replaces `scala.Iterator`
  throughout Soundness. It extends `caps.Stateful`, so a value of type `Iterator[e]^` is
  exclusive: an `update def` advances it, a `consume def` takes it over, and the compiler
  rejects a second use of a consumed one. There is no `hasNext`/`next()` pair. Read one with
  - a terminal operation (an `update def`, draining in place): `each(lambda)`,
    `fold(initial)(lambda)`, `exists(p)`, `all(p)`, `count(p)`, `size`,
    `seek[result](p)(absent: => result)(present: element => result)`, `option: Option[e]`,
    `chain: Chain[e]` (lazy), `to[result]` (via `Reshapable`);
  - `update def next(): element | Iterator.Exhausted`, for a stateful consumer that holds the
    iterator in a field: one call advances and yields, and the caller matches on
    `Iterator.Exhausted` first (`case Iterator.Exhausted => … case value: Int => …`);
  - the moving style, `consume def pull: Iterator.Pull[element]`, which yields
    `Iterator.Exhausted` or an `Iterator.Cursor[element]^` owning the iterator; `cursor.value`
    reads the element and `consume cursor.pull` advances. Branch with a typed pattern
    (`case cursor: Iterator.Cursor[Int]`; backtick a class type parameter) and read `value`
    before `pull`. `Exhausted` is a pure `null`-backed opaque, so a step allocates nothing.
  Lazy combinators are `consume def`s returning a fresh iterator: `map`, `filter`,
  `sweep(partialFunction)`, `keep(n)`/`skip(n)`, `keep(p)`/`skip(p)`, `zip(consume that)`,
  `indexed` (pairs with an `Int` index), `trace(initial)(lambda)` (`scanLeft`),
  `excerpt(from, until)`, `batched(n): Iterator[List[e]]^`, `deduplicate(key)`, `distinct`,
  `concat(consume that)` (`++`), and `flatMap(lambda)(using inner is Traversable)`, whose
  lambda returns a pure *collection*, not an iterator. A combinator's result captures its
  lambda (`Iterator[e2]^{lambda, caps.any}`), so a capturing lambda makes the result exclusive.
  The companion has `empty`, `apply(elements*)`, `range(start, end)`, `fill(n)(elem)`,
  `tabulate(n)(lambda)`, `continually(elem)`, `iterate(initial)(lambda)`, `array(array)`, and
  `from(…)` for a `scala.collection.Iterator`, a `java.util.Iterator` or a
  `java.util.Enumeration`; `consume def stdlib: scala.collection.Iterator[e]` hands one out to
  a stdlib or JDK API, and is a tagged bridge like every `.stdlib`.
  Implementations write `new Iterator[e]:` with `update def advance(): Boolean` (move and
  materialise the element into a `var`) and `def current: e` (a plain read), and inherit the
  rest. The old anonymous `new scala.Iterator[e] { def hasNext; def next() }` with
  `@untrackedCaptures var`s becomes this, with plain `var`s.
  Migration of stdlib call sites: `it.hasNext`/`it.next()` → `next()` match or `pull`;
  `it.toList`/`List.from(it)` → `it.to[List]`; `it ++ that` → `it.concat(that)`;
  `it.take(n)`/`drop(n)` → `keep(n)`/`skip(n)`; `takeWhile`/`dropWhile` → `keep(p)`/`skip(p)`;
  `collect` → `sweep`; `zipWithIndex` → `indexed`; `grouped(n)` → `batched(n)`;
  `scanLeft` → `trace`; `slice` → `excerpt`; `find(p)` → `seek(p)(Unset)(identity(_))`;
  `nextOption()` → `option`; `foreach` → `each`; `forall` → `all`. (#2235)
- `Traversable.traverse(self)` now returns `Iterator[Operand]^` (the new type, exclusive) and
  `Reshapable.reshape(elements: Iterator[Operand]^)` takes it; an instance of either written
  outside Soundness must be re-typed accordingly. `Reshapable.build(elements, builder)` is a
  new helper for strict instances backed by a stdlib `Builder`. (#2235)

## vacuous

- `compact` on an iterator of `Optional`s now takes and returns `murmuration.Iterator` (`extension
  [value](consume iterator: Iterator[Optional[value]]^) def compact: Iterator[value]^`). (#2235)

## rudiments

- The `each` and `all` extensions whose receiver was a `scala.Iterator` are removed: the
  iterator's own `each`/`all` methods take their place. The `Traversable` extensions (`each`,
  `all`, `fuse`, `seek`, `reap`, `sweep`, `where`, `indexed`, `head`, `last`, `lead`,
  `leading`, `trailing`, `locate`, `total`, `product`, `reduce`, `occupied`) are unchanged in
  signature but now drive `murmuration.Iterator`. `sorted` and `ordered` on an iterator take it
  as `consume`. (#2235)

## acyclicity

- `Nodal.nodes(self): Iterator[Operand]^`, `Nodal.successors(self, node): Iterator[Operand]^`
  and `Bidirectional.predecessors(self, node): Iterator[Operand]^` now return
  `murmuration.Iterator` (exclusive); every provided instance (`Dag`, `Digraph`, `Hasse`,
  `Topology`, `Map`, `Ledger`) follows. A user instance returning a stdlib iterator wraps it with
  `Iterator.from(…)`. (#2235)
- The extension `dot` on `Dag[Text]` is `def dot: Dot raises Name.Error`, where before it was
  `def dot: Dot` and threw `Name.Error` for a node whose text is not a DOT identifier (empty,
  or containing `"` or a newline). A call site needs a `Tactic[Name.Error]` in scope. (#TBD)

## bitumen

- `Tarfile.read`, `Tar.Handle.entries`, `Arfile.read` and `Ar.Handle.entries` return a fresh
  `Iterator[…]^` rather than `Iterator[…]^{tactic}`: the iterator is a new mutable object, and
  its mutability no longer rides on a tactic capture (which is empty for the pure ambient
  strategies). A binding typed `Iterator[Tar.Entry]^{tactic}` becomes `Iterator[Tar.Entry]^`.
  (#2328)

- `Ar#serialize`, `Tar#serialize`, `Tar#dataBlocks` and `Archive.Body#chunks` return
  `murmuration.Iterator[Data]^` (`chunks` as `Iterator[Data]^{this, caps.any}`). `Arfile.Member`
  and `Tarfile.Member` are now `Traversable by Data` so an archive's members may be streamed
  with `each` or `stream`. (#2235)

## breviloquence, locomotion, stratiform, ypsiloid

- `Cbor.emit`, `Protobuf.emit`, `Tel.emit` and `Yaml.emit` return `Iterator[…]^`
  (`murmuration.Iterator`). Consumers that called `.toList`/`.mkString` on the result use
  `.to[List]`/`.to[List].join`, or drain it with `.stream`/`.each`. (#2235)

## caesura

- `Sheet` construction from a `Dsv` iterator takes the iterator as `consume`; `Dsv` row readers
  are `murmuration.Iterator` implementations. (#2235)

## gossamer

- `Joinable.Assembly.assemble(parts: Iterator[Part]^)` and `Source.traverse` now use
  `murmuration.Iterator`; `join` with a separator builds the interleaving through the iterator's
  `concat`/`flatMap` rather than a stdlib `flatMap`. (#2235)

## honeycomb, xylophone

- `Html.HtmlParser.fromIterator(input: Iterator[BaseText]^, permissive)`,
  `XmlParser.fromIterator(input: Iterator[BaseText]^)` and `fromIteratorTracked` take a
  `murmuration.Iterator`; `Attributes#keys`, `values` and `iterator` return one. (#2235)
- `honeycomb.ClassList.apply[name <: Label: Reifiable to List[String]](): ClassList of name` is
  `inline def apply[name <: Label](): ClassList of name`: a macro which checks each string
  literal of `name` (a literal or a union of literals) against `CssClass`'s identifier rules at
  expansion. A label which is not a CSS identifier (`ClassList["1bad"]()`) is now a compile
  error where before `apply` threw `Name.Error` at runtime; a type argument which is not made of
  string literals is also a compile error. (#TBD)

## jacinta

- `Json.Parser.parse`, `Json.Parser.parseTracked`, `Json.Ast.parse` and `Json.Ast.parse(input,
  holes)` take `consume input: Iterator[Data]^` (`murmuration.Iterator`) and declare their error
  with an explicit `(using Tactic[Parse.Error])` rather than `raises Parse.Error` (identical for

## profanity, ultimatum

  Iterator[event]^{this}` and `Form#run(events: Iterator[Terminal.Event]^)` use

## sibylline

- `Llm.Response#events: Iterator[Event]^{this, caps.any}` and `text: Iterator[Text]^{this,

## ulysses

- `Bibliography#lookup(prefix): Iterator[Data]^` returns `murmuration.Iterator`. (#2235)

## zephyrine

- `Stream.apply(iterator: Iterator[medium]^)`, `Cursor.apply(iterator: Iterator[data]^)` and
  the `stream` extension take `murmuration.Iterator`; `Producer#iterator` is a `def` returning
  `Iterator[medium]^`. A source written as an anonymous `scala.Iterator` becomes `new
  Iterator[Data]:` with `advance()`/`current`. (#2235)

## guillotine

- The line-at-a-time result of a process is now `Chain[Text]` rather than `Iterator[Text]`:
  `sh"…".exec[Chain[Text]]()` replaces `exec[Iterator[Text]]()`, and the `Intelligible` results
  of the POSIX commands that produce lines (`cat`, `grep`, `head`, `ls`, `man`, `sed`, `sort`,
  `strings`, `tail`, `uniq`) are `Chain[Text]`. The chain is lazy and memoizing, so lines still
  arrive as the process writes them; an exclusive `murmuration.Iterator` cannot be the result
  type of an erased evidence given. (#2235)
- `guillotine.Computable#compute(process: Subprocess^): Self` is `compute(process:
  Subprocess^)(using Tactic[Truncation.Error]): Self`: an output read which is cut short is
  raised rather than thrown. A method with a `using` clause is not a single abstract method,
  so an instance written as a lambda (`job => …`) no longer converts: write it as
  `Computable((job, tactic) => …)` through the new factory `Computable.apply[self](lambda:
  (Subprocess^, Tactic[Truncation.Error]) => self): (self is Computable)^{lambda}`, binding
  `given Tactic[Truncation.Error] = tactic` in the body where a read needs it, or as an
  explicit `new Computable`. The provided instances (`Chain[Text]`, `List[Text]`, `Text`,
  `String`, `Data`, `Exit`, `Unit`, `Stderr`, `Instantiable`) and `Computable#map` are
  unchanged in use. (#TBD)
- `guillotine.Job#await()(using computable: (result is Computable)^)` is `await()(using
  computable: (result is Computable)^, truncation: Tactic[Truncation.Error])`, and the timed
  `await(duration)` likewise adds `truncation: Tactic[Truncation.Error]` and captures it in its
  result. A call with no such tactic in scope mitigates it to its own error or declares
  `raises Truncation.Error`. `Executable#exec()` and the inline `apply()` are unchanged in
  signature: they report a cut-short read as `Exec.Error(command)` (the last command of a
  `Pipeline`) through their existing `Tactic[Exec.Error]`, where before it was thrown as
  `Truncation.Error`. (#TBD)

## contingency

- `Emit` (and so every `Tactic`) now extends `scala.caps.Control` rather than
  `scala.caps.SharedCapability`. A `Control` capability may retain only `Control` capabilities,
  so a `handle`/`recover` case body may raise into an outer tactic but may no longer capture a
  non-control shared capability such as a `Loggable` logger: move the logging out of the case
  body (log the recovered value after the `handle`, or raise a richer error). `Emit.apply`'s
  handler is `error ->{caps.any.only[caps.Control]} Unit` (was `only[caps.SharedCapability]`).
  (#2328)
- `ThrowTactic[error, success]` is `ThrowTactic[-error]`: the phantom second type parameter is
  gone, and the class is contravariant. `ThrowTactic[Hazard, Any]^` is `ThrowTactic[Hazard]^{}`,
  `ThrowTactic[E, R]()` is `ThrowTactic[E]()`, and `unsafely`/`throwErrors` blocks that named it
  (`ThrowTactic[error, success]^ ?=> …`) name `ThrowTactic[error]^`. (#2328)
- The ambient strategies are pure values: `strategies.throwUnsafely: ThrowTactic[Hazard]^{}`
  (was `[success] => ThrowTactic[Hazard, success]^`), `strategies.uncheckedErrors: [error] =>
  (erased error is Unchecked) => UncheckedTactic[error]^{}`, `strategies.fatalErrors: [exception:
  Fatal] => FatalTactic[exception]^{}`; `strategies.throwSafely: [error] => (erased canThrow:
  CanThrow[error]) => ThrowTactic[error]^{canThrow}` retains its `CanThrow` evidence. The static
  instances are `ThrowTactic.ambient` and `UncheckedTactic.ambient`. Code that passed
  `strategies.throwSafely[E, Any]` passes `strategies.throwSafely[E]`. `ThrowTactic`,
  `UncheckedTactic` and `FatalTactic` no longer extend `scala.caps.SharedUnscoped`, so a
  consumer needs no Proscala-only classifier for them (the fork's supplementary library is still
  needed for `scala.Spreadable`). (#2328)

## anticipation

- `anticipation.DurableUnscoped` is removed; every type that extended it (`LogSink`,
  `parasite.Supervisor`, `parasite.Threading`, `parasite.threads`, `parasite.supervisors`,
  `surveillance.Watcher`, `surveillance.watchers`, `urticose.Internet`, `octogenarian.Git.Activity`,
  `espionage.Acp.Observer`, `exegesis.Lsp.Observer`) extends `anticipation.Durable`. A consumer
  that declared its own ambient capability `DurableUnscoped` declares it `Durable` and provides it
  through a given that is a value (or an object), not a polymorphic method: a value is a static
  capability, visible from every level, which is what the level exemption used to buy. (#2328)
- Capture-checked Soundness now requires Scala 3.10 (Proscala's 3.10 builds); the 3.9 builds no
  longer compile it. (#2328)

## octogenarian

- `Git.Repo#fetch`, `#push`, `#pull`, `Git.clone` and `Git.cloneCommit` take
  `activity: Optional[Activity^] = Unset` rather than `activity: Activity^ = Activity()`: a
  fresh capability minted in a default argument cannot reach the call site without a level
  exemption, which `Activity` (now plain `Durable`) no longer has. Callers that passed an
  `Activity` pass it unchanged; callers relying on the default are unaffected; a caller that
  wants the progress object creates it (`val activity: Git.Activity^ = Git.Activity()`) and
  passes it. (#2328)

## espionage, exegesis

- `Acp.connect`, `Lsp.proxy`, `Lsp.listen` and `Lsp.Proxy.run` take `observer:
  Optional[Observer^] = Unset` rather than `observer: Observer = Observer.Silent`, for the
  reason `Git.Activity` does (a default argument of capability type minted a fresh capability
  in a default getter, which only the retired level exemption let reach the call site). A caller
  that passed an observer passes it unchanged; the default is the silent observer as before.
  (#2328)

## contingency (ambient strategies)

- Library code no longer discharges its own obligations with `strategies.throwUnsafely`; the
  ambient strategies are for a program's entry points and prototyping. Consumers are unaffected
  except where a signature became honest, listed per library below. (#2328 follow-up)

## distillate

- `Requirable` (and its `Requirable.decodable` given) is removed: nothing used it. A consumer
  that summoned `value is Requirable` to test whether an empty text decodes writes
  `safely(t"".as[value]).present` directly. (#2328 follow-up)

## archimedes

- `Ergo.unsafeInterpolate(parts, atoms)` takes `(using erased unsafe: Unsafe)`, as its name
  requires; `Ergo.unsafe(input)`, which had no callers, is removed — use
  `unsafely(Ergo.parse(input))`. (#2328 follow-up)

## xenophile

- `WitDialect.worlds(source)` declares `raises Wit.Error` instead of throwing it; a caller that
  tolerated an unparsable file writes `safely(WitDialect.worlds(source))`. `CHeader.Dialect`,
  `WitDialect` and `WebIdlDialect`'s `parse` are total, as `TypescriptDialect.parse` was: a
  source that does not parse defines nothing (an empty `Map`) rather than throwing. (#2328
  follow-up)

## obligatory

- `JsonRpc.Request` and `JsonRpc.Failure` gain companion `Json.Decodable` givens (pure
  derivation anchors), so `safely(json.as[JsonRpc.Request])` works at a use site. The
  `JsonRpc.serve` macro no longer needs a `Tactic[JsonRpc.Error]` at its expansion site: an
  unknown method is thrown from the dispatcher (as a `JsonRpc.Error`) for the serving loop to
  report, exactly as before when the expansion site imported `strategies.throwUnsafely`. A
  decode failure inside the dispatcher is likewise thrown as a `Json.Error`. (#2328 follow-up)

## jacinta

- `Json.Provider.fieldsOf(schema)` and `Json.Provider.memberOf(document, node, limit)` take
  `(using Tactic[Json.Error])` instead of throwing: a caller at macro time wraps them in
  `safely(…).or(halt(…))` or a `HaltTactic`; `Json.Provider#fields` is unchanged (it throws, as
  a schema read at expansion must). (#2328 follow-up)
- `Json#updateDynamic(field: String)[value: Encodable in Json](value: value)` and
  `Json#updateDynamic(field: String)[value](unset: Unset.type)` return `Json` with no tactic,
  where before each was `Json raises Json.Error`. A field is set, replaced or removed on an
  object; applying either to a non-object `Json` is a programming error (it throws a
  `ClassCastException`) rather than raising `Json.Error`. A caller that handled `Json.Error`
  around `updateDynamic` alone has nothing to handle. (#TBD)

## apoplexy

- `apoplexy.unsafeHttpUrl(text)(using Unsafe)` is new, called by the generated code for a value
  the macro validated at expansion; it is not exported to `soundness`. (#2328 follow-up)

## galilei

- `Explorable#children(path)` takes `(using Tactic[Io.Error])`, and so does the `children`
  extension on a `Path`: a listing is strict, so a backend failure is reported through the
  caller's tactic rather than thrown. A caller with no tactic in scope writes
  `safely(path.children)` or declares `raises Io.Error`. (#2328 follow-up)

## exegesis

- `Lsp.listen` takes `Tactic[Framing.Error]` and `Tactic[Truncation.Error]` (a malformed frame
  or a truncated standard stream is reported, not thrown); `Lsp.proxy` and `Lsp.Proxy.run` take
  those and a `Tactic[Lsp.Error]`. `LspSessional` (and so `Lsp.Server#session`) takes a
  `Tactic[Lsp.Error]`, and a server that fails to launch is reported as
  `Lsp.Error(Reason.Unstarted, details)` rather than thrown as an `Exec.Error`.
- `rewrite.result(method)` and `rewrite.notification(method)` take
  `Tactic[Json.Error] ?=> Json => Json`: a rewriter decodes under the tactic the proxy supplies
  at each call, and a message it cannot read passes through unchanged. The registered rewriters
  are `Lsp.Proxy.Rewriter` instances.
- The client proxies (`JsonRpc#proxy`, and so `Lsp.Connection`'s members) summon each result's
  decoder inside the generated method, under the call's own tactic; a missing decoder is now
  reported where the proxy is *used*, by the compiler's own "no given instance" message.
  (#2328 follow-up)

## espionage

- `Acp.connect`'s streams and sink are minted inside the exchange's reader and writer tasks,
  each under that task's tactic; no signature changes. (#2328 follow-up)

## vivisection

- `Dap.listen` takes `Tactic[Framing.Error]` and `Tactic[Truncation.Error]`, as `Lsp.listen`
  does. (#2328 follow-up)

## obligatory

- The `JsonRpc.serve` dispatcher summons each parameter's decoder inside the generated
  dispatcher, under its per-call tactic (a missing decoder is reported by the compiler's own
  message at the `serve` site). (#2328 follow-up)
- `Grpc.Channel(connection, authority, defaults)`: the `Host` of the HTTP/2 requests it builds
  (unused by the transport, which sends `authority` as `:authority`) is `Localhost` when the
  part of `authority` before the first `:` is not a `Host`, where before the constructor threw
  the decoding error. (#TBD)

## hellenism

- `Classpath.streamable`/`source` and `Resource.streamable`/`source` declare what they retain:
