# Changes since 0.70.0

This file is read by an LLM agent to upgrade code that consumes Soundness libraries from
0.70.0 to the next release. Each entry states precisely what changed; see `AGENTS.md` for the
format. Entries are grouped by module, most-recently-added last within a module.


## anthology

- `anthology.Format` gains an abstract member `kind: anthology.Format.Kind` (new enum: `Source`,
  `Ir`, `Application`), implemented as a `final def` by `Format.Source`, `Format.Ir` and
  `Format.Application`, and `final override` definitions of `equals` and `hashCode`: two formats
  are equal when their `kind`s and `id`s are equal. A class extending `Format` other than through
  one of the three tier traits must define `kind`; one overriding `equals` or `hashCode` no longer
  compiles; and a case class extending `Format` no longer has a synthesized structural `equals`.
  Two formats of one kind with the same `id` are now equal even if their other members differ, so
  a format whose parameters distinguish nodes must encode them in its `id` (every built-in format
  already does). (#PRNUM)

## ethereal

- `ethereal.DaemonService` renamed to `ethereal.Resident` (also exported as `soundness.Resident`),
  and its type parameter replaced by a type member: `case class DaemonService[bus <:
  Matchable](…)` is now `abstract class Resident(…)` with `type Transport <: Matchable`, the type
  of the messages its clients exchange. Write `DaemonService[X]` as `Resident over X`
  (`prepositional.over`), and `DaemonService[?]` as `Resident`. The constructor no longer takes
  `deliver: bus => Unit` or `bus: Chain[bus]`; `bus: Chain[Transport]` and `broadcast(message:
  Transport): Unit` are abstract members, implemented by the daemon. Being no longer a case class,
  it has no `copy`, `unapply`, or structural `equals`/`hashCode`; its other constructor parameters
  remain public `val`s, with the same names. (#2163)
- `ethereal.service[bus <: Matchable](using DaemonService[bus]): DaemonService[bus]^{service}`
  (also `soundness.service`) renamed to `ethereal.resident[bus <: Matchable](using Resident over
  bus): (Resident over bus)^{resident}` (also `soundness.resident`); `service` removed. Rewrite
  every `service.…` inside a `cli` block as `resident.…`. The context function taken by
  `ethereal.cli[bus]` now provides `Resident over bus` in place of `DaemonService[bus]`. (#2163)

## exoskeleton

- `exoskeleton.Enclave` (`exoskeleton-rig`) now finds the builder it packages with in the
  environment variable `$XEK` instead of `$XEQ`, and defaults to `dist/xek` instead of
  `dist/xeq`. A test environment that set `$XEQ`, or fetched the builder into `dist/xeq`, sets
  `$XEK`, or fetches it into `dist/xek`, instead; `$XEQ` is no longer read. (#2157)

## jacinta

- `jacinta.Json.apply` gains overloads `apply(value: Int)`, `apply(value: Short)`,
  `apply(value: Byte)`, `apply(value: Float)`, `apply(value: Long)` and `apply(value: Double)`
  beside `apply(value: Any)`. `Json(i)` for an `Int`, `Short` or `Byte` now holds that integer
  (stored as a `Long`), where it previously held the `Int` raw, which the AST reads as a packed
  small decimal, so the value read back was wrong (usually `0`); a `Float` is stored as a
  `Double`. A value statically typed `Any` still goes to `apply(value: Any)` unchanged. (#2162)

## stratiform

- `stratiform.layer` (`case class layer(name: Text) extends StaticAnnotation`, also exported as
  `soundness.layer`) removed. Its replacement is `stratiform.assign` (`final class assign(layer:
  Tel.Layer[?]) extends StaticAnnotation`; `soundness.assign` is a type alias of it, leaving the
  term `soundness.assign` to anamnesis), which names a layer by a
  singleton object rather than by text. Rewrite `@layer(t"foo")` on a field as `@assign(foo)`,
  declaring once, at the top level or in an object, `object foo extends Tel.Layer("foo")` (the
  same name); fields sharing a layer name share the one object. The derived schema is unchanged.
  The argument of `@assign` must be a reference to such an object, whose name is a string
  literal; anything else is now a compile error at the annotation. (#2165)
- New `stratiform.Tel.Layer[name <: String & Singleton](val name: name)`, an open class a layer
  object extends, and `stratiform.Tel.Name[layer <: Tel.Layer[?]]`, the match type giving a
  layer's name from its type. New annotation `stratiform.retract` (`final class retract(layer:
  Tel.Layer[?]) extends StaticAnnotation`, also `soundness.retract`), for a case of a sum. Not
  required by existing code. (#2165)
- Layer composition (`Tels.Layers.compose`, `Tels.Layers.composeComponents`, and acceptance
  serving and reading) no longer rejects a layer's `exclude` of a variant which the base
  `select` declares but an earlier layer has already excluded: it is a no-op. Previously that
  raised `Tel.Error` with reason `ExcludeMissingVariant` (E211). An `exclude` of a variant the
  base `select` never declared still raises it. (#2165)
- `fulfil(acceptance, codecs)` on a value leaves out of its composition any offered layer whose
  `select` excludes a variant keyword that the value's encoded document uses anywhere, where it
  previously offered every layer (and failed to serve such a value). The served
  `Tel.Acceptance.Served#hashes` may therefore omit such layers. (#2165)
