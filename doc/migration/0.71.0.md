# Changes since 0.70.0

This file is read by an LLM agent to upgrade code that consumes Soundness libraries from
0.70.0 to the next release. Each entry states precisely what changed; see `AGENTS.md` for the
format. Entries are grouped by module, most-recently-added last within a module.


## ethereal

- `ethereal.DaemonService` no longer takes a type parameter: `case class DaemonService[bus <:
  Matchable](…)` is now `abstract class DaemonService(…)` with a type member `type Transport <:
  Matchable`, the type of the messages its clients exchange. Write `DaemonService[X]` as
  `DaemonService over X` (`prepositional.over`), and `DaemonService[?]` as `DaemonService`. The
  constructor no longer takes `deliver: bus => Unit` or `bus: Chain[bus]`; `bus: Chain[Transport]`
  and `broadcast(message: Transport): Unit` are abstract members, implemented by the daemon. Being
  no longer a case class, it has no `copy`, `unapply`, or structural `equals`/`hashCode`; its
  other constructor parameters remain public `val`s. `ethereal.service[bus]` now takes `(using
  DaemonService over bus)` and returns `(DaemonService over bus)^{service}`, and the context
  function of `ethereal.cli[bus]` takes `DaemonService over bus`. (#PRNUM)

## exoskeleton

- `exoskeleton.Enclave` (`exoskeleton-rig`) now finds the builder it packages with in the
  environment variable `$XEK` instead of `$XEQ`, and defaults to `dist/xek` instead of
  `dist/xeq`. A test environment that set `$XEQ`, or fetched the builder into `dist/xeq`, sets
  `$XEK`, or fetches it into `dist/xek`, instead; `$XEQ` is no longer read. (#2157)

## jacinta

- `jacinta.Json.apply` gains overloads `apply(value: Int)`, `apply(value: Short)`,
  `apply(value: Byte)`, `apply(value: Float)`, `apply(value: Long)` and `apply(value: Double)`
  beside `apply(value: Any)`. `Json(i)` for an `Int`, `Short` or `Byte` now holds that integer
  (stored as a `Long`), where it previously held the `Int` raw, which the AST reads as a packed
  small decimal, so the value read back was wrong (usually `0`); a `Float` is stored as a
  `Double`. A value statically typed `Any` still goes to `apply(value: Any)` unchanged. (#2162)
