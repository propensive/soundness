# Changes in 0.66.0

This file is read by an LLM agent to upgrade code that consumes Soundness libraries from
0.65.0 to 0.66.0. Each entry states precisely what changed; see `AGENTS.md` for the format.
Entries are grouped by module, most-recently-added last within a module.

## ziggurat

- The `ziggurat` library is removed. Its packaging (`ziggurat.Packaging`, `ziggurat.Packager`)
  and polyglot script generation (`ziggurat.Xeq`, `ziggurat.Payload`) now live in the separate
  [propensive/xeq](https://github.com/propensive/xeq) project, published as the `xeq` builder
  script alongside the runner stubs. Build a distributable with `xeq build --jar <jar> --out
  <name>` (or `embed-all`/`download`) instead of calling `Packager.pack`. (#1988)

## anthology

- `anthology.xeq` (the `Jar`-to-executable toolchain edges: `xeqEdges`, `xeqOptions`,
  `XeqConfiguration`, `anthology.Xeq`) is removed. The same packaging is reachable as a toolchain
  format in the `xeq` project's `xeq.toolchain` module. (#1988)

## ethereal

- `ethereal.Assembler` and `ethereal.Runners` are removed, along with the in-JVM self-packaging
  path (`java -Dbuild.executable=… -jar app.jar`). An application JAR run without a launcher now
  prints an instruction to build one with `xeq build …` and exits. Package with the `xeq` builder
  script. The launcher→daemon `build.id` property is unchanged. (#1988)
