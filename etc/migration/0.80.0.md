# Changes since 0.79.0

This file is read by an LLM agent to upgrade code that consumes Soundness libraries from
0.79.0 to the next release. Each entry states precisely what changed; see `AGENTS.md` for the
format. Entries are grouped by module, most-recently-added last within a module.

## build

- The pinned compiler is Proscala `1.2.0` on Scala 3.10.1 (`3.10.1-pro-1.2.0`, was
  `3.10.0-pro-1.2.0`). Soundness's published artifacts are compiled with it, so a consumer
  compiling against them pins the same build. Under capture checking, Scala 3.10.1 checks the
  level of a read-only capability `x.rd`, which 3.10.0 did not: a closure which calls only
  non-`update` members of a `scala.caps.Stateful` capability `x` bound by a lambda parameter,
  and which is the result of that lambda, was accepted with the inferred type
  `() ->{x.rd} T` and is now the error _Capability `x.rd` outlives its scope_. Such code
  must return a value which does not capture `x`. (#2459)
- Scala 3.10.1 rejects two shapes which 3.10.0 compiled; neither is specific to Soundness, but
  both arise in code which uses it. First, `x += f(a)` fails with _value += is not a member of
  Long_ (or of whichever type `x` has) when `x` is a `var` and `f` has a leading `using` clause,
  as parasite's `async` does: bind the operand first, as `val y = f(a); x += y`. Second, a Java
  source compiled together with Scala sources may not name a protected nested type through a
  subclass, as protoc-generated builders name `GeneratedMessage.BuilderParent`: compile such
  Java sources in a Java-only module which the Scala module depends on. (#2459)

## proscenium

- `missingContext`, the export of `scala.annotation.implicitNotFound` under another name, is
  removed, from `proscenium` and from `soundness`. Soundness no longer annotates any type or
  parameter with it: delete a `@missingContext("…")` annotation, or write
  `@scala.annotation.implicitNotFound("…")` to keep it. The compile errors for a missing
  `Testable` (probably, sedentary), `Typesettable` (phoenicia), `Ratel.Reader` (stratiform),
  `Readable` (turbulence), `Permit` or `ProcessingPermit` (gastronomy) no longer have their own
  text, and are the compiler's _No given instance of type …_: code which matches on the former
  text, such as a `demilitarize` test, must match on the type's name.

## probably

- `Testable.orphan`, the text of the former error for a `test` with no `Testable` in scope, is
  removed, and has no replacement.
