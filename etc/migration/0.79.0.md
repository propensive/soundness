# Changes since 0.78.0

This file is read by an LLM agent to upgrade code that consumes Soundness libraries from
0.78.0 to the next release. Each entry states precisely what changed; see `AGENTS.md` for the
format. Entries are grouped by module, most-recently-added last within a module.

## murmuration

- `murmuration.Intersectable` now also extends `prepositional.Resultant`, gaining the abstract
  type member `Result`. Its members were `def intersect(left: Self, right: Operand): Self` and
  `def except(left: Self, right: Operand): Self`; they are now `def intersect(left: Self,
  right: Operand): Result` and `def except(left: Self, right: Operand): Result`. The extension
  methods `intersect(right: operand)` and `except(right: operand)` return
  `intersectable.Result`; they returned the receiver's type `self`. The given
  `murmuration.Intersectable.set` is typed `Set[element] is Intersectable by Set[element] to
  Set[element]`; it was `Set[element] is Intersectable { type Operand = Set[element] }`. Results
  for a `Set` are unchanged. A hand-written `Intersectable` instance must define `Result` and
  return it. (#2553)

## proscenium

- `proscenium.Map.build[key, value](lambda: Map.Builder[key, value]^ => Unit): Map[key, value]`
  gains a second, contextual parameter list, `(using hashable: key is proscenium.Hashable,
  equatable: key is proscenium.Equatable)`. Both resolve for every `key` to the universal
  instances in the typeclasses' companions (`##` and `==`), with which the result is as before.
  A call which passes `Map.build` an explicit second argument list, or eta-expands it, must be
  changed; a call of the form `Map.build[K, V] { map => … }` needs no change. With another
  `Hashable` or `Equatable` in scope for `key` at the call (for example
  `proscenium.equalities.identityEquality`), the map's keys are hashed and compared by those
  instances instead. (#2553)

## rudiments

- The object `rudiments.sorting` is renamed `rudiments.sortingInternal`; its members
  (`Entry`, `extremum`, `comparator`, `sorted`, `ordered`, `drain`) are unchanged. It is the
  plumbing which the inline `sort` and `order` extensions expand to, so code compiled against
  an earlier release must be recompiled; source which calls `sort`, `order`, `maximize` or
  `minimize` needs no change. (#2553)

## stratiform

- `stratiform.Tel.Document` gains a seventh field, `terminated: Boolean = false`, after
  `continuation`: `true` when the document's last line was in a source atom and ended with a
  line ending. Its `apply` and `copy` accept it and its `unapply` yields it, so a constructor
  pattern `Tel.Document(a, b, c, d, e, f)` must gain a seventh sub-pattern. (#2553)
- Writing a document (`Tel is Showable`, `Tel.Document is Showable`, `emit`, `lend`) whose last
  line is in a source atom now writes the final line ending if the source had one: the text
  `"note\n    first\n    second\n"`, read as a `Tel` and shown, gave `"note\n    first\n
  second"` and now gives the source text. A source with no final line ending is unchanged. (#2553)
- Blank lines which follow a source atom, before a line at a lesser indentation or the end of
  the document, are no longer discarded when a document is read. They end the block the atom's
  compound is in, and are counted in that `Tel.Block`'s `trailingBlankLines`, as blank lines
  after any other line are; the compound which follows begins a new `Tel.Block`. The atom's
  text is unchanged, and so are `childCompounds`, `field`, `fields` and every decoded value.
  Writing such a document back now reproduces the blank lines: `"detail\n    All about
  it.\n\nentry Text\n"` gave `"detail\n    All about it.\nentry Text\n"` and now gives the
  source text. Code which indexes a subtree's `children` (its blocks) by position must allow
  for the additional blocks. (#2553)
- A run of N blank lines at the very end of a document which ends with a line ending is now
  counted as N + 1 in the last block's `trailingBlankLines` (it was N), so that writing the
  document back reproduces every one: `"a\n\n"` gave `"a\n"` and now gives `"a\n\n"`. (#2553)
- `stratiform.Tel#document: Optional[Tel.Document]` is now public (it was
  `private[stratiform]`), and `stratiform.Tel` gains the public members `blocks:
  Array[Tel.Block]` and `transform(lambda: Tel.Compound => Tel.Compound): Tel`. `Tel` extends
  `scala.Dynamic`, and a member takes precedence over dynamic selection: with
  `dynamicAccess.dynamicTel` in scope, `tel.document`, `tel.blocks` and `tel.transform` no
  longer select a child compound of that keyword. Use `tel.field(t"document")`,
  `tel.field(t"blocks")` or `tel.field(t"transform")` for such a field. (#2553)

## turbulence

- `turbulence.Stdio.divert[result](stdio: Stdio)(block: => result): result` now also binds
  `scala.Console.out` to `stdio.out` and `scala.Console.err` to `stdio.err` for the duration of
  `block`, by `scala.Console.withOut` and `withErr`. `Stdio.capture`, which calls `divert`,
  therefore also captures what `block` writes through `scala.Console` (`scala.Predef.println`),
  which it previously captured only if `scala.Console` was first loaded after a diversion had
  been installed. (#2553)
